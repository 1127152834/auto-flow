# CloakBrowser 0.5.9 指纹种子范围（M4 Task 1）

- 日期：2026-10-04；状态：confirmed（Windows，内核 chromium-146.0.7680.177.5）；macOS 平台参数待补测
- 来源：cloakbrowser 0.5.9 源码与 METADATA；实测脚本 `apps/backend/tests/research/seed_range_probe.py`

## 文档与源码

- METADATA：`--fingerprint` 默认随机 10000–99999；"同一种子跨启动得到同一指纹"。
- `config.get_default_stealth_args()`：`random.randint(10000, 99999)`——这只是包装层的默认随机范围，不是内核限制。
- 本项目当前 `browser_launch_options` 也把种子限制在 10000–99999（`worker.py`），沿用的就是这个默认范围。

## 实测（每个种子启动两次，哈希 canvas、WebGL 渲染器、音频、硬件并发、屏幕）

| 种子 | 确定性 | 指纹哈希 |
|---|---|---|
| 10000 | 是 | 4371e8ce… |
| 12345 | 是 | 44652e70… |
| 99999 | 是 | 4adda3cd… |
| 102345（12345+90000） | 是 | f0e1584d… |
| 282345（12345+3×90000） | 是 | 540d4bb8… |
| 1,012,345 | 是 | c97c9ccd… |
| 2,147,483,647 | 是 | a910c728… |
| 4,000,000,000 | 是 | 35c06f64… |

8 个种子 8 个不同指纹；超出文档范围的值被接受且确定，相差 90000 不碰撞（内核不取模）。

## 结论（供 Task 2）

- `SEED_MIN = 10000`，`SEED_MAX = 2**31 - 1`：比实测的 32 位上限保守，避免内核以有符号整数解析时越界。
- 约 21 亿个种子，新分配随机抽取并靠 `seed_registry.seed_value` 唯一约束重试即可；规格中"可用种子低于 10% 提醒"不需要。
- 旧数据 10000–99999 的种子全部落在新范围内，迁移无需改值。
- 注意：GPU 型号等部件取自有限候选表（两个种子都得到 RTX 3050），整体区分度来自 canvas/音频噪声；"种子唯一"不等于每个部件都唯一。
- 未验证：macOS（`--fingerprint-platform=macos`）下同样的范围与确定性；> 2³² 的值是否回绕（设计上不使用）。
