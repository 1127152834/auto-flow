# AutoFlow AI 工作记忆

`.ai/` 是项目协作知识库，不存放业务源码。它记录经过确认的上下文、架构决策、经验和阶段计划，帮助后续 agent 延续工作而不重复猜测。

Studio 当前状态以 [memory/studio-status.md](memory/studio-status.md) 为准：已按用户新授权迁入 WebRPA 前端编辑器、Store 与 HTTP/SSE Mock 边界；真实后端与各平台验收仍按迁入台账推进。

## 目录

- `memory/`：稳定的项目事实、用户偏好、当前目标。
- `knowledge/`：技术调研、迁移经验、验证结论。
- `decisions/`：已确认的架构和产品决策，使用 ADR 格式。
- `plans/`：阶段性实施计划和任务拆分。
- `sessions/`：每次重要协作的简短记录，包含完成项、未决项和下一步。

## 维护规则

1. 只记录可复用、已验证或明确确认的信息；不把猜测写成事实。
2. 先更新对应文件，再在会话中引用路径；重要决策必须记录原因和取舍。
3. 变更代码、API、目录或工作方式后，同一提交中更新相关知识记录。
4. 不保存密钥、令牌、个人隐私或完整对话转录。
5. 过时内容标记为 `superseded`，不要静默删除历史决策。
