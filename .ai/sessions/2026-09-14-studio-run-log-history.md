# Studio F3：独立运行身份与日志历史

## 决策

- 将单次执行 `runId` 与流程 `workflowId`、编辑文档 `documentId` 分开。
- 实时 Store 只承担有界渲染；历史日志的查询、筛选和导出以服务端记录为准。
- Mock 与将来的正式后端使用相同的运行列表、日志分页及 JSONL 导出合同。
- Vitest 全量并发固定为 4，避免 12 核环境下大量 jsdom/user-event 文件并行导致字符输入损坏；不延长测试超时。

## 结果

- 10,000 条日志在内存及实际本地 HTTP 两种传输上完成分页、组合筛选和完整导出。
- Studio 页面完成历史选择、分页、搜索和刷新恢复。
- 全量 284 文件、3,380 项前端测试通过；7 项后端合同、49 项脚本、类型、ESLint、OpenAPI 和构建通过。
- 正式 Electron Blob 下载、真实自动化后端和跨平台实机仍需后续里程碑验收。
