# Studio F3：调试运行身份与暂停变量修改

## 决策

- 所有暂停控制以 `runId + pauseId + controlRevision` 共同定界，不能只依赖工作流和节点。
- 多变量修改是单个幂等命令；未知响应查询原命令，不能重发。
- UI 等待新的暂停事件确认修改，HTTP 成功只表示命令已被接收和登记。
- 变量事件携带作用域、只读状态和最近来源；循环局部值不能由暂停面板修改。
- 前端仅接受标准 JSON 值和有限数字，单请求上限 1 MiB。

## 结果

- 内存及本地 HTTP 两种实现共享同一调试变量合同。
- 已验证并发重复、旧运行、旧暂停、迟到回执、丢响应查询、明确拒绝、无效 JSON 和局部只读。
- 正式 worker、真实浏览器调试和 Electron 宿主继续留在后端与 F6 验收范围。
- 浏览器实测发现并修复 React Flow 断点按钮手势隔离和终态后历史摘要不刷新；修复后完成导入、断点、变量 1→7、单步和 completed 状态链。
