# F3 交互输入值验证

2026-09-14。InputPromptDialog 的手动确定与 AI 弹窗操作共用 validatePromptValue。复选框验证实际布尔值；滑动条验证实际数字；单选/多选验证已选项及候选成员。它们不再误用隐藏的文本状态做必填验证。数字必须有限，整数拒绝小数，最小/最大值与长度限制对 AI 同样有效。可选空单选返回空字符串、空多选返回 [] 的 JSON 文本。

滑动条保留合法 0 默认值，不再被负数最小值覆盖。文本、多行、列表、密码、文件/目录文本和数字沿用原结果编码。相同活跃 requestId 重复到达保留正在填写的值；过期、取消或已提交的缓存 AI action 不再重复提交。

初始 19 个场景全部失败；修复后扩展 38 个组件用例全部通过。前端全量 128 文件/1546 项通过，包含本轮拾取与变量原子编辑修复；lint 和 renderer/main/preload 构建通过。首次类型检查实际失败：测试参数暴露事件层只声明两种输入模式，以及测试库不支持的 exact 选项；原先“类型通过”的记录有误。后续输入协议批次统一13种模式的生成类型、修正测试调用与 nullable 原生属性后重新通过，详见 input-command-protocol.md。证据 evidence/f3-input-validation。

仍需实现服务端交互命令应用、确认回执及断线未确认时的草稿保留。文件选择的异步响应归属、输入请求完整队列与运行身份也未由本批解决。组件 sendInputResult spy 只能验证正确提交参数，不证明服务已经执行或浏览器已运行。F3 未完成。
