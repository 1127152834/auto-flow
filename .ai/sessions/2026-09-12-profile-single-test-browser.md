# 配置测试浏览器单会话与状态同步

- 日期：2026-09-12
- 状态：confirmed（实现与当前桌面实测完成）
- 来源：用户明确要求每份配置仅打开一个测试浏览器，按钮切换为关闭，原生关窗后恢复打开；当前 manager、HTTP 与 React Query 源码。
- 范围：现有测试功能的有界修正；旧多窗口语义 superseded，持久化项目环境不在本次范围。

## 实现

后端公开测试会话列表和幂等关闭接口。启动前防重覆盖代理解析、启动、运行和回收阶段；关闭结束或检测到原生关窗后移除状态。前端每秒轮询后端作为状态源，POST/DELETE 成功直接更新查询缓存，页面重新进入也恢复状态。启动/关闭独立按卡片等待；关闭失败保留运行态，状态同步失败禁止误启动并允许重试。运行中禁止删除配置，避免丢失关闭入口。

复用既有临时目录、代理 relay、POSIX 进程组与 Windows Job Object，不新增浏览器实例数据库或依赖。重置指纹对下次启动生效，当前窗口仍使用启动快照。
