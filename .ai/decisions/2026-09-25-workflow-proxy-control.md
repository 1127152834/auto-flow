# 工作流代理控制边界

日期：2026-09-25。状态：confirmed。来源：用户批准的实施计划及当前实现。

- 三节点复用现有远程服务和 proxy_operations，不增加供应商 HTTP 客户端、数据库表或调度器。
- 单次确认预算默认30秒；轮数默认5，间隔10秒，均允许变量。IP基准固定为节点入口的新连接出口观测。
- worker通过现有私有管道异步请求宿主，校验运行、执行代次、节点访问；真实POST前再次校验运行仍有效。
- 使用登记只补本sidecar的浏览器占用，持久unknown互斥由原数据库负责。原运行未存可靠代理身份时，遗留目录未清理会保守阻断工作区全部代理；不能从浏览器地址或凭据反推身份。
- 供应商尚忙、结果未知时只读，不以“IP相同”证明操作已结束。只有已受理且供应商明确允许再次操作，或地点代次推进的已验证证据，才允许下一次写入。
- 不刷新/重启浏览器；清理旧转发连接并走原转发入口验证。指定其他代理不改变当前浏览器绑定。
- 捕获仅处理预期操作失败；取消、协议错误不伪装成功。结果变量使用既有 `{result['status']}` 访问语法。
- 实网/Windows/打包验证单独记录，本机合成测试不替代。
