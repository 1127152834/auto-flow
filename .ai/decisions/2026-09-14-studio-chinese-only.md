# Studio 仅提供中文界面

日期：2026-09-14；状态：confirmed / implemented。

依据：用户明确“不需要 i18，AutoFlow 本来就只服务于中国”。旧迁入的中英界面能力退出产品范围。

移除语言选择、系统语言探测、DOM 翻译监听/词典、40 份英文教学文件及 i18n 审计，共 44 个专属文件。43 个原迁入文件记录转入 excluded-source-files.json；参考源码与已有用户数据不改。中文教学文档继续懒加载和缓存；浏览器语言/时区、代码语言、技术标识不受此决定影响。

历史 i18n 验收是当时事实，不重写；后续不维护英文词条，不要求英文覆盖。删除专属测试来自本次产品范围变更，保留所有中文功能回归。

验证：99 文件 / 1,167 项前端测试，类型/lint/构建、16 项脚本测试通过；实际浏览器设置及中文文档通过。证据见 docs/migration/studio-frontend-completion/chinese-only.md。
