# M5 体验重构 设计规格

- 日期：2026-09-30；状态：proposed，待用户审批
- 总纲：[整改里程碑总纲](2026-09-30-remediation-roadmap.md)；对应整改方案 H1–H8、I1–I7、J1–J7、K、L、M、G4（界面部分）
- 前置：M1 已合并即可开始 5A；5B 依赖 M2 的签名与台账接口；5C 的身份页依赖 M4
- 实施计划：[M5 实施计划](../plans/2026-09-30-remediation-m5-experience.md)（任务级）
- 评审依据：[前端交互评审](../../qa/2026-09-30-remediation-reviews/frontend-interaction-review.md)

## 1. 结论

用户在任何地方看到和操作的都是"账号·邮箱"这样的业务名称；画布优先；运行时看得见每一行卡在哪里；全应用只有一套颜色、组件、图标和动效规范。M5 与后端并行，按依赖分三段交付。

## 2. 分段

| 段 | 内容 | 依赖 | 周 |
| --- | --- | --- | --- |
| 5A 基础 | K 设计系统统一（令牌、深色值、控件迁移、图标）、L 动效令牌、M 文案术语表与 CI 检查、J2–J6 Studio 布局与节点视觉、I1–I2 导航与项目外壳、G4 模块条视图与小问题 | M1 | 3–6 |
| 5B 数据与运行 | H2–H8 数据绑定体验（签名面板、数据侧栏、标签输入框、写回表单节点、End 勾选、绑定页、试跑）、I3 运行总览、I4 批次实时监控、I5 数据表页、I6 任务详情时间线、J7 运行与调试 | M2 | 6–9 |
| 5C 身份与衔接 | 身份列表页、I7 Studio 嵌入主窗口、失败归组一键跳到失败节点试跑、可用性验收 | M4 | 9–11 |

## 3. 需求（按整改方案条目，验收写在第 5 节）

| 编号 | 需求 |
| --- | --- |
| R5-01 | 令牌：`styles/tokens.css` 为唯一来源；补齐表面层级、文字层级、状态色、8 种节点类别色、动效时长与曲线；每个令牌有深色值。 |
| R5-02 | 写死调色类按映射表脚本化替换为语义类；`webrpa.css` 拆解后删除；守门检查 `paletteClasses` 归零后改为 lint 规则禁止。 |
| R5-03 | Studio 控件改用 `shared/components/ui`；缺少的颜色选择器、坐标输入、路径输入补进共享库；删除 `workflows/components/controls`。 |
| R5-04 | 图标统一为 lucide；phosphor 导入归零后从依赖中移除。 |
| R5-05 | 动效令牌 motion-fast 120ms / base 180ms / slow 280ms / loop 1.2s；去掉节点整体闪烁与弹跳；运行中只在外圈显示进度，失败节点变色不抖动，画布平移定位；设置提供"完整 / 减少 / 关闭"。 |
| R5-06 | 术语表 `shared/copy/glossary.ts` 与 CI 检查：界面文案不得出现内部术语（数据集代次、RecordRef、执行代次、撤权等）；错误信息 = 发生了什么 + 怎么办。 |
| R5-07 | Studio 工具栏单行：左侧流程名、项目、保存状态；中间撤销 / 重做、视图切换；右侧"试跑▾"（次要）与"批量运行"（唯一主按钮）；其余收进"更多"与命令面板（Ctrl+K）。 |
| R5-08 | 布局：左右栏可折叠并记忆宽度；未选中节点时右栏收起；底部面板空闲时一行状态条、运行时展开到 30%；小地图默认关闭；1440×900 下画布 ≥ 60% 窗口面积。 |
| R5-09 | 节点两行：动作名 + 数据标签与目标；正文 ≥ 13px；类别色只用左侧细色条；状态用角标与外圈；配置问题显示警告角标。 |
| R5-10 | 快速添加面板：双击画布或 `/`，最近与常用 12 个节点；从连线端点拖到空白处弹出同一面板并自动连线。 |
| R5-11 | 配置面板分"基本 / 高级"，校验错误就地显示，选择器旁常驻"当前页面匹配 N 个元素"。 |
| R5-12 | 流程"输入与输出"面板（编辑签名，可填样例值，可从数据表导入）。 |
| R5-13 | 数据侧栏（输入字段及样例、上游节点输出、全局变量、凭据）与标签输入框（CodeMirror 6 原子装饰）：引用显示为"账号·邮箱"，悬停看样例、类型、来源，失效引用标红可重选，内部保存 `{input.账号.email}`；敏感样例打码。替换 `controls/variable-input.tsx`。 |
| R5-14 | 画布数据可见：节点第二行显示数据标签；读 / 写角标；选中侧栏字段时高亮引用它的节点；分支连线带文字标签。 |
| R5-15 | 写回改为 4 个表单节点：更新当前记录、设置状态、新增记录、查询记录（可视化条件编辑器复用数据页筛选组件）；不出现 UUID 与版本号。 |
| R5-16 | End 节点：业务结果、"保留当前身份的登录状态"开关、"关联到"勾选输入分组名称。 |
| R5-17 | 自动化绑定页：左签名字段、右表字段，按名称和类型自动匹配，未匹配标红；实时"当前条件匹配 N 行，其中未处理 M 行"并展示 3 行样例；多表关联用连线图；输出字段可一键在表中创建。 |
| R5-18 | 试跑：按表的主显示字段选择行（可搜索）；节点旁显示实际使用和产出的值；默认"不真实写回"。 |
| R5-19 | 全局导航改为左侧窄栏 4 项：运行总览、项目、资源（身份模板、代理、模型、内核）、设置；安卓与实验室移入设置中的"实验功能"开关，默认关闭。 |
| R5-20 | 项目外壳：一行项目头（约 56px）；可折叠二级左栏（概览、数据、流程、自动化、运行、身份、统计）；最多两层导航，详情用右侧抽屉。 |
| R5-21 | 运行总览：指标行（运行中批次、当前并发 / 上限、今日已处理行、成功率、待人工数）、需要处理、运行中批次、下一次定时、资源健康。 |
| R5-22 | 批次实时监控：按台账 state 分段的进度条、吞吐与预计剩余、正在运行的任务卡片（行显示名、身份、当前节点、用时、5 秒刷新的截图缩略图）、失败按错误编码归组（批量重跑 / 跳过 / 导出）、全部任务表。 |
| R5-23 | 数据表页：全宽、虚拟滚动、冻结首列、列宽记忆、行内编辑、右侧抽屉详情、行操作收进"…"菜单、台账列与身份列、处理状态左边条。 |
| R5-24 | 任务详情时间线：每节点一行（耗时、用到的值、产出、attempt 次数），失败节点自动展开原因、建议、截图，数据写入与环境保存内嵌在时间线中。 |
| R5-25 | Studio 作为项目"流程"模块的工作区，默认在主窗口打开，可弹出；从批次失败归组一键跳到失败节点并用该行数据试跑。 |
| R5-26 | 模块条视图：错误分支节点显示在来源节点下方并标注"出错时"；没有起始节点的完全循环图预检报错。 |

## 4. 设计约束

- 每个页面先完成组件（含组件测试）再组装页面（`AGENTS.md` 工程习惯）。
- 视觉回归：关键页面在 1280×800 与 1440×900 两档截图比对，截图作为 CI 产物，不入库。
- 功能开关：`newStudioLayout`、`tagInput`；黄金场景与视觉回归连续 7 天通过后默认开启。

## 5. 验收标准

| 编号 | 验收 |
| --- | --- |
| AC5-01 | 守门检查：`paletteClasses` = 0、`secondIconLibraryFiles` = 0，并转为 lint 规则。 |
| AC5-02 | 1440×900 下 Studio 画布可见面积 ≥ 60%（自动化截图测量）。 |
| AC5-03 | 引用项目数据时界面可见的内部 ID 数量为 0（术语与 UUID 扫描测试覆盖流程编辑、写回节点、End、绑定页、试跑）。 |
| AC5-04 | 术语检查在 CI 通过。 |
| AC5-05 | 批次监控页在 G2（10,000 行）运行中保持 60fps 滚动，数据延迟 ≤ 2 秒。 |
| AC5-06 | 可用性验收：5 位未接触过系统的目标用户，不看文档完成"导入账号表 → 录制注册流程 → 绑定数据 → 试跑一行 → 批量运行 → 处理失败行"，至少 4 人独立完成，中位用时 < 20 分钟。 |
| AC5-07 | 减少动效设置下无循环动画，状态变化直接切换。 |

## 6. 风险

| 风险 | 应对 |
| --- | --- |
| 大规模样式迁移带来视觉回归 | 脚本化替换 + 截图比对，按页面分批合入 |
| 标签输入框替换影响所有节点面板 | 功能开关；保留旧组件直到全部面板通过契约测试 |
| 依赖 M2 / M4 接口延期 | 5A 不依赖后端；5B、5C 以接口契约（OpenAPI）先行，页面用契约夹具开发 |
