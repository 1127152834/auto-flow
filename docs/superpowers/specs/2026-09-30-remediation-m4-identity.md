# M4 身份模型 设计规格

- 日期：2026-09-30；修订：r2；状态：proposed（按用户已确认的评审方向修订，未实施；开工门槛见总纲）
- 总纲：[整改里程碑总纲](2026-09-30-remediation-roadmap.md)；对应整改方案 F1–F5 与黄金场景 G1
- 前置：M3 已合并（会话模式、环境瘦身）
- 实施计划：[M4 实施计划](../plans/2026-09-30-remediation-m4-identity.md)（任务级）

## 1. 结论

把"指纹种子 + 固定代理 + 登录环境 + 地区"合成一个"身份"对象，整体分配、整体恢复、整体校验。每个账号一个身份；新建身份分配不同种子，历史重复种子明确保留。代理成员粘性与实际出口IP分别记录，出口变化按策略核实；不承诺可变代理供应商永不换IP。perIdentity会话在本阶段建立身份后接入。

## 2. 背景

- 种子挂在浏览器配置上（`application/profiles/service.py:30`，范围 10000–99999）：同一批次所有任务同一指纹；1,000 个配置时出现重复种子的概率约 99.6%。
- 代理池按运行轮转成员，不与账号绑定；开启 geoip 时时区随 IP 变化。
- 记录上的"当前环境"只关联登录环境，不关联指纹和代理。

## 3. 目标与非目标

**目标**：F1–F5 全部落地；黄金场景 G1 建立并达标。

**非目标**：代理供应商接入扩展；账号养号策略（属于流程内容）。

## 4. 需求

| 编号 | 需求 |
| --- | --- |
| R4-01 | 表 `identities`：identity_id、project_id、name、template_profile_id、seed_id（引用全局种子登记；兼容旧共享种子）、region（timezone、locale、geolocation）、proxy_binding（fixed proxy_id 或 pool_id + member_id）、environment_id、health（last_login_success_at、consecutive_failures、banned）、created_at、updated_at。 |
| R4-02 | 全局种子登记表seed_registry以seed_value唯一约束；新分配事务插入新值并绑定一个身份，绝不复用已有登记。旧迁移可将多个独立身份引用同一登记，标记legacyShared并记录冲突成员；此权限仅迁移路径可用，公开创建API不可指定历史共享豁免。先验证 CloakBrowser 0.5.9 支持的种子范围：支持更大范围则放宽；否则在可用种子低于 10% 时提醒。 |
| R4-03 | 记录关联：记录的"当前环境"字段迁移为"身份"；领取时带出身份，任务按身份恢复种子、代理与环境。 |
| R4-04 | 粘性代理：身份首次使用代理池时分配成员并写入 proxy_binding，之后固定；成员失效时按策略处理：sameRegion（同地区替换）、confirm（进入人工待办）、never（身份不可用）。 |
| R4-05 | 启动前校验：测出口 IP 地理位置（缓存 10 分钟），与身份 region 比较，不一致按策略拒绝或警告；代理健康预检失败归 infrastructure，不消耗行预算。代理正在换 IP 时有限等待（默认 60 秒）后再启动。 |
| R4-06 | 身份独占：同一身份同一时刻只有一个活动浏览器（沿用环境独占）。 |
| R4-07 | 身份健康参与领取：banned 或连续登录失败 ≥ N（默认 3）的身份，其关联行跳过并进入待处理列表。流程可通过 End 的业务结果或新节点"标记身份状态"更新健康。 |
| R4-08 | 临时身份模式（无登录采集）：每个任务生成一次性种子，不宣称全局唯一；不得与持久身份混用或保存登录状态。pool若需要任务级种子而内核无法在隔离上下文切换，则回退perTask，不静默沿用上一任务种子。 |
| R4-09 | 接口：身份 CRUD、从模板批量创建（按数据表行一行一个）、重新生成种子（二次确认，提示可能触发网站重新验证）、健康重置。 |
| R4-10 | 迁移：每个已保存环境生成一个身份，沿用其实际冻结身份包的种子、UA、语言、时区和内核关联，不从当前Profile重新推导；多个环境共用同一种子时写入迁移报告，由用户逐个决定是否重新生成（默认保留）。记录的"当前环境"迁移为对应身份。迁移前自动备份工作区。 |
| R4-12 | perIdentity在identity_id建立后实现：同身份串行多任务租借同浏览器，身份独占覆盖等待人工与空闲租借；保留该身份的浏览器登录状态，但Task注入的凭据、数据变量和权限不继承；撤权/结果未知立即封锁复用并关闭或保留待核实现场，不能归还池。 |
| R4-11 | 浏览器配置降级为"身份模板"：内核、默认语言、扩展、行为参数；不再持有种子。 |

## 5. 设计要点

- 领域：`domain/identities/`（身份、种子分配规则、地区一致性判断，纯逻辑）；应用：`application/identities/`；持久化：新迁移 `rm4_identities`。
- M3只提供perTask/无登录pool；本阶段新增perIdentity，以identity_id为键；临时身份与pool的组合必须证明内核支持所需种子隔离，否则保持perTask。
- 代理粘性分配复用 `ProxyRemoteControls` 与 `ResolveProxyForProfile.resolve_group`，新增"按身份解析"入口。
- G1 场景站点：登录页（2% 账号密码错误返回业务错误）、资料页（记录 Cookie、UA、时区、出口 IP 声明）、本地 SOCKS 代理夹具（可注入 5 分钟断开）。

## 6. 验收标准

| 编号 | 验收 |
| --- | --- |
| AC4-01 | G1新建200身份种子两两不同；稳定出口夹具中每身份3次运行种子/UA/语言/时区/出口一致。另注入同一代理成员出口变化，验证检测及拒绝/警告/人工策略；不以成员ID相同冒充出口未变。 |
| AC4-02 | G1 中 2% 密码错误的账号记为业务失败，批次不停，身份健康计数增加。 |
| AC4-03 | 代理断开 5 分钟期间：失败归 infrastructure，不消耗行预算；连续失败达阈值时批次暂停并指出代理；恢复后继续。 |
| AC4-04 | 出口 IP 地区与身份 region 不一致时按策略拒绝启动，错误说明两边的地区。 |
| AC4-05 | 迁移：夹具工作区中的环境全部生成身份；共用种子的环境出现在报告中且种子未被改变。 |
| AC4-06 | 新分配1000身份及并发分配无重复；两个历史同种子环境迁成两个独立身份、同一登记且legacyShared报告完整。公开API不可创建共享豁免，新分配不重用旧共享值。 |
| AC4-07 | perIdentity连续多行复用、参考变量与Task注入凭据清理、身份登录状态保留、跨批次身份独占、等待人工/撤权/未知结果不归还；临时种子与池隔离不支持时明确回退。 |

## 7. 风险

| 风险 | 应对 |
| --- | --- |
| 迁移后网站要求重新验证 | 默认保留原种子；重新生成需二次确认 |
| 种子范围受内核限制 | 先验证再决定；低于 10% 可用时提醒 |
| 地理位置服务不可用 | 校验结果缓存；服务失败时按策略"警告继续"或"拒绝" |
