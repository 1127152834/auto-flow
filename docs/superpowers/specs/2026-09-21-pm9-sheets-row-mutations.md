# PM9 Sheets 行变更与公式模板：待确认切片

日期：2026-09-21；状态：proposed，未包含在已提出的 C1–C4/R1–R5 确认问题中。来源：data-and-state-rules.md §10–11 和 f580b1c6 源码。

## 当前缺口

`outbound._push` 对未定位到的身份直接记录 SYNC_REMOTE_ROW_MISSING，没有新增云端行路径；本地 delete_record 只提交 tombstone/本地操作/变更事件，没有删除同步意图。现有项目 Sheets 源码未使用 appendCells/deleteDimension/copyPaste 等行变更或公式复制能力。DATA-SH-03/10/11 不能仅列缺测试/实网；本地删除不复活、公式只读刷新和现有行字段推送的通过证据仍有效。

本片独立于系统 UUID 初始化、增列和共享 Task lease：复用相同身份/操作账本与 Google transport，不能把其中一项的交付代替另一项。

## 最小契约和原命令恢复

- 新增：仅对明确本地新建来源的记录生成 `appendRow` 意图，冻结目标/bindingEpoch、可靠业务键、字段快照及公式模板修订；既有远端缺行的本地记录不自动变为新增。发送前同 Workspace/Spreadsheet 协调下重查业务唯一键；存在且无本操作归属证据时报告冲突，不覆盖。发送结果未知后核验原键、字段/归属证据，不盲目追加；跨设备或外部协作者竞争不能由本机锁保证唯一，发现重复应隔离并显示修复动作。
- 删除：明确操作影响整个物理行，包括未映射列与其他绑定；复用影响预览，冻结原共享身份、bindingEpoch、影响修订与整行身份/内容证据。在事务提交 tombstone 时登记独立删除意图。远端定位后紧邻发送重验；不以旧行号删除别人记录。结果未知先按原身份核验，无法确定则保持待处理；本地删除不自动恢复。
- 公式：绑定显式选择模板行/列，冻结来源身份、范围和模板修订；复制是新增的子步骤。已新增但公式未完成不得标整操作 confirmed，也不得为重试公式再新增一行。模板消失、混合公式或结构变化保留本地记录和已知远端阶段，不猜公式。
- 账本：沿用 SyncOperationRow 并扩展已有 kind/stage 契约，记录已发送阶段和原始请求；同一原 operationId/digest 重放只读已完成结果。不同状态的本地后续修改作为新意图依赖未决新增，未经确认不得越过阶段。业务 statusId/statusRevision 保持本地，来源变更不自动迁移状态。

## 垂直切片与验证

1. M1：先确定可安全核验的新增归属证据及 Google 请求组合；若 provider 没有足够原子性，先形成具体保守失败契约，不用本机串行代替远端并发证明。离线验证两个项目同键、写成功响应丢失、外部插行和已存在冲突。
2. M2：删除影响 DTO/持久意图/原命令恢复，再接管理确认和任务授权。测试跨绑定活动占用、预览后外部移行/改身份、响应丢失后不误删以及 tombstone 的删除同步状态展示。
3. M3：模板配置与新增分阶段确认；注入新增成功但复制失败、模板改变和重启核验，断言只一个原新增身份、不重复行、不能提前确认。
4. 按片更新 OpenAPI/客户端/UI/操作详情、定向 pytest/Vitest/类型/lint，然后稳定候选完整本机和三平台。Google 实网仍要求明确授权表及账号；不把受控 transport 当作实网。

这些是新增持久远端变更协议，须依 AGENTS.md 确认后实施。当前生产候选验证继续，不为本片提前放开远端写入。releaseAccepted=false。
