# 设置与总览设计规格

- 日期：2026-09-12；状态：confirmed（用户授权自主完成设计、计划并直接在 baseline 开发）。
- 分支：`codex/architecture-baseline`，直接使用当前工作树，保留其他任务改动。
- 依据：`docs/prototype/settings/`；旧 `SettingsPage.tsx`、`DashboardPage.tsx`、工作区协调器；新主进程与 AppPaths。

## 产品范围

设置保留常规、工作区、关于三个页签，水平导航、暖灰黏土棕配色。实现真实服务状态/重启、四类目录打开、工作区切换与切回、校验和失败回滚、平台退出语义、运行环境详情，以及已授权进入本轮的缩放、减少动效、诊断导出。组件先于页面，复用现有 shadcn/Radix 控件。

总览延续旧版“资源概况 + 工作入口”，移除独立内核导航（内核从浏览器配置表单管理），提供浏览器、代理、模型、设置入口。显示真实浏览器配置数、已启用代理数、代理组和已安装内核数；模型模块可用时显示其实际计数，不可用时显示未接入，不伪造零。已启用代理不标为“健康/可用”，不编造任务趋势、节省时间或成功率。空态引导创建资源，失败保留重试。

## 所有权与契约

桌面主进程拥有本机偏好、原生目录选择、workspace 根选择、运行信息、服务生命周期和本地诊断文件保存。Python 提供只读资源聚合、运行信息、占用预检和暂停接收变更请求；renderer 不操作文件或进程。

- `GET /api/v1/dashboard`：真实资源计数与生成时间。
- `GET /api/v1/settings/runtime`：后端/Python/SQLite/API 版本、已知目录、占用原因。
- `POST /internal/settings/quiesce`：仅 host token，无 Origin；原子检查在途变更和任务占用，再禁止新变更请求。
- `POST /internal/settings/resume`：停止/切换前失败时解除暂停。
- 前端 HTTP 类型来自 OpenAPI；桌面 IPC 类型统一放 `apps/desktop/src/shared/settings.ts`，main/preload/renderer 共用。
- 新 IPC 只接受枚举、经过校验的偏好、由原生选择器产生且绑定本窗口的短期选择凭据。不得接受任意文件路径或 renderer 提供的诊断内容写磁盘。

## 工作区与生命周期

“工作区”是业务数据根，内部路径沿用当前 AppPaths，非 `root/workspace` 子目录本身。既有 AutoFlow baseline 默认 userData 根原地接管，不复制/清理其业务数据；新选择目录必须为空或带有本版 `.autoflow-workspace.json` 标记，拒绝旧版 marker、无标记非空目录、文件和不可写目录。

本机设置保存在固定 userData 下，包含 schemaVersion、当前/上一个根、缩放与动效。本机设置不随工作区切换。采用临时文件+原子重命名、备份，读取失败恢复备份并显示恢复提示；两者均损坏时保留证据并要求重新选择或退出，不静默创建新业务数据掩盖故障。

切换：选择器前预检 → 系统选目录 → 校验+预览确认 → 再检查/暂停接收变更 → 停旧服务 → 启目标服务并验就绪 → 保存新 current/previous → 重建客户端与缓存。取消/选择同一规范路径无副作用。启动或保存失败时恢复旧服务与原路径；恢复也失败时明确报告并保留重试/选择/退出入口。重启、切换与退出串行，重复提交拒绝，提交进行中不可关闭弹窗。仅新增空目录留下合法初始化标记，不搬迁、覆盖或删除目录。

占用覆盖已存在的内核下载/安装/授权子进程、代理同步/检查、浏览器配置活动标记/锁、在途 API 变更；后续执行器须加入同一检查。无法证明空闲时拒绝切换。主进程停止后不得因查询已停止后端而无法恢复启动。只对合作进程和现有标记提供占用判断，不声称可发现任何外部程序打开的文件。

## 偏好与诊断

缩放 90/100/110/125%，主进程 `webContents.setZoomFactor` 应用；动效 system/reduce/full，根节点统一规则。偏好立即保存，失败还原已保存值，启动/新建窗口恢复。

诊断默认仅白名单运行版本、平台、服务状态、错误码；日志默认不选。为保证无原始凭据泄露，首版可选日志仅包含本应用记录的结构化生命周期事件（时间、事件、状态和固定错误码），不扫描任意日志或导出 stderr 原文。完整预览与保存内容一致，预览 ID 绑定窗口且短期有效。保存使用原生 SaveDialog，取消不成功；不可写可重新选择。使用可直接查看的单一 `.json` 诊断文件，代替原型示例 `.zip`，无需新增压缩依赖，不改变预览和本地导出能力。不导出数据库、浏览器配置、代理凭据、host/instance token、真实用户路径或原始异常堆栈，不上传。

## 应用装配与验证

设置即使 sidecar 离线仍可访问并恢复。应用壳保留现有领域入口，轮询监督器状态，按实际 instance/baseUrl 更新 ApiProvider；切换后清理旧工作区查询缓存。macOS 关闭最后窗口保留应用；Windows 关闭最后窗口退出；退出有序停止 sidecar。

验证：偏好持久化、坏设置备份/双坏恢复、marker/目录校验、切换成功与双重失败、跨平台路径、IPC 来源/输入/短期选择凭据、诊断不泄漏、原生保存取消/失败；后端鉴权/占用/暂停竞态/计数语义；前端加载/空/错误/保存/弹窗防重复；完整 pytest、Vitest、lint、typecheck、OpenAPI、build、sidecar smoke 与 macOS 实际 UI。Windows 本机打包/运行不在当前 macOS 上冒充通过。
