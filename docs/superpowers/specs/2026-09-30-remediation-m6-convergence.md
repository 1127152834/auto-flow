# M6 收敛与清理 设计规格

- 日期：2026-09-30；状态：proposed，待用户审批
- 总纲：[整改里程碑总纲](2026-09-30-remediation-roadmap.md)；对应整改方案 C4、G2、G3、N1，以及删除旧路径与功能开关
- 前置：M4、M5 已合并，且各功能开关在黄金场景连续 7 天达标
- 实施计划：[M6 实施计划](../plans/2026-09-30-remediation-m6-convergence.md)（任务级）

## 1. 结论

M6 只做减法：Studio 调试与批量运行合并为一个执行引擎；节点有明确的输出契约；节点目录从 220 种收敛到约 50 个核心节点加表达式；冻结范围移入实验功能；删除旧执行栈、旧控件库、旧引用格式和所有整改期功能开关。

## 2. 背景

- 两套执行栈：Studio 走 `WorkflowRunCoordinator` + `workflow_worker.py`（2,143 行），项目运行走 `WorkflowRunDispatcher` + `project_workflow_worker.py`，两套运行表，容量各算各的。
- 节点输出写到哪个变量靠 `project_graph.py` 按类型猜配置键；变量提示不看执行顺序。
- 220 种节点中约 85 种纯计算；桌面触发器、系统操作、局域网共享在并发批次中危险。

## 3. 需求

| 编号 | 需求 |
| --- | --- |
| R6-01 | 共用事件转换：Studio 与批量运行使用同一个"执行器事件 → 运行事件"转换函数（先于入口切换完成）。 |
| R6-02 | Studio 调试 = 带调试标志、不属于任何批次的单次运行，走同一派发器、worker、事件模型和运行表；断点、单步、变量查看作为运行选项。 |
| R6-03 | 历史 Studio 运行记录迁移到统一运行表（只迁元数据与日志索引）；旧栈在新栈通过全部调试用例后删除。 |
| R6-04 | 节点输出契约：每个执行器声明输出（名称、类型、是否敏感），统一落到"节点名.输出名"；全局变量只能由"设置变量"节点产生；编辑器只提示一定已执行的上游输出；预检报告引用不存在或可能未生成的输出。`project_graph.py` 的配置键猜测逻辑删除。 |
| R6-05 | 表达式 `{= ...}`：基于 `safe_expr`，提供字符串、数学、列表、字典、日期函数库；所有输入框支持。 |
| R6-06 | 节点目录：核心约 50 个（网页导航与交互、元素查询与采集、控制流、数据节点、HTTP、AI、验证码、通知、脚本）；纯计算节点保留执行器以兼容旧文档，打开时提示"可一键转换为表达式"并提供转换。 |
| R6-07 | 冻结范围（N1）：Android / iOS 模拟器管理、桌面触发器、系统操作、局域网共享移入"实验功能"开关（默认关）并在批量运行中禁用；Google Sheets 保留读取与导出，双向同步停止扩展。 |
| R6-08 | 删除：旧引用格式 `PROJECT_INPUTS[...]`（M2 起已迁移一个版本）、`workflows/components/controls`、`webrpa.css`、phosphor 依赖、功能开关（台账领取模式、会话复用、新 Studio 布局、标签输入框）的旧分支；M0 的守门项全部转为 lint 规则或删除。 |
| R6-09 | 破坏性数据库清理（只在本里程碑）：删除旧 Studio 运行表、旧"当前环境"列；迁移前自动备份，迁移可在备份上重放验证。 |
| R6-10 | 文档：按整改方案 N2 改写仍然有效的设计文档（业务场景、指标、不做什么）；过时的设计与计划标记 superseded。 |

## 4. 验收标准

| 编号 | 验收 |
| --- | --- |
| AC6-01 | 仓库中不再存在 `workflow_worker.py` 旧执行路径与 Studio 专用运行表；Studio 调试用例全部在统一引擎上通过。 |
| AC6-02 | 同一流程在 Studio 试跑与批量运行中产生相同的节点事件序列（对照测试）。 |
| AC6-03 | 模块库默认只显示核心节点；旧文档中的纯计算节点可打开、可运行、可一键转换。 |
| AC6-04 | 变量提示只列出上游一定已执行的输出，预检能发现引用未生成输出的情况。 |
| AC6-05 | 黄金场景 G1–G4 连续 7 天全部达标（整改方案"验收基准"表中的所有目标）。 |
| AC6-06 | 删除功能开关后全部测试、构建、打包冒烟通过。 |

## 5. 风险

| 风险 | 应对 |
| --- | --- |
| 合并执行栈期间 Studio 调试功能回退 | 先共用事件转换再切入口；旧栈保留到新栈通过全部调试用例 |
| 隐藏节点导致旧文档打不开 | 执行器保留，文档可打开可运行，只是不在模块库展示 |
| 破坏性清理不可逆 | 自动备份 + 在备份副本上重放迁移后再执行 |
