# AutoFlow 全局精细网格表格规格

日期：2026-09-14。状态：依据用户选定第二张图及“先构建全局统一组件，再盘点并统一实施”的授权执行。视觉源：../../prototype/table-system-2026-09-14/fine-grid-selected.png。

## 目标与边界

全部真实表格采用细浅横纵线、轻表头、14px正文、紧凑工具。保留顶部导航、页面层级、已有卡片和业务逻辑。常规单行目标32px；有按钮的行允许40px，多行内容自然增高，禁止裁掉操作。查询输入、工具按钮、查询选择器32px（表内行操作28px，含操作行40px），不能缩放整个页面来假装紧凑。

交付基线为正式主线 bdca5ee，独立工作区 autoflow-table-system / codex/global-table-system。早期 dcb1831 盘点已被主线整合替代；保留已合入的同表行内新增和完整 Studio。主目录及旧实施目录只读参考，不覆盖其他任务未提交文件。

## 组件方案

选择扩展现有shared/components/ui/table.tsx和现有控件，新增组合式TableToolbar；各领域仍负责数据/列定义、查询草稿、幂等及请求隔离。相较纯全局table CSS，本方案有显式接入边界；相较引入完整DataGrid引擎，不重写已验证的查询与编辑行为。packages/ui不另建第二实现。

Table保留原生table语义和ref；TableHead默认为col，详情键值使用row；不添加伪grid角色或每格Tab停止。TableScroll负责具名键盘可滚动区域。视觉由唯一tables.css及令牌定义，普通表格/内嵌表/Studio虚拟网格共享视觉，虚拟化保留原机制。

工具栏只组合既有控件，不增加业务能力。记录字段选择/关键词/搜索操作组成一组，筛选、排序、选列互斥草稿行为不变；代理保留输入即查询，模型保留本地过滤，不强行统一触发方式。

## 状态及布局

细线使用现有line，背景surface/subtle，hover使用surface-hover，selected使用clay-soft；状态有文字而非仅颜色。焦点沿用可见黏土色outline，不能全局outline:none。loading/错误/只读由领域传入，刷新失败保留旧内容。行选中只反映真实Checkbox选择。

表内按钮小而可聚焦，危险动作不成为主色；长文保留title或现有详情，长标识不撑宽应用。表格必要横滚只发生在TableScroll，工具栏在窄视口换行。表头/单元格共享字号间距，列宽仍由领域提供。

分页保留服务端页码及总数事实，统一32px按钮；不更改每页数量、排序或自动请求。Excel预览保持10行上限及异常提示；来源事实保持只读。嵌套Dialog/Popover继续OverlayHost，不污染弹窗内普通表单尺寸。

组件测试验证原生语义/ref、标题作用域、受控selection及scroll区域。现有业务测试和真实Electron流程验证筛选取消/应用、排序、显示列、记录编辑、字段原子保存、状态引用、Excel预览及文件闭环不退化。
