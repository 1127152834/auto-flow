## 1. 需求复述与完成定义

交付一个功能完整的正式 Studio 前端：所有保留节点可配置、编排和保存，其依赖的配置、资源、变量、工具、对话框、运行/调试/录制/拾取交互全部接通。成功、失败、取消、离线、重连和并发冲突均有确定行为。

Mock 代替服务实现，不代替前端功能。正式后端接入阶段，原则上只实现已冻结契约并替换服务适配，不再新增缺失页面、Store 动作、业务规则或交互分支。

“前端不再需要动”的工程定义：

1. 页面、组件、Store、编辑模型不依赖 Mock 实现或场景控制开关。
2. Mock 和正式适配器满足同一契约；正式后端使用同一套请求/响应/事件契约测试。
3. 切换服务实现不修改组件、表单、状态机和编辑算法；只允许连接配置、协议映射或宿主适配变化。
4. 若联调需要补功能，判定为前端交付遗漏；若外部能力或产品需求变化，记录契约变更及影响后再调整。
5. 真实集成可能发现缺陷，不承诺永远零行修改。不得借此把已知未完成项留到后端阶段。

## 2. 范围冻结

2026-09-14 用户确认：产品仅提供中文界面；移除界面语言切换、翻译运行时和英文教学文档，i18n 不再属于交付范围。浏览器语言、时区等自动化配置继续保留。

### 2.1 保留能力

以基线当前动作目录的 **284 个内置入口** 为初始保留清单，生成逐项 `type + 分类 + label` 快照。数量只是防漏基准，不是验收证据。不得再凭“非 Web”主观删掉现存数据库、AI、网络请求等条目；用户本轮明确剩余节点有用。

保留节点所需配套功能必须追踪并交付，包括但不限于：

- 原画布与模块条视图、分组、便签、子流程、自定义模块、快捷添加、搜索、收藏、排序。
- 属性编辑、默认值、参数校验、变量引用/选择、结构化数据编辑、代码编辑器与相关辅助工具。
- 文档新建/打开/保存、导入导出、资源引用、撤销重做、未保存保护。
- 浏览器/Profile 选择、标签页、选择器/框架定位、拾取、定位测试、录制审查与生成。
- 运行、断点/单步等原版保留调试能力、日志、数据、变量追踪、结果与导出。
- AI 助手、保留节点实际依赖的模型/MCP/凭据/连接配置和工具。
- 主题、布局、快捷键、Tooltip、错误反馈、窗口与服务连接协调。

不沿用旧 M1–M6 编号推断能力已实现或默认恢复旧设计。当前行为以冻结源码与用户已批准的 AutoFlow 差异为依据；发现规则缺失时写明确决策，不自创第二套产品。

### 2.2 删除能力及其依赖

此前排除的企业、发布/版本、Windows 桌面、手机、SAP，以及本轮排除的 Excel、PDF、Word/通用文档与文件处理、图像编辑、盲水印、音视频处理/播放/转换、QQ/微信机器人、飞书和 WPS，不恢复其节点和专属配套配置。

删除必须覆盖：分类/搜索/快捷入口、收藏/常用残留展示、专属设置标签、对话框、文档帮助入口、AI 工具暴露、Mock 路由和仅供这些功能使用的依赖。

采用调用关系判断共享能力：

- 保留节点仍使用的图片资源、数据表、路径选择、变量输入、凭据或代码工具，保留所需部分。
- 不因排除 Excel 节点就删除网页采集结果的表格展示；不因排除图像编辑就删除网页截图预览。
- 不删除用户已保存文档和自定义模块。遇到已排除节点，明确标记不支持、禁止执行和重新添加；允许无损查看/导出，不静默丢节点或改配置。
- 删除专属源码前建立引用清单；不以全目录字符串替换方式删除。

## 3. 逐模块台账：全覆盖的依据

建立 `docs/migration/studio-frontend-completion/`，至少包含：

1. `capabilities.json`：每个保留节点及每个非节点能力的稳定 ID、源入口、当前入口、配置字段、Store 动作、依赖工具、请求、事件、验收 ID、状态。
2. `excluded-capabilities.md`：删除范围、专属/共享依赖、旧文档处理与清理证据。
3. `contract-matrix.md`：方法、路径、DTO、错误、幂等、取消、事件与关联测试。
4. `acceptance.md`：逐项实际结果、证据路径、平台与未验收项。
5. `backend-handoff.md`：后端需要实现的操作、事件、持久化、资源及权限语义。

台账状态固定为：待核对、待实现、待验证、通过、明确排除。文件复制、按钮可点击、测试数量都不能直接标记通过。

每个保留节点至少覆盖：默认创建、各条件显隐分支、合法/非法配置、变量引用、编辑提交、保存重开、复制/撤销、所有配套工具入口。共享表单可复用测试，但要验证每个节点的实际注册和字段映射，不能只测组件本身。

## 4. 架构与契约

### 4.1 遵守 AutoFlow 的现有结构

- 编辑器组件、Store/hooks、前端规则留在 `apps/desktop/src/renderer/domains/workflows`。
- 公共连接、鉴权、SSE parser 和生成类型复用 `renderer/shared/api`；不新增平行 HTTP 客户端、contracts 包或事件总线。
- 窗口/目录/资源等受控宿主能力在 main/preload 的现有 IPC 边界内；校验已登记窗口和主 frame。
- 沿用 React、TypeScript、Zustand、React Flow、现有主题和构建；不为了完成前端重写源图算法。
- 后端仍遵循现有 workflows 分层。本阶段不开发真实执行器、数据库业务或真实录制服务。

### 4.2 先冻结语义，再冻结线路格式

保留源前端模型和调用语义；通过有限适配层映射 AutoFlow API。不得假定 WebRPA 原 HTTP 形状天然等于 AutoFlow 最终契约。

F1 批次为全部服务操作确定：

- 请求/响应及错误结构、字段默认值、空值、单位、枚举、日期/标识、分页和大小限制。
- 文档/资源 revision 与冲突处理；修改时间由服务返回。
- 命令接受与实际应用的区别；状态查询、幂等 ID、响应丢失后的恢复。
- 事件序号、运行/会话/请求 ID、执行次数/上下文、重复和乱序规则。
- 能力不可用、权限不足、配置缺失、资源占用及取消后的可操作状态。

沿用现有 OpenAPI 生成工具与 `renderer/shared/api/generated.ts`。F1 明确唯一契约源及 schema-only 导出路径，在不启动真实业务的条件下生成类型；禁止 Mock DTO 与正式类型各自手写维护。SSE payload/IPC 同样有可校验 schema 或现有共享类型，不只写在 Markdown。

契约不能仅覆盖当前成功样例。每个操作同时提供最小成功样例、业务拒绝、传输失败、空结果与涉及的取消/冲突样例。F1 存在未确定的必需字段或状态，不进入依赖该契约的批次。

### 4.3 Mock 是服务替身

- 页面只调用正式服务接口；移出 StudioApp 对 configureMock 等具体实现的依赖，场景面板只在测试/开发入口挂载。
- 使用可复现的状态化夹具，能够创建、查询、修改、失败、取消、冲突和恢复；未知操作返回明确错误。
- 交互型操作按 requestId 等待用户结果，校验迟到/重复结果，不能收到任意命令就 success。
- 控制流通过预置执行轨迹驱动 UI，不在 Mock 内重写完整自动化执行引擎。轨迹必须与冻结的文档 ID/节点 ID 对应。
- 单独验证传输边界：至少一种测试夹具通过本地 HTTP 和真正的 SSE 字节流提供同一契约，不能只用内存函数调用证明网络接入完成。
- 区分 renderer 重载、断线、服务重启；通过服务侧测试夹具保留历史，模拟服务重启后的 interrupted 状态，不将 renderer 内存冒充后台持久化。
- 媒体/图片/下载等 DOM 资源加载使用受控 URL/Blob 适配；不得把虚拟域名直接交给原生 src 请求。
- 模拟必须明确标识，不宣称网页、模型、数据库或系统操作真实发生。

## 5. 前端业务行为要求

| 领域 | 必须完成的行为 |
|---|---|
| 文档与编辑 | 编辑输入先提交再捕获；保存途中继续编辑不误清脏；失败保留草稿；冲突可恢复；导入错误不破坏当前文档；复制与撤销覆盖完整操作 |
| 参数与配置 | 默认值/枚举/单位与契约一致；隐藏字段保留或清空有明确规则；变量/凭据/资源选择可用；错误定位具体字段；配置持久化和重开一致 |
| 运行与调试 | 独立运行快照；编辑不修改运行；每次执行有身份；多轮状态不覆盖；等待/暂停/失败/清理中的按钮合法；停止失败不伪造结束 |
| 拾取与录制 | 目标页和请求绑定；换节点/改字段/导航/关闭使旧结果失效；取消不改草稿；录制审查及整批生成可撤销；与运行互斥 |
| 日志/数据/变量 | 分页、空/大数据、筛选、断流补读、去重；从运行快照取节点信息；结果按需读取；导出成功/失败反馈完整 |
| AI 与辅助工具 | 本地工具真实操作编辑模型；外部工具经服务；批准/拒绝/取消/失败有状态；工具变化可回溯；配置和资源选择不依赖硬编码样本 |
| 生命周期 | 新建/打开/关闭/退出/换区统一处理草稿与会话；保存成功后才清理；取消不停止；清理失败不离开；主窗口单独关闭不误停 Studio |
| 连接与权限 | 离线不刷新丢草稿；先重连再考虑重启；活跃会话阻止危险重启；工作区切换锁编辑并支持失败回滚；令牌不进日志/导出 |
| 体验与可访问性 | 原版布局/Tooltip/快捷键/面板缩放恢复；焦点与输入框快捷键优先；错误可读；键盘可操作；正式窗口高 DPI/窄窗口可用 |

具体某项若源版本不具备，台账注明“AutoFlow 接入要求”而非伪称原版行为。保留能力中已存在的日志搜索、导出、变量工具等不能无理由降级成后续项。

## 7. 验收矩阵

所有场景具有固定输入、操作、预期 UI、请求/事件、Store 断言和证据 ID。

| 分组 | 必测内容 |
|---|---|
| 范围 | 删除类别及专属设置不可达；剩余节点完整；旧文件/自定义模块中排除节点不会消失或被静默执行 |
| 每个节点 | 默认配置、各显隐分支、必填/类型/单位、变量/资源、保存重开、复制撤销；全部配套工具入口 |
| 每个请求 | 成功、空、字段错误、401/403、409、离线/超时、取消；有幂等需求的重复/丢响应/迟到请求 |
| 每个事件族 | 正常、重复、断流补发、服务重启、关联 ID 过期、失败/停止竞争、终态之后的迟到事件 |
| 编辑 | 输入框快捷键不误触画布；运行/保存中继续编辑；跨文档切换；导入损坏；批量操作一次撤销 |
| 控制流/Debug | 真/假分支、循环多轮/零轮、嵌套上下文、重复节点执行身份、断点/单步/停止、变量变化 |

| 工具 | 代码编辑器、JSON/数据编辑、资源/凭据、AI 批准拒绝、MCP 发现失败、导出缺失文件、连接配置恢复 |

容量验收固定使用：500 节点图、1,000 次节点执行轨迹、10,000 条日志分页、超过 64 KiB 的变量/结果、资源列表分页。记录测试硬件、构建模式、实际耗时与内存。先在 F1/F2 建立基线，再为响应耗时设门槛；不得虚构跨机器统一性能结论。必须有界渲染/分页，不一次展开全部日志或大变量，不静默截断原值。

自动检查包括：台账注册完整性、契约/schema/type 一致性、前端规则与组件测试、HTTP/SSE 适配测试、Electron IPC/生命周期测试、TypeScript、ESLint、目录/脚本检查及 renderer/main/preload 构建。只改文档不重复跑业务测试。

macOS arm64、macOS Intel、Windows 分列：通过/失败/未实测；模拟平台分支不能替代实机。缺平台设备时可交付明确的平台未验收记录，但不得标记全部平台完成。

## 8. 后端交接门槛

交接包应让后端开发者无需反查 UI 猜业务：

- 唯一 API/事件/IPC schema，完整样例和可执行契约测试。
- 文档/布局/运行快照序列化、兼容规则、资源引用与导入导出格式。
- 状态机、命令幂等/修订、取消/清理、互斥与工作区身份规则。
- 节点与工具依赖、参数校验边界、错误路径、输出数据与事件顺序。
- 所有场景及固定期望；持久化、分页、资源下载/导出、权限和服务恢复要求。
- Mock→正式连接切换说明；明确仅允许修改的适配位置。

至少以第二种 HTTP/SSE 契约实现运行同一套前端验收，证明组件没有依赖 Mock 内部。真实网页操作、真实模型与 MCP、真实进程清理、数据库持久化正确性仍须后端阶段实测；前端验收不替代这些证据。

## 9. 不允许的“完成”判定

以下任一情况存在，不得宣布前端完整：

- 保留节点的配套工具仍是 TODO、不可点击、空处理器或永远成功。
- 配置能输入但不参与请求，保存重开丢失，或修改后无效却不提示。
- 核心流程只能靠开发者手动 emit 事件，没有可重复用户操作场景。
- HTTP 接受即显示执行成功；断线即失败；停止失败仍清空活跃状态。
- 只测一个同类节点，未检查其他节点实际注册/字段映射。
- 页面直接读取 Mock 内部状态，正式接入时必须重写 Store 或页面。
- 已排除能力继续要求用户配置；或者共享工具被误删导致保留节点失效。

完成声明应分别写清：前端功能通过、Mock/契约通过、宿主与平台结果、真实后端待实现项。不得将前端完成宣称为自动化系统真实运行完成。

## 10. 数据所有权与状态不变量

| 数据 | 所有者 | 前端规则 |
|---|---|---|
| 当前草稿与编辑历史 | 编辑会话 | 输入提交及编辑算法真实运行；不由 Mock 生成最终编辑结果 |
| 已保存文档、资源与配置 | 服务；本阶段服务夹具 | 前端只以成功响应更新保存基线；保留服务 revision，不用客户端时间推断覆盖安全 |
| 活跃运行/录制/拾取/Debug | 服务 | 以确认事件/查询为准；本地按钮状态不决定执行终态 |
| 运行快照 | 服务冻结、前端只读投影 | 与当前草稿分离；草稿变化不改日志名称或运行对象 |
| 布局与偏好 | 指定的本地/工作区设置服务 | 明确持久化范围；两个窗口 UI 状态独立，不互相覆盖草稿 |
| 凭据、令牌与大文件 | 受控服务/宿主 | 前端保存引用和必要掩码；不进入流程明文导出、日志或诊断快照 |

状态名称可由适配器映射，业务不变量必须一致：

- 文档 dirty/saving/conflict/error 不能简单互斥覆盖；保存中仍可变 dirty，失败保留最新编辑。
- 服务连接失效只代表连接未知/离线，不自动把运行标失败或成功。
- 运行/拾取/录制/Debug 共享互斥会话占用；只有服务确认清理完成才解除占用。
- HTTP 命令被接受不表示动作已应用；命令查询及事件携带可关联身份。
- 用户取消离开不发停止；保存失败不继续关闭；清理失败保留重试入口。
- 切文档/换区/换页/改字段使相关工具结果过期，过期结果只提示失效，不写回新目标。
- 对事件出现序号缺口先补读/查询；游标失效时按契约重新获取状态，不能凭前端猜补中间动作。
- 结束后迟到事件不得重新激活旧会话；旧工作区事件不能投影到新工作区。

## 11. 请求、事件和工具的规格要求

每个操作必须有稳定 operation ID，操作级合同至少包含下列字段定义；不要求所有接口机械采用同一字段名：

| 操作种类 | 必须定义 |
|---|---|
| 文档/配置读写 | 所属工作区、资源标识、schema 兼容、revision、冲突、字段问题、缺失/权限行为 |
| 启动与控制 | 稳定命令标识、相同请求重试、不同内容冲突、状态查询、取消、安全恢复 |
| 拾取/测试/编辑工具 | 目标标识与修订、输入、结果、错误、取消、过期判定、应用到草稿是否可撤销 |
| 列表与日志 | 筛选语义、排序、游标、空列表、总数是否精确、恢复边界、服务重启行为 |
| 资源与导出 | 资源标识、类型/大小、读取/下载方式、缺失文件、权限、取消、截止快照 |
| 实时事件 | 事件名、序号、资源/会话/运行身份、执行上下文、时间、payload、重复/缺口/终态规则 |
| 宿主 IPC | 已登记窗口权限、主 frame 校验、输入校验、结果/取消/错误、安全资源地址 |

前端和服务都需要校验。前端校验用于即时反馈，不能替代后端权限/数据校验。错误要能定位到字段、节点或工具，不能全部变成“操作失败”。

完整服务操作和线路 schema 是 F1 的交付物：在逐项盘点后冻结实际方法/路径，不在规格中杜撰尚未对照源调用的接口。冻结前不得将相关功能记为实现完成。

## 12. 工具完整性判定

每个工具按同一检查表验收：入口可达 → 已选上下文正确 → 输入校验 → 请求/本地操作 → loading/取消 → 成功/空/失败 → 用户确认应用 → 撤销或持久化 → 重开恢复。

- 本地工具：编辑、搜索、布局、复制、代码/JSON 编辑、变量选择、录制到节点转换等必须使用真实前端逻辑；不得 Mock 这些逻辑的结果来冒充完成。
- 外部工具：连接测试、定位、模型/MCP、数据库/网络、执行与采集等由契约夹具返回结果；前端输入、请求构造、状态反馈和应用结果必须真实实现。
- 混合工具：如 AI 生成后修改画布，服务输出可模拟，参数校验、权限确认、画布修改与撤销必须真实运行。
- 所有保留节点工具均需注册到能力台账；同一工具多个入口分别检查传入上下文，不能只验证一个弹窗。

## 13. 错误与恢复用户行为

| 场景 | 用户可见结果与后续操作 |
|---|---|
| 保存离线/失败 | 草稿仍可编辑，显示未保存和原因；恢复后显式重试 |
| 保存冲突 | 保留本地内容，提供明确的重新读取/另存处理；不自动覆盖 |
| 工具取消 | loading 结束，旧配置不变；服务清理未确认时继续显示处理中 |
| 工具空结果 | 展示明确空状态，可修改参数重试，不误报系统异常 |
| 资源不可用 | 显示缺失资源/配置项与可修复入口，不自动替代成默认值 |
| 命令响应丢失 | 查询原命令；不能自动生成新 ID 重复单步/启动/提交动作 |
| 服务重启 | 已保存历史可查，活跃操作显示中断；不自动重放网页动作或提交用户输入 |
| 工作区切换失败 | 回到原工作区及草稿；已停止的会话不自动重启 |
| 导出失败 | 保留当前记录，显示缺失/权限/网络原因；不下载伪造成功的空文件 |

## 14. 交付范围声明

前端阶段交付包括正式 Electron 窗口、真实前端算法与可用交互、完整配置/工具、服务合同、HTTP/SSE 夹具和测试。外部动作使用明确 Mock 标识。

后端阶段交付真实执行、浏览器采集、数据库/文件持久化、模型/MCP/连接与资源清理，必须满足同一契约。前端阶段不得用真实系统集成未完成为理由保留空按钮；后端阶段不得擅自修改已冻结语义以迫使前端补业务。
