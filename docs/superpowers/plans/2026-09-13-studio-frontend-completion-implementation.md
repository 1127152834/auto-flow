- 工具结果绑定文档/节点/字段修订/页面/请求；所有变更与取消使旧结果失效。

### F4.2 录制审查与生成

- 保留源录制 UI/转换逻辑，补会话控制、步骤分页、尾部确认、重连和错误显示。
- 输入/点击/导航/页面变化通过服务夹具产生明确步骤；敏感字段与不支持动作清晰标记。
- 步骤编辑、变量化、生成预览、加入画布按完整操作撤销；生成响应迟到不覆盖新草稿。
- 切换运行/Debug/拾取/录制先确认并等待清理完成；取消保留当前会话。

验收：用户在正式 UI 完成启动→步骤审查→生成→保存→重开→模拟运行/Debug 的闭环；同时覆盖页面失效、清理失败、请求丢失和取消。结果只能标为前端协议验收，不标真实录制通过。

## 9. F5：宿主、设置与全部依赖收口

### F5.1 真实宿主桥接

- 在现有 main/preload/shared 层加入受控运行上下文及必要服务能力，不允许 renderer 拼接端口/令牌。
- 原生窗口、目录/文件选择、资源打开与快捷键使用现有适配入口；验证取消与权限拒绝。
- WebRPA 旧安全令牌/端口配置映射为 AutoFlow 管理，不保留无效可操作控件。

### F5.2 离开与恢复

- 实现统一离开处理：提交输入→选择保存/放弃/取消→必要保存→停止/清理→离开。
- 接入新建、打开、关 Studio、退出、换工作区；处理多次关闭、保存冲突及清理重试。
- 普通断线只重连；服务重启不重放动作；换区期间锁编辑并在失败时回滚。

### F5.3 剩余工具逐项销账

- 对 AI 助手/本地画布工具/MCP、模型、凭据、数据库/网络连接及保留策略等台账依赖逐项完成。
- 测试批准/拒绝/取消/不可用/权限不足/空列表；工具变更有可追踪结果。
- 删除原排除能力残留说明和帮助入口，更新用户文案，避免将 Mock 成功描述为外部服务已运行。

验收：所有保留依赖都有可重复闭环；离开矩阵通过；仅关闭主窗口不误停 Studio；错误或取消不丢草稿、不切错工作区。

## 10. F6：全量验收与后端交接

### F6.1 完整性检查

- 核对每个能力有契约、实现、测试及证据；所有排除条目有依据。
- 扫描 TODO、空处理器、固定 success、501、mock imports、硬编码虚拟资源 URL；逐条归类，范围内必需功能不得残留。
- 比对全部节点配置入口及专属工具，无只测共享组件而漏注册的条目。

### F6.2 工程与宿主验收

按根 package.json 的实际脚本核对并执行；桌面当前命令：

```sh
npm run test --workspace @autoflow/desktop
npm run typecheck --workspace @autoflow/desktop
npm run lint --workspace @autoflow/desktop
npm run build --workspace @autoflow/desktop
npm run openapi:check --workspace @autoflow/desktop
```

同时执行目录/脚本检查、HTTP/SSE 集成和 Electron 交互测试；契约 schema-only 导出如修改后端 schema，需要对应后端契约检查，不运行未实现执行器来制造通过。

开发 URL、构建 HTML、正式 Electron 包分别验收。PyInstaller/真实后端分发入口在本轮只验证宿主兼容边界，真实执行及资源清理留后端阶段。macOS arm64/Intel、Windows 各自记录实际平台结果，缺平台不能标通过。

容量数据固定：500 节点、1,000 次执行、10,000 条日志、大于 64 KiB 的值。记录硬件/构建模式/响应与内存；检查有界渲染、交互未冻结、原数据无截断。

### F6.3 交接

交付 capabilities.json、contract-matrix.md、acceptance.md、backend-handoff.md、可运行 HTTP/SSE 夹具、schema 与同一套契约测试。

后端实现必须通过同一套测试；替换适配器不得修改组件、Store、表单或增加遗留缺失 UI。每项真实业务待实现内容明确对应操作 ID、输入输出、事件顺序、持久化、取消/清理和权限要求。

## 12. 停止条件与变更控制

- F0 发现共享依赖：保留并追踪，不先删后补。
- F1 存在不确定字段/行为：对照冻结源码形成决策；需要新产品选择时列出具体选项及影响。依赖任务不凭猜测继续。
- 任一验收失败：修复当前批次，不将已知前端缺口转移到后端阶段。
- 出现与用户范围冲突的新能力：单列变更，不以“完整复刻”为由自动添加。
- 不给未经测量的日程承诺。每批以可运行交付物和退出门槛衡量，不以完成多少文件衡量。
