## 执行方式

从届时最新 baseline 创建独立 worktree/分支；先检查工作区和新迁移 head，保留其他任务改动。使用当前 FastAPI、SQLite、React、shadcn/ui、Tailwind 和 Phosphor。API 类型由 OpenAPI 生成；组件先于页面。按下面垂直切片交付，每片包含后端、前端和匹配测试，不先做一套全 mock 页面。

## 任务 1：冻结真实读取契约与能力语义

输入为官方 docs/developers、现有列表/凭据 adapter、已授权只读样本。

- 为详情、地点和空计划建立脱敏 fixture 与映射测试；检查地点/运营商稳定 ID、可用容量、运行前置条件。
- 核对非空计划字段、官方周期选项和目标地点完成判据；记录 unknown，不填猜测值。
- 修改本地占位 mode/interval DTO 的方案，生成新契约；修正证据来源与运行能力的关系，不自动启动或续费代理。
- 接通远程状态、地点、轮换 GET；构建状态区、只读计划状态、地点选择组件，再接入详情。

完成标准：当前账户能够看到真实位置、计划状态和中文 not_bound 原因；旧“schema 未核验”开发提示消失。读取失败可单区重试，不能误显示计划已关闭。

## 任务 2：完成最小命令记录与生命周期

- 检查 proxy_operations 现有表和当前唯一迁移 head，增补幂等键/请求摘要/身份版本/确认前置快照及必要索引。
- 实现短事务登记、同代理并发排他、同键去重、状态路由、受监管后台执行和退出/启动恢复。
- 完善前端本地任务轮询、重新打开详情恢复、旋转 loading 和“结果待核实”展示。
- 不引入通用任务框架；仅支持本模块的四种写操作，不复用供应商购买/续费幂等假设。

完成标准：重复请求最多发送一次远程写入；应用关闭或网络超时不自动重发；其他代理读取不被阻塞。

## 任务 3：即时换 IP

- 接通 Provider POST rotate、前置能力检查和详情读回。
- 为确认弹窗绑定实际命令，展示提交中/确认中/成功/明确失败/结果待核实。
- 结果刷新只更新当前代理远程字段，保留别名/启用，失效旧健康与相关选项缓存。

完成标准：能力允许的代理可发起，只有真实 current_ip 变化或经核验的最终完成证据才 Toast 成功；not_bound 代理显示原因且不发送变更。

## 任务 4：指定地点切换

- 地点目录支持搜索、运营商筛选、容量状态、重试和当前目标标记。
- POST 使用真实 location_id；提交前重新校验目标可用性；选择变化只改草稿。
- 处理地点售罄、代理忙、过期 revision；以目标匹配及新观测确认完成，刷新端点/地点/出口与凭据有效性。

完成标准：不会因旧 GET 响应或单纯 generation 增加而报切换成功；刷新失败不会重放 POST。

## 任务 5：轮换计划编辑、保存与关闭

- 完成独立 RotationScheduleForm：三种官方模式、分钟周期、草稿与保存、关闭计划确认、未保存关闭提示。
- 实现 PUT/DELETE，完成后 GET 读回；清晰标注服务端执行。
- 有已验证下次运行时间才展示；AutoFlow 不承担服务端周期调度。

完成标准：切换模式不会立即触发远程写入；保存/关闭读回一致，失败保留草稿；关闭 AutoFlow 不被误认为关闭计划。

## 任务 6：完整回归与真实验收

- 后端：Provider 字段校验；临时 SQLite 迁移、同代理并发、幂等冲突、Key 替换、同步乱序、断网/进程中断、unknown 恢复。
- 前端：组件与页面的加载、空、失败、限流、草稿、确认、任务恢复、loading 结束、键盘焦点和关闭行为。
- 运行 pytest、Ruff、mypy、npm test/typecheck/lint/build、openapi:check、test:scripts；迁移覆盖新库和现有库。
- 冻结 sidecar smoke 核对新增后台模块与迁移资源；平台差异仍归现有适配器，Windows 实机/CI 单独记录。
- CUA 验收只读界面，然后在明确允许中断且满足运行条件的代理上执行换 IP、切地点、保存/关闭计划；记录实际前后状态与失败，不保存凭据。取得实际写入授权与目标后才做这一步，之前可完成代码和自动测试。
- 当前 4 条代理均 not_bound。若写入条件仍不满足，交付必须列出具体阻塞和已完成范围，不能声称真实写入已通过，也不能用假 capability 绕过供应商限制。
- 更新 ADR、API 契约、PROJECT_STRUCTURE、迁移验收和 .ai；隔离复审后按用户既有协作方式接入 baseline，不触碰自动化编排草稿。

## 工程取舍

只增加本模块必要的远程用例、执行任务、表字段和领域组件；不新增代理系统、不自建轮换定时器、不扩展白名单/用量/购买。开发顺序以读取和命令确认机制为先，保证每个写操作都从开始就有真实状态反馈。
