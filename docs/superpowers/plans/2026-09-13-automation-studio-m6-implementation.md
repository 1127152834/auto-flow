# M6：网页录制与可重放流程生成实施计划

日期：2026-09-13；状态：**proposed，文档阶段，尚未获得实施确认**。

依据：[正式设计建议](../specs/2026-09-13-automation-studio-m6-design.md)、现有 M1–M5 源码、WebRPA 冻结源码 `5ccb900e8dcf1530aae66f676d87593c416c7ebb`。详细字段/状态以设计文件为准，本计划负责实施依赖、退出条件和证据。验收记录见 [M6 矩阵](../../migration/automation-studio-m6-validation.md)。

## 1. 交付目标与范围

用户在正式 Studio 录制真实网页操作，停止后审查并生成普通工作流节点，保存重开后，在独立浏览器里重放；失败能沿用 M5 调试。录制原浏览器的登录态不传给运行浏览器。

本轮建议包含导航、点击/双击/网页右键、文本、原生选择/勾选、限定按键、页面/容器滚动和确定性标签页路由。新增七种执行节点：select_option、set_checked、press_key、scroll_page、wait_page、switch_page、close_page；兼容扩展 input_text、open_page、click_element。

本轮不会生成尚无执行器的节点。drag/upload 等旧录制类型作为明确缺口进入后续专项；遇到可检测的不支持动作必须留问题项。完整核心对齐仍欠子流程、错误处理/重试、双视图/分组和剩余核心动作。

本轮新增产品选择均为建议，不把“请输出下一阶段文档”当成对字段或实现的批准。

## 2. 开工前冻结的设计决定

| 决定 | 建议值 | 理由与检查 |
| --- | --- | --- |
| 浏览器 | 专用可见临时会话，ready 后显式开始 | 复用 M3 资源能力，采集不影响正在运行/调试的页面 |
| 停止 | 固定捕获截止后保留浏览器供审查 | 停止捕获和资源关闭分开，互斥仍持续到清理结束 |
| 原始数据 | 工作区持久化已确认步骤，不保存 Cookie/HTML | UI 重连和关闭后仍可审查；进程丢失不冒充可恢复采集 |
| 文档 | schemaVersion 3 增加 literalPaths，旧格式读取不自动写库 | 录制 `{name}` 等原文不能被模板解释；语义变化显式版本化 |
| 应用位置 | 空流程或唯一顶层尾部；整批一次撤销 | 避免首轮同时实现跨控制块的智能插入/替换 |
| 页面 | 运行别名，不保存录制 pageId | 页面身份在独立浏览器可重新建立，不能“取最新页”碰运气 |
| 传输 | 受控 binding + 来源校验 + 有界确认缓冲；非消费式 HTTP 分页 | 先真实验证当前 CloakBrowser，不直接搬旧 sessionStorage drain |
| 范围 | 常见可重放网页操作优先；拖拽/上传等单列后续 | 不把节点数量当完成度，不隐瞒部分录制边界 |

## 3. 实施批次与退出条件

每批先定义契约和组件，再接入页面；每批包含相应后端、前端、真实浏览器及回归验证。按 A → B → C → D → E → F 推进，不以 UI 按钮可点击替代退出条件。

### A：确认采集链路与文档契约

工作：

1. 再核对 git 状态、数据库 head、节点目录、共享 locator、InspectionService、worker 单读取方和 M5 监护，不改历史迁移或无关 UI。
2. 固定录制/步骤/问题/命令 DTO、双状态机、序号与 revision、字面量及页面别名规则；补 OpenAPI 契约。
3. 用独立临时工作区和当前真实 CloakBrowser 完成最小采集切片：ready → start → input/click → stop → 已确认步骤。复用已有 provider/process 边界，禁止把试验代码挂入用户主流程。
4. 验证当前已加载文档、未来文档、跨域框架、导航前刷新和重复注入。脚本不使用页面存储作为唯一消息通道，不阻止页面操作。
5. 实现 schemaVersion 3 的读写兼容及 literalPaths；配置保存、模板引用、重命名、定位测试、起跑预检和快照比较一起覆盖。
6. 用最小正式 RecordingPanel 验证源事件身份、状态确认和截止序号，证实技术路线后再扩充动作。

退出验收：

- 含 `{中文变量}`、`${name}`、大括号 JSON 的录制值按原文往返；v1/v2 原流程行为不变，内存转换不制造未保存状态。
- 主页与嵌套跨域 frame 的真实 input/click 到达同一有限通道；重复注入、重复请求不重复记录。
- 正常导航前最后一次输入不丢；主动销毁上下文的不可确认末尾显示缺口，不能输出完整成功。
- 测试页点击计数与未录制时相同，证明未拦截、未额外触发业务动作。
- 若当前 binding/刷新方案无法通过，记录失败证据并调整设计后再进入 B，不以 mock 替代。

### B：补齐录制要生成的执行能力

工作：

1. 新增七种节点的目录、专用表单、保存/运行校验、变量引用、framePath、错误定位和执行器。
2. input_text 增加兼容默认 fill、可选 sequential 及 requiresValue；已有输入、空文本、append 行为保持。
3. 实现运行页面别名：创建、跟随唯一新页、切换、关闭、重复绑定校验；普通运行/Debug 使用同一执行器。
4. 增加 wait_page 的 URL/加载状态等待、同文档导航支持；导航观察不重复 goto。
5. 页面别名加入控制路径可用性分析；M5 顶层起跑在正常暂停页面面板补绑定，禁止假造已跳过的网页动作。
6. 每种新增元素动作接入 M3 拾取和测试；日志 executionId、loopPath、错误与停止沿原链路。

退出验收：

- **先手工编排**完成单/多选、勾选/取消、Enter 提交、滚动、弹窗及返回原页；没有录制器也能真实运行和 Debug。
- 原生表单与自定义控件区别明确；radio=false、缺目标、重复 option value、别名未产生/已关闭/冲突均准确失败。
- 嵌套 iframe 的选择/勾选/按键/容器滚动通过共享定位器；缺 frame 不回退。
- 导航/弹窗/逐字输入中可停止；节点统一超时，清理前不确认终态。
- 七种节点目录 runnable 与真实实现一致，无占位执行器。

### C：会话持久化、互斥与完整捕获

工作：

1. 在当前 head 后添加录制摘要、步骤与幂等命令迁移；大值放受管文件，确认游标和步骤原子提交。
2. 实现打开、页面准备、开始、暂停/继续、停止、关闭和历史查询。close 可以打断 start/pause/stop，不被普通过期修订号卡死。
3. 复用 Profile/内核使用锁，将录制加入 run/debug/inspection 的原子互斥和显式重启阻止判断。
4. 完成 input/IME、dblclick、原生 select/check、限定按键和滚动的合并；按 page/frame/epoch/段隔离。
5. 记录页面/框架生命周期、导航原因、popup opener、页面选择、关闭及完整性问题；不会仅依据时间差删除导航。
6. 完成当前文档/未来文档的被动脚本覆盖、源验证和有界缓冲；密码字段在页面侧生成待补值标记。

退出验收：

- 输入后立即 Enter、点击导致导航、中文输入、label 勾选、双击均没有重复业务步骤或末字丢失。
- 两个 origin 中相同 selector 不合并；页面无存储权限不使整个录制失效。
- 暂停恢复保留段边界；未记录的页面准备可见；停止后新点击不再进入该录制。
- 同 ID 同请求只启动一次；HTTP 响应丢失回查可恢复；异内容 409；清理前第二任务和资源删除被拒绝。
- 重开 Studio 已确认记录可见；sidecar 崩溃后只能审查 interrupted 记录，不自动继续采集。

### D：审查、生成与画布事务

工作：

1. 先交付 RecordingStepList、RecordingStepEditor、RecordingIssues、RecordingImportPreview、页面面板与组件测试，再组合 Studio。
2. 停止后允许修订、删除、排序、变量化和明确排除不支持动作；保存审查结果带 expectedRevision。
3. 纯转换器把固定 revision/cutoff 的步骤生成普通工作流片段；导航确认、页面别名、字面量、待补值和 sourceEventIds 可追溯。
4. generationId 的请求摘要/结果按录制修订记录复用，异内容 409；生成无工作流数据库写入。
5. 只在空流程或完整唯一顶层尾部应用；现有变量/别名冲突在预览中一次解决；语义摘要变化需重新预览。
6. 节点、边、变量与布局作为一次 editor 操作；幂等回调不重复插入，撤销/重做与手动保存保持。

退出验收：

- 录制期间编辑工作流不受污染；预览期间换文档/改连线/改变量的迟到响应不能覆盖草稿。
- 一次撤销恢复全部原图及变量；条件/循环整体之后可追加；块内目标、不完整尾部明确拒绝。
- 原文大括号与变量化输入各自按预期运行；待补密码没有被当作合法空输入执行。
- 修改步骤顺序/删除创建页面步骤会重新校验别名与导航依赖，不能生成表面通过的错误流程。
- 保存冲突不丢当前流程或录制草稿；已加入流程的数据不依赖随后被删除的录制文件。

### E：跨窗口保护、断线与容量

工作：

1. 录制中运行/Debug 接入“捕获与预检快照 → 确认停止并清理 → 提交快照”；用户取消时保持录制。
2. 扩展原离开协调，区分工作流保存与录制草稿；清理和捕获刷新的错误单独展示，不能一律显示已停止。
3. 完成非消费式步骤分页、审查 revision 游标、命令查询与去重；列表有界渲染，大值按需读取。
4. 测试磁盘写入失败、单值/步骤/总容量上限、源事件洪泛、frame 销毁、worker/sidecar 强制退出与清理重试。
5. 新增源码与冻结入口 smoke 脚本；复用当前受控网页、多 origin 和进程核验方式。

退出验收：

- 新建、打开、关窗、退出、换区分别覆盖保存/放弃/取消和保存失败；录制原文与未提交审查内容不被错误清除。
- 只关主窗口时继续采集；UI 断线不重启；显式重启服务在占用期间被阻止。
- 1,000 步审查、分页交界、跨页重复输入、超过 64 KiB 文本完整读取；到限不生成截断节点。
- 停止刷写超时说明缺口；清理失败仍持锁，重试完成后才释放；崩溃后无已确认动作重放。

### F：正式应用独立重放与验收收口

工作：

1. 使用正式 Studio 从空流程录制受控网页，审查、应用、保存、关闭原录制浏览器和应用；重新打开后运行。
2. 核对真实页面计数、表单值、选择结果、弹窗身份、iframe 结果和最终提取/截图；对照捕获步骤、生成节点和实际 executionId。
3. 对生成流程设置断点，单步七种新节点，修改运行输入，再核对网页结果；普通运行与 Debug 无第二套回放逻辑。
4. 运行 M1–M5 回归、工程检查、源码/冻结 sidecar、开发 URL/构建 HTML/正式 Electron 包入口。
5. 更新规格状态、差异表、总里程碑、验收矩阵和 .ai 决策；只把具有证据的场景标为通过。

退出验收：

- 原录制浏览器已清理，独立运行完成主闭环；不能用原会话里的既有页面状态充当重放成功。
- 真实嵌套跨域 iframe、开放 Shadow DOM、导航与多页路由均在正式应用有证据。
- 无阻塞缺陷；已知限制、暂未支持动作及未实测平台逐项记录。
- Windows/macOS 分别标记实机结果，macOS arm64 的通过不能代替 Windows 或 macOS Intel。

## 5. 验证与证据要求

每批执行对应局部测试，语义变更覆盖相关领域回归；最终执行：

- 后端 pytest、Ruff、mypy；迁移升级/历史读取、契约、仓储、worker 协议、资源锁和故障注入。
- 前端交互测试、TypeScript、ESLint；生成时竞态、一次撤销、断线、分页和离开保护。
- `npm run openapi:check`、`npm run test:structure`、`npm run test:scripts`、`npm run build`。
- `npm run backend:build`、`npm run package:dir`，以及新录制 smoke 和现有 M1–M5 smoke；检查实际包所含 renderer/main/preload 和冻结后端确为本轮构建。
- 真浏览器测试使用独立临时工作区和本地多 origin，禁止改用户现有流程、账号或第三方页面。

验收证据至少包括：环境与提交、启动入口、测试场景、录制 revision/cutoff、步骤/节点/执行映射、页面可核对结果、进程清理结果、失败与未测项。数据脱敏，不把真实输入秘密放入仓库。

本次仅文档校验，不执行这些业务测试，也不复用 M5 的通过记录为 M6 背书。不能在没有实现的情况下预填“通过”。

## 6. 依赖风险与后续路线

| 风险 | 验证/控制方式 |
| --- | --- |
| 事件在卸载前来不及确认 | A 先验证真实通道与屏障；异常记录 gap，禁止丢失后返回完整成功 |
| 自动导航与手动导航无法可靠区分 | 来源证据优先；歧义进入审查，不按时间阈值猜测 |
| 输入状态与逐字符行为不同 | 保持 fill 默认，sequential 明确选项；用联想/校验控件分别验收 |
| 录制原文触发模板 | v3 literalPaths 贯穿编辑/校验/执行/Debug，而非临时转义补丁 |
| 多页或后缀起跑缺上下文 | 稳定页面别名、控制路径预检、暂停时明确绑定，不用索引/最新页回退 |
| 功能范围膨胀 | 仅普通链生成和约定动作；复杂插入、拖拽/上传等明确留专项，不作为隐藏半成品入口 |

建议后续按能力组织，编号在各专项批准时确定：

1. 补齐录制剩余类型及相关网页动作：drag、upload/download、复杂键盘和更完整页面操作。
2. 子流程、输入输出、异常处理与可配置重试；特别明确重复网页副作用边界。
3. 双视图、分组注释和大流程编辑；保持同一文档与控制编译语义。
4. 全部核心差异收口和跨平台整体验收。

这些方向是待规划项，不因 M6 完成而被移除，也不沿用旧历史编号宣称完成。实施工期需要 A 的传输证据和 B 的节点工作量后才能估算，本文件不编造日历承诺。
