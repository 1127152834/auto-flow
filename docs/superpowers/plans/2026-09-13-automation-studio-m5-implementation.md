## 兼容与边界

工作流仍为schemaVersion2，断点为可选布局项，旧文档/日志/产物保持可读。0008是当前head后的增量迁移，不改写0005–0007；旧产物按原事件回填截止序号，缺少旧变量诊断显示真实空状态。

停止后的结束检查点只表示已确认的诊断；强制进程终止保留已有证据，不制造终结变量快照或重放网页动作。正常暂停无自动续跑期限，页面本身继续运行。

macOS arm64按实际运行记录验收；Windows/macOS Intel未实测，不计作通过。子流程、错误处理/自动重试、录制、双视图、分组注释及剩余动作仍未完成；M5不等于核心能力全量对齐。
