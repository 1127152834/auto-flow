## 4. 已知差异（逐条登记，不隐藏）

### 4.1 拉取卡主按钮文案 `拉取来源（含公式）` vs 原型 `检查新增`

原型把「检查」和「拉取」当作两步；冻结契约把它合成一个 `syncPull` 命令，命令本身同时完成新增行引入与公式列刷新。按钮沿用命令语义，避免出现没有后端动作的第二个按钮。

### 4.2 来源核对卡的内容不同

原型显示漂移摘要（`云端缺失 0 条` / `来源配置 未变化`）。冻结的 16 个 sheets 端点里**没有漂移汇总 DTO**，人为算一个数字会变成假事实。当前改为展示绑定事实（账号 / Spreadsheet / 工作表 / 映射字段 / 调度），全部来自真实返回值。

**这是本画板唯一未对齐的结构项。** 需要产品决定：要么补一个漂移查询契约，要么接受「来源核对」卡承载绑定事实。

### 4.3 字段映射的位置

`011` 把映射表放在右栏常驻；实施放在「调整绑定…」向导内，来源页改为 `映射字段 3 个，身份列 A` 一行摘要。原因是向导是唯一能校验身份与重叠映射的地方，常驻一份不可编辑的副本会与真实映射产生对不上的第二种说法。

## 5. 本轮截图发现的真实缺陷（已在同一轮修复）

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| 1 | `SheetsConnectionPanel` 表头用 `<TableHead><TableRow><TableCell>` | `<td>` 位于 `<thead>` 被浏览器提升出表头，5 个列名挤成一行无分隔文本 | 改为 `TableHeader`/`TableHead`（`th`） |
| 2 | `SheetsBindingWizard` 字段映射表同样嵌套错误 | 同上，`本地字段来源列方向公式` 连成一行 | 同上 |
| 3 | 账号表 `选择` 之后有一个无名列，数据行却在该列放按钮 | 出现空表头列，按钮列无标签 | 表头补 `操作` |
| 4 | 同步记录表尾列无名，已确认行渲染成空格 | 表格右侧像少了内容 | 表头补 `操作`，无动作时显示 `—` |
| 5 | 记录表把身份渲染两遍（业务编号列 + 记录身份列都显示 `001`） | 用户看到重复的 `001` | `showsDedicatedIdentityColumn`：身份字段可见时不再渲染独立身份列 |
| 6 | 来源页签原为单栏纵向堆叠 | 与 `100` 的两栏骨架不符 | 改为 `2fr / 1fr` 双栏 |
| 7 | 解绑确认渲染在页面末尾，脱离触发按钮 | 用户看不到确认属于哪个动作 | 移到按钮正下方 |

缺陷 1–4 属同一类：`<td>` 嵌在 `<thead>`。已在 `scripts/structure.test.mjs` 加一条仓库级结构断言，禁止再出现。
