## 真正运行的验收

三个场景均使用同一隔离构建 `/tmp/autoflow-uuid-build-Qiz4xl`，真实 Electron、FastAPI、隔离 SQLite；当前平台 macOS arm64，CDP 视口 1440×1024、DPR 1。26 张最终截图已逐图检查：业务标题、任务序号、冻结节点名、错误和确认状态均未出现测试资料中的内部 UUID 或八位截断形式。表格中保留的 UUID 明确属于用户业务字段，不认定为泄露。

- **runs：13 图。** UI 建项目、自动化，启动两个任务并核对 ordinal；真实 CloakBrowser 输入、点击、读取；目录、详情、日志、输入输出、证据、普通停止、强停及自然节点失败。失败截图内嵌加载和放大预览均验证。工作流与浏览器配置由正式服务作为夹具准备，没有用 Studio demo 冒充用户路径。
- **data：8 图。** UI 建系统表、字段、业务状态及记录；查看、编辑、状态、删除确认。业务字段身份表通过真实 Excel 检查、映射、导入建立；原生文件选择返回由 QA 定向到生成的测试文件，这一步单独标为适配层注入。没有直接修改数据库身份。
- **references：5 图。** UI 建项目；正式 HTTP 与 Idempotency-Key 准备历史失效资源引用；UI 打开环境、模型、代理和浏览器配置选项，检查语义文案及感知属性。
- **合成读取故障单独登记。** 一次用户刷新及其两次查询重试注入 HTTP 500，原错误带已知内部 ID；验证原列表保留、安全提示及 UI 重试恢复。自动化资源读取另有一次页面重载后的故障与重试恢复；该 E2E 没有宣称验证重载保留脏草稿，脏草稿由真实组件测试覆盖。它们不是自然后端故障。真实缺失选择器导致的节点失败另行记录。
- **强停进程故障单独登记。** 只暂停本次隔离 Electron 子树中唯一的 workflow worker，记录 PID 与启动时间；UI 正常停止并等待真实宽限期，再输入“强制停止”提交。确认同一进程已退出，随后新批次仍能运行。异常退出时仅恢复同 PID/启动时间的进程，不操作业务进程。

扫描范围为 `document.body.innerText`、title、placeholder、aria-label、aria-description 及已展开浮层。data-*、value、href/hash、网络字段和 React key 不在感知文本扫描范围。检查器只针对本次资料的明确内部身份；合法业务 UUID 只豁免其完整值所在范围，不会连带豁免同前缀技术短 ID。

每个原始报告的 `coverage: partial` 表示单场景范围，不宣称一个场景覆盖整个产品；三个场景与组件/后端契约共同构成此次验收。本次专项截图为 100% 缩放；200% 缩放仍列在用户待执行手测，不声称本轮执行。冲突、未知提交恢复、旧实例/工作区隔离由实际组件与既有回归验证；没有把合成测试称作新的完整手工或跨平台流程。
