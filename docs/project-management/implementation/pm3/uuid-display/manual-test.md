## 启动

打开终端，进入隔离构建副本。副本没有 .git，因此显式设置已记录的源码 HEAD，仅用于报告版本标识。三个场景应依次运行；完成一个场景并按 `Ctrl+C` 退出后，再启动下一个：

```bash
cd /tmp/autoflow-uuid-build-Qiz4xl
export UUID_SOURCE_HEAD=a5e7d48
node scripts/qa-project-uuid-flow.mjs --scenario data --manual
node scripts/qa-project-uuid-flow.mjs --scenario references --manual
node scripts/qa-project-uuid-flow.mjs --scenario runs --manual
```

每次启动成功后，终端会输出 `manual: true`、本次 `owner`、`workspace` 和 `evidence` 路径。先把这三个路径记入问题记录，再开始操作。Electron 中打开的项目名称分别为“UUID专项data”“UUID专项references”“UUID专项runs”。不要另行打开业务目录，也不要把业务工作区切换到测试窗口。

按 `Ctrl+C` 会关闭该次 Electron 和夹具服务器，但保留脚本创建的隔离工作区与证据目录，便于复核。脚本只写入报告所列的 `owner/workspace/evidence`，不会修改用户业务目录。
