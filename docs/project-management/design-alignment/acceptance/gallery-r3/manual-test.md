## 启动及测试资料

工作目录：`/Users/zhangtiancheng/Documents/projects/autoflow-project-management-implementation`。不要在主项目运行验收脚本。

```bash
npm run build
node scripts/qa-project-alignment-r3.mjs --manual
```

工具在系统临时目录创建专属标记的测试工作区，自动走真实UI初始流程，再保持应用与命令终端。它创建“R3架构验收 / 内容资料库二”，含标题、文章链接、日期、数字、布尔字段与一条用于竞争修改的合成记录；它还生成供文件向导使用的合成Excel。路径以终端实际输出为准，不要使用自己的业务文件。

测试者另通过界面建立“手测资料库”：项目→数据→新建数据表，名称“手测资料库”、说明“用户验收专用”；进入字段与校验，依次添加标题（title，文本，必填）、摘要（summary，文本，可选），每次点击“应用到草稿”；完成后点击外层“保存字段”→确认影响→“确认保存字段”。进入数据记录→新增记录，填写“温室光照管理笔记”和“测试记录”→保存到本地。

窗口缩放使用工具的 `zoom100` / `zoom200`；`shot` 保存当前画面，`service` 重启本次服务，`lost` 为下次字段提交武装一次响应丢失，`readerror` 注入字段读取失败，`restore` 撤销读取/响应测试注入。具体异常工具的作用域与实际结果以终端及run报告为准，均不新增生产调试接口。
