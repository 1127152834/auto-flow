## 启动与资料

在implementation工作区执行 `npm run build`，然后 `node scripts/qa-project-alignment-r1.mjs --manual`。等待“本地服务正常”，终端输出本次隔离工作区和截图目录。不得选择业务工作区。工具seed只提供分页边界资料；核心资料由下列UI操作创建。

1. 点击顶部“项目”→“新建项目”；名称输入“内容采集项目”，描述“自动采集与整理资料”，创建后返回目录。以同样步骤建立“客户跟进项目”。
2. 查看全部→先打开内容采集→返回→打开客户跟进→返回最近。预期客户跟进在前；卡片左图标/中间信息/右上更多；点击更多再编辑不得先进入项目。截图M01。
3. 终端输入seed；全部目录搜索R1分页，翻第二页，打开项目后返回。预期搜索、页码和位置保持。截图M02。
4. 打开内容采集→数据→新建数据表“资料库”；编辑描述后打开。新增文本字段“标题”，通过新增记录录入“温室管理清单”。预期卡片与数据均为真实保存；返回并重启后仍存在。截图M03。
5. 记录页打开筛选，添加标题包含温室后取消。列表不变。再次设置并应用，才生效。排序、显示列各重复取消/应用；关闭按钮、外点、Escape同样取消草稿。截图M04a/b/c。
6. 快捷搜索选标题，输入温室，不按Enter前不查；Enter后匹配。创建状态“已核对”并给一条记录设置，叠加此状态筛选；清空快捷搜索只移除文本条件。截图M05。
7. 按现有工具命令readerror注入读取失败，刷新应保留旧内容并报错，再刷新恢复；编辑项目时conflict制造真实竞争写入，保存后输入保留；lost注入提交后响应丢失，新建项目后核对结果，不能创建两个同名项目。截图M06。注入不是正常网络实测。
8. service重连、switch切工作区B再切A、restart重启；预期无串数据，原访问事实保留。此工具直接调用桥，只作恢复集成验证；设置界面的真实切换路径还须按设置→工作区→选择工具专用B目录→确认，反向切回，记录独立E1结果。截图M07。
9. zoom200后打开三个浮层，Tab/Enter可达、嵌套Select第一次Escape只关闭Select、第二次关闭浮层并回到按钮。主应用宽度不变，仅表格可横滚。zoom100恢复；对照B0检查卡片、页头、主按钮。截图M08。
10. 回归记录编辑、批量状态、真实Excel选择/导入/导出，随后检查浏览器、代理、模型、设置、Studio入口。不能用文件面板替身当原生面板通过。截图M09。

完整边界与导出断言见现有 [R1手测](../r1/manual-test.md)，每项必须同时登记业务结果和原图比对结果。清理用终端clean，仅清当前工具所有权目录；截图保留。quit退出但保留目录，禁止手动删除用户业务目录。
