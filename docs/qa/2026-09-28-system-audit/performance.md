# 真实仓库数据性能验证

- 日期：2026-09-28（Asia/Shanghai）；状态：confirmed，本机实测。
- 源码：`33ae3aa49600840b1700c83723408c494dc201a8`；正式 Python sidecar、TCP HTTP、真实临时 SQLite，未使用 mock、内存数据库或替代业务服务。
- 主机：Apple M2 Max，12 核，32 GiB 内存；macOS 26.4.1 arm64，Python 3.11.13。硬件与样本摘要见 [hardware-and-sample.json](performance/hardware-and-sample.json)。

## 结论

**8,504 条真实文件记录在本机完成正式批量写入、筛选、排序及全量分页，数据核对全部通过。** 每类查询重复 10 次；8,504 行时默认首页 P95 为 **32.826 ms**，按文件字节数排序首页 P95 为 **139.781 ms**。这支持当前样本规模的 API 可用性，不证明 10 万行、长时运行、UI 或多用户并发性能。

## 数据和执行方式

数据来自 `git ls-files -z` 枚举的当前仓库跟踪文件，并对每个真实常规文件执行 `stat`。实际数量为 **8,504**；没有复制数据凑到 10,000，没有编造业务行。保存三个实际字段：相对路径、扩展名、字节数。无扩展名文件保留实际空扩展名，因此该字段设为非必填。

在独立临时工作区启动正式 `python -m autoflow`，通过 `/api/v1/projects`、项目表/字段 API 建立表，再以每批最多 100 行的正式 `/records/batch` API 写入。先测前 1,000 条，再继续追加到全部 8,504 条。两个规模是同一 `git ls-files` 顺序的前缀，不是随机抽样：`.py` 文件分别为 676 和 999 条，筛选命中比例不同。

每次读返回 200 条记录，验证总数、实际字段值、筛选成员、无页内重复、数值降序及页长度；额外遍历所有页面，独立对照采集清单，验证完整集合无漏行、无重复和字段完全一致。每档 5 类 × 10 次计时读，总计 **100 次计时读**；另有 10 次首次观察读和 48 次完整分页读，最终运行总计 **158 次查询请求**。

计时覆盖 HTTP 请求到完整响应体收取，包含服务端、SQLite 和本机传输，排除客户端 JSON 解码及断言。使用持久 HTTP 客户端；先单独记录首次观察，再记录 10 次重复读。P50/P95 采用 nearest-rank：10 个样本的 P95 等于最大值，不能视为充分收敛的长期尾延迟。未清空 OS 文件缓存，不将首次观察称为冷缓存测量。

## 最终测量

单位：毫秒；每个单元格为 **P50 / P95**。

| 查询场景 | 1,000 行 | 8,504 行 |
|---|---:|---:|
| 默认顺序首页 | 16.540 / 17.936 | 31.624 / 32.826 |
| 文件字节数降序首页 | 40.180 / 41.781 | 136.831 / 139.781 |
| 扩展名 `.py` 筛选首页 | 21.673 / 133.214 | 60.644 / 62.319 |
| `.py` 筛选 + 字节数降序 | 35.686 / 38.209 | 79.963 / 81.705 |
| 默认顺序末页 | 18.564 / 19.500 | 73.833 / 75.257 |

1,000 行 `.py` 筛选有一次 133.214 ms 观测，其余样本见原始结果；未剔除该值。此测试与同会话其他 QA 工作共享主机，未测量独占 CPU/磁盘条件，因此不把该离群点直接归为生产缺陷。

| 持久写入/完整分页 | 结果 |
|---|---|
| 前 1,000 行，10 个批请求 | HTTP 耗时合计 488.746 ms；批请求 P50 49.034 ms，P95 50.610 ms |
| 后续 7,504 行，76 个批请求 | HTTP 耗时合计 4,545.423 ms；批请求 P50 56.572 ms，P95 72.447 ms |
| 全部 8,504 行，86 个批请求 | HTTP 耗时合计 **5,034.169 ms**；最后一批为 4 行；不含项目/表/字段初始化 |
| 1,000 行全量分页 | 5 页，1,000 个唯一路径，与实际采集清单完全一致 |
| 8,504 行全量分页 | 43 页，8,504 个唯一路径，与实际采集清单完全一致 |

8,504 行排序查询较默认首页更慢，与现有 JSON 投影/自定义排序实现相符。当前数据没有显示必须立即替换 SQLite 或引入缓存；应先确定实际业务预算，再对更大的真实样本和并发负载复验。
