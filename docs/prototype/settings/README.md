# 设置页高保真原型

- 日期：2026-09-12
- 状态：confirmed；用户已授权自主设计与开发。当前实现与验证见[实施状态](../../migration/settings-dashboard-status.md)。
- 范围：旧设置页的能力迁移，以及三项新增建议。三张图片属于同一个方案。

## 查看原型

| 画板 | 内容 |
| --- | --- |
| [常规](./settings-general.png) | 服务状态、重启、连接详情、本地数据、缩放与动效偏好、保存成功提示 |
| [工作区与切换流程](./settings-workspace-flow.png) | 当前目录、四类文件位置、切换和切回、目标确认、切换中、失败已恢复、任务占用、目录错误 |
| [关于与诊断导出](./settings-about-diagnostics.png) | 版本、平台、运行环境入口、本地诊断预览和保存、成功/失败、macOS 与 Windows 退出差异 |

沿用已确认的暖灰、黏土棕与 shadcn/ui 组件风格。应用级顶部导航只有一个设置入口；设置内部采用“常规 / 工作区 / 关于”水平页签，不增加侧栏。组合画板中的弹窗与状态是不同时间点，不能同时叠加成真实页面。

## 保留和新增

保留旧版的本地服务重启、本地数据说明、工作区目录管理、切换/切回、版本与运行环境信息和退出入口。旧版工作区校验、占用预检和回滚逻辑作为能力依据，但不兼容旧版数据。

| 新增提案 | 用途 | 实现边界 |
| --- | --- | --- |
| 界面缩放 | 适应不同显示器与阅读习惯 | 90% / 100% / 110% / 125%，即时生效并保存在本机；已接入主进程并测试持久化/失败回滚 |
| 减少动效 | 允许用户控制弹窗与加载动效 | 跟随系统 / 减少动效 / 完整动效；已接入本机偏好与系统媒体查询 |
| 导出诊断包 | 排查本地启动与服务故障 | 默认白名单基础信息、状态与错误码；日志默认不选，预览后本地保存；已实现白名单 JSON 预览/原生保存；可选日志仅含当前会话结构化生命周期事件 |

工作区选择目标后的二次确认是新增交互；旧版没有该确认。重启和切换的占用保护需要覆盖新系统当前执行器，不能把旧版仅有的内核任务检查当作已完成。状态为未知或恢复失败时，不能显示“已恢复”或“运行正常”。

macOS 沿用新应用当前“关闭窗口后仍保留进程”的行为；Windows 关闭最后一个窗口会退出。页面文案按平台展示，不新增行为切换开关。
