# 代理管理模块交互与状态基准

- 日期：2026-09-12
- 状态：proposed；“即将到期”与远程聚合指标受 live contract/capability flag 约束
- 来源：[ProxyPanel 首页](https://proxypanel.io/home)、[ProxyPanel Developers](https://proxypanel.io/developers)、[ProxyPanel 旧版 API 文档](https://proxypanel.io/documentation)

总览图中的“即将到期”和“总代理”是已具备对应字段时的条件画板；运行时默认遵循 capability flag：到期字段未验证时隐藏或显示“到期信息不可用”，总量未确认时显示“已同步 N 个”。

## 1. 页面信息架构

代理管理使用一个主内容区，不增加页面内侧栏。

顶部区域是 ProxyPanel 连接状态：

- 连接名称和账号；
- 已连接/未连接/验证失败；
- 最近同步时间；
- 刷新代理；
- 连接设置。

页面先读取 connection capabilities；未达到 `fixture-verified` 的 Provider 操作不渲染可提交按钮，只显示“当前 API 未提供此能力”。

摘要区域显示可验证的运行中、异常和已同步数量；“即将到期”只有 API 返回明确截止时间并通过 fixture 验证时才显示，否则显示“到期信息不可用”或隐藏。

主体是 ProxyPanel 代理舰队表格，底部是 AutoFlow 本地代理组。ProxyPanel 远程代理舰队和本地代理组必须使用不同的视觉标签，避免用户误以为本地代理组是 ProxyPanel 远程对象。

## 2. ProxyPanel 连接

### 连接设置弹窗

字段：

- 连接名称；
- API Key；
- API Key 显示/隐藏；
- 连接说明。

行为：

- API Key 只写入 CredentialStore，SQLite 只记录 `secret_ref` 和 `hasSecret`；
- 验证按钮不能用换 IP 作为验证，因为换 IP 是有副作用且受频率限制；
- 优先调用无副作用的认证/状态接口；
- 验证成功后拉取代理列表和地点目录；
- 失败时显示可读错误，不显示 API Key、完整请求 URL 或原始 Token；
- 保存中显示“正在验证…”并禁止重复提交。

## 3. 代理舰队表格

表格列：

- 代理名称；
- 状态：运行中、待启动、异常、未激活；“即将到期”只有有明确 `subscription_expires_at` 时才显示；
- 运营商；
- 城市；
- 出口 IP；
- 延迟；
- 轮换策略；
- 关联配置数量；
- 行操作菜单。

筛选：

- 搜索代理名称、城市、出口 IP、运营商；
- 状态；
- 运营商；
- 城市。

行操作：

- 查看详情；
- Change IP；
- 改变地点；
- 轮换设置；
- 凭据与白名单；
- 健康检查；
- 关联浏览器配置。

不提供任意外部代理的“添加代理”表单。代理来自 ProxyPanel `GET /api/v1/proxies`，本地只允许修改显示名称、启用状态、关联信息和编排关系。

## 4. 代理详情 Drawer

详情抽屉不作为第二页面，只从表格行打开。

### 概览

- ProxyPanel 代理状态；
- 当前城市和运营商；
- 出口 IP；
- HTTP 端点；
- SOCKS5 端点；
- 最后检测时间；
- 延迟和丢包摘要；
- 测试连接。

复制端点时显示短暂 Toast；密码只通过 sidecar 受控复制，不进入 renderer、日志或诊断导出。

### 位置与轮换

轮换模式：

- 同城轮换；
- 随机城市；
- 保持运营商；
- 不轮换。

轮换间隔使用下拉选择。后端强制执行 ProxyPanel 的最小轮换间隔，UI 在保存前给出明确错误。

提供：

- 更换 IP；
- 改变地点；
- 保存轮换计划；
- 取消轮换计划。

### 凭据与白名单

- HTTP/SOCKS5 端点展示；
- 用户名复制；
- 密码不进入 renderer；提供由 sidecar 读取凭据并写入系统剪贴板的“复制密码”操作，轮换仍需确认；
- IPv4 白名单启用/禁用；
- 白名单新增、删除、替换；
- 每代理最多 16 个 IPv4 的限制在表单中提前提示。

控制面 API Key 和数据面代理密码分开保存，不能共用一个字段。

### 用量

显示当前代理的用量摘要和时间范围筛选。若 API 没有返回完整用量数据，显示“暂无用量数据”，不伪造图表。

## 5. 改变地点弹窗

从详情抽屉打开。

- 城市搜索；
- 运营商筛选；
- 地点列表；
- 当前城市标记；
- 延迟/可用性摘要；
- 取消；
- 切换地点。

切换地点是有副作用操作，按钮提交期间锁定。成功后刷新代理详情和表格行，显示“位置已切换”。失败保留弹窗输入，并显示服务端可读错误。

## 6. Change IP

点击“更换 IP”后显示确认提示：

- 当前出口 IP；
- 操作可能导致当前浏览器会话短暂重连；
- 当前代理有轮换频率限制；
- 取消 / 确认更换。

提交后显示“正在更换 IP”，完成后更新出口 IP、位置状态和检测时间。

## 7. 本地代理组

本地代理组是 AutoFlow 的编排实体，不是 ProxyPanel 的远程对象。

- 组名；
- 成员代理；
- 成员顺序；
- Round Robin 游标；
- 关联浏览器配置数量；
- 成员健康摘要。

成员弹窗支持勾选、上移、下移和保存。加入异常或未检测代理时，第一次保存只显示风险确认，第二次才提交。

## 8. 状态、错误和动效

- 页面加载：摘要和表格显示 Skeleton；
- ProxyPanel 未连接：显示连接提示和连接设置按钮；
- 代理列表错误：保留旧数据并显示刷新操作；
- 单代理健康检查：行内显示旋转图标和“检测中”；
- API 429：显示频率限制和 Retry-After，不自动高频重试；
- 连接超时、认证失败、DNS 失败：显示友好错误，并提供展开的技术详情；
- 位置切换/换 IP/轮换保存成功：Toast 150ms 淡入，2.6 秒后淡出；
- 详情 Drawer：150ms 淡入并轻微横向进入；
- 健康状态刷新：300ms 过渡，不使用大幅位移。

所有写操作在进行中禁用重复提交；危险操作确认框默认聚焦“取消”；支持 Escape 关闭和键盘完成主要流程。

## 9. 不纳入本模块

- 其他代理供应商；
- 任意代理手工创建；
- ProxyPanel 远程代理池 CRUD；
- 购买、续费和支付流程；
- 账户团队管理；
- 项目管理、模型管理和浏览器内核页面。
