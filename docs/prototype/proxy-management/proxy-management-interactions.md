# 代理管理模块交互与状态基准

- 日期：2026-09-12
- 状态：proposed；“即将到期”与远程聚合指标受 live contract/capability flag 约束
- 来源：[ProxyPanel 首页](https://proxypanel.io/home)、[ProxyPanel Developers](https://proxypanel.io/developers)、[ProxyPanel 旧版 API 文档](https://proxypanel.io/documentation)

总览图中的“即将到期”和“总代理”是已具备对应字段时的条件画板；默认到期字段未验证时隐藏，总量未确认时显示“已同步 N 个”。图中的丢包率、地点延迟和固定 60 秒限制不作为开发依据。行为以[设计方案](../../superpowers/specs/2026-09-12-proxy-management-design.md)和[API 契约](../../references/proxypanel-api-contract.md)为准，本文保留视觉与交互索引。

## 1. 页面信息架构

代理管理使用一个主内容区，不增加页面内侧栏。

顶部区域是 ProxyPanel 连接状态：

- 连接名称和账号；
- 已连接/未连接/验证失败；
- 最近同步时间；
- 刷新代理；
- 连接设置。

页面读取服务端 capabilities；未核验的操作隐藏或禁用并解释原因。当前没有 live fixture，人工样例只测试 UI，不证明 Provider 能力。

摘要区域显示可验证的运行中、异常和已同步数量；“即将到期”只有 API 返回明确截止时间并通过 fixture 验证时才显示，否则显示“到期信息不可用”或隐藏。

主体是 ProxyPanel 代理舰队表格，底部是 AutoFlow 本地代理组。ProxyPanel 远程代理舰队和本地代理组必须使用不同的视觉标签，避免用户误以为本地代理组是 ProxyPanel 远程对象。

## 2. ProxyPanel 连接

### 连接设置弹窗

字段：

- 连接名称；
- API Key；
- API Key 显示/隐藏；
- 连接说明。

行为：

- API Key 首次输入/替换短暂存在 renderer 表单内存，提交/关闭后清空；CredentialStore 使用系统凭据存储，SQLite 只记录 secret_ref/has_secret；
- 验证按钮不能用换 IP 作为验证，因为换 IP 是有副作用且受频率限制；
- 优先调用无副作用的认证/状态接口；
- 验证成功后拉取代理列表和地点目录；
- 失败时显示可读错误，不显示 API Key、完整请求 URL 或原始 Token；
- 保存中显示“正在验证…”并禁止重复提交。

## 3. 代理舰队表格

表格列：

- 代理名称；
- 远程状态与本地健康分开显示；未知值显示未知。“即将到期”是单独的条件标签，不与运行状态互斥；
- 运营商；
- 城市；
- 出口 IP；
- 延迟；
- 轮换策略；
- 关联配置数量；
- 行操作菜单。

筛选：

- 搜索代理名称、城市、出口 IP、运营商；
- 状态；
- 运营商；
- 城市。

行操作：

- 查看详情；
- Change IP；
- 改变地点；
- 轮换设置；
- 凭据与白名单；
- 健康检查；
- 关联浏览器配置。

不提供任意外部代理的“添加代理”表单。代理来自 ProxyPanel `GET /api/v1/proxies`，本地只允许修改显示名称、启用状态、关联信息和编排关系。

## 4. 代理详情 Drawer

详情抽屉不作为第二页面，只从表格行打开。

### 概览

- ProxyPanel 代理状态；
- 当前城市和运营商；
- 出口 IP；
- HTTP 端点；
- SOCKS5 端点；
- 最后检测时间；
- HTTPS 探测耗时；移除未经测量的丢包率；
- 测试连接。

复制成功才显示 Toast；密码经受限 preload IPC 由 Electron main 从 host-only sidecar 端点读取并写入剪贴板，不进入 renderer、日志或诊断导出。

### 位置与轮换

轮换候选模式（仅启用真实契约已核验的选项）：

- 同城轮换；
- 随机城市；
- 保持运营商；
- 不轮换。

轮换间隔使用下拉选择，选项/上下限来自已核验的 constraints；未验证时禁用提交，不混用旧 API、自动轮换与 one-hit URL 的限制。

提供：

- 更换 IP；
- 改变地点；
- 保存轮换计划；
- 取消轮换计划。

### 凭据与白名单

- HTTP/SOCKS5 端点展示；
- 用户名复制；
- 密码不进入 renderer；“复制密码”由受限 Electron main IPC 完成，轮换需确认；
- IPv4 白名单启用/禁用；
- 白名单新增、删除、替换；
- 上限来自已核验 constraints；文档所示 16 条仍须与当前 API 请求核验。

控制面 API Key 和数据面代理密码分开保存，不能共用一个字段。

### 用量

显示当前代理的用量摘要和时间范围筛选。若 API 没有返回完整用量数据，显示“暂无用量数据”，不伪造图表。

## 5. 改变地点弹窗

从详情抽屉打开。

- 城市搜索；
- 运营商筛选；
- 地点列表；
- 当前城市标记；
- 当前 API 确认的可用性；没有地点延迟数据时不显示延迟；
- 取消；
- 切换地点。

切换地点提交期间锁定；202 只显示正在处理，核验最终位置后显示“位置已切换”。失败保留输入；结果不明时刷新查询，不自动重发。

## 6. Change IP

点击“更换 IP”后显示确认提示：

- 当前出口 IP；
- 操作可能导致当前浏览器会话短暂重连；
- 当前代理有轮换频率限制；
- 取消 / 确认更换。

提交后显示“正在更换 IP”，最终完成后更新出口 IP、位置状态和检测时间；结果不明时保留待核验提示。

## 7. 本地代理组

本地代理组是 AutoFlow 的编排实体，不是 ProxyPanel 的远程对象。

- 组名；
- 成员代理；
- 成员顺序；
- Round Robin 游标；
- 关联浏览器配置数量；
- 成员健康摘要。

成员弹窗支持勾选、上移、下移和保存。加入异常或未检测代理时，第一次保存只显示风险确认，第二次才提交。

## 8. 状态、错误和动效

- 页面加载：摘要和表格显示 Skeleton；
- ProxyPanel 未连接：显示连接提示和连接设置按钮；
- 代理列表错误：保留旧数据并显示刷新操作；
- 单代理健康检查：行内显示旋转图标和“检测中”；
- API 429：有有效 Retry-After 时显示倒计时，没有时提示稍后手动重试，不编造冷却秒数；
- 连接超时、认证失败、DNS 失败：显示友好错误，并提供展开的技术详情；
- 位置切换/换 IP/轮换保存成功：Toast 150ms 淡入，2.6 秒后淡出；
- 详情 Drawer：150ms 淡入并轻微横向进入；
- 健康状态刷新：300ms 过渡，不使用大幅位移。

写操作发送中禁用重复提交；危险确认框默认聚焦取消且发送中不可关闭。受理后详情可关闭，关闭查看不取消远程命令。共享弹窗支持 Escape、焦点回归和 reduced-motion。

## 9. 不纳入本模块

- 其他代理供应商；
- 任意代理手工创建；
- ProxyPanel 远程代理池 CRUD；
- 购买、续费和支付流程；
- 账户团队管理；
- 项目管理、模型管理和浏览器内核页面。
