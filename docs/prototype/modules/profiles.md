# 浏览器配置原型

## 主流程
左侧资源列表切换全部/已启用/草稿，右侧显示表格。新建和编辑使用同一套详情表单，基本设置、指纹与环境、代理设置、高级选项使用 Tabs。复制从详情页打开确认弹窗并自动追加“副本”。

## 表单
名称和启动地址必填；端口、视口、时区、语言提供即时校验；提交期间按钮 loading。修改后离开页面弹出未保存确认。

## 弹窗和危险操作
删除使用 AlertDialog，默认焦点为取消；确认后关闭详情并显示“配置已删除”。批量删除显示影响数量。

## 状态
加载 Skeleton、无配置 EmptyState、API 错误 ErrorState；列表请求失败保留筛选条件，支持重试。成功创建/编辑显示 Toast 并定位新资源。
