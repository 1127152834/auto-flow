# 内核管理高保真原型基准

参考来源：旧项目 `src/renderer/pages/KernelPage.tsx` 及实际运行页面。

## 必须保留的功能

- CloakBrowser License：License Key、验证并登录、已登录状态、套餐、到期时间、会话数、退出登录。
- 默认内核：只用于新工作流预选；显示当前默认项，支持取消默认和设为默认。
- 发布列表：刷新发布列表、Wrapper 版本、已安装数量。
- 筛选标签：全部版本、公开版、正式版、已安装。
- 版本卡片：版本、Chromium 版本、Stable/Preview、公开版/正式版、已安装/默认内核、发布日期、安装包大小。
- 操作：下载安装、重试下载、设为默认、打开目录、删除。

## 状态和交互

- License 未登录：正式版下载按钮显示“需要 License”，登录后才可下载。
- 下载中：卡片内显示阶段、百分比、消息和原生 progress；按钮禁用，不能重复下载。
- 下载失败：卡片内显示“下载失败：原因”和“重试下载”。
- 删除：AlertDialog 标题为“删除浏览器内核”，说明版本和可能的引用影响，按钮为“取消 / 确认删除”。
- 默认内核读取失败：顶部显示可重试提示；已保存配置不随默认项变化。
- 发布列表失败：保留已安装版本管理能力，并显示“发布列表刷新失败”的提示。

## 视觉约束

- 以旧项目暖灰工作台为基准，优化层级和密度，不改变功能语义。
- 不出现 Firefox、Safari、Chrome 多品牌管理，不出现通用浏览器市场概念。
- 主要动效：150ms 面板进入、300ms 进度变化、Toast 淡入淡出；不使用大幅位移动效。
