# 浏览器管理模块交互与状态基准

## 1. 页面结构

应用级导航保留总览、浏览器配置和设置等入口；浏览器配置页面内部只有一个主内容区，不再增加页面级侧栏。

主页面包含：

- 页面标题“浏览器配置”；
- “新建配置”主按钮；
- 搜索和配置筛选；
- 双列配置卡片，窄窗口单列；
- 配置字段：名称、描述、指纹种子、CloakBrowser 内核、语言/时区、代理模式；
- 打开测试浏览器、编辑、复制、重置指纹、删除操作。

### 配置卡片与临时测试（2026-09-12，confirmed）

来源：用户后续明确要求。配置是参数模板，不是持久化浏览器实例；项目环境由后续模块定义。

- 卡片内突出名称和指纹种子，保留内核、语言/时区、代理模式并显示视口。
- 种子右侧“重置指纹”：请求中图标旋转、禁止重复提交；成功后直接显示服务端新种子，Toast 展示旧值 → 新值及“下次打开测试浏览器时生效”。已打开窗口不受影响。
- 主按钮“打开测试浏览器”：读取已保存配置，每次新建独立临时会话；启动中显示“正在打开…”，其他卡片仍可操作。
- 每份配置仅一个测试浏览器：成功后按钮切换为“关闭浏览器”；点击后显示“正在关闭…”，待进程回收完成再恢复打开。启动失败在本卡显示原因，不自动重试。
- 手动关窗或异常退出由后端检测；前端每秒同步状态，页面切换/刷新同样恢复运行态。运行时禁用删除配置；不同配置可独立操作。
- 状态查询失败时保留上次状态，禁用启动/关闭并显示重试同步；关闭失败不假装已关闭。
- 起始网址加载失败时，明确提示测试窗口已打开但页面加载失败。
- 测试使用可见窗口，不改变保存的无头模式字段。关闭后不保留 Cookie、登录状态或浏览历史；不创建项目环境实例。
- 离线禁用写入与启动；不因重连自动再次启动浏览器。

## 2. 新建/编辑配置弹窗

使用大尺寸 Modal，不跳转路由。编辑和新建复用同一表单。

### 基础信息

- 名称：必填，最多 120 个字符；
- 描述：可选；
- 起始网址：校验 URL 格式。

### 浏览器环境

- 浏览器语言：预设或 BCP 47 自定义值；
- 浏览器时区：预设或 IANA 时区自定义值；
- 浏览器视口：常用桌面预设；
- 自定义尺寸：宽 320–7680，高 240–4320；
- 色彩模式；
- 人类行为预设：标准/谨慎；
- User Agent：跟随内核预设或手动输入。

### 内核与代理

- 浏览器内核：只显示已安装 CloakBrowser 版本；
- 内核下拉框右侧显示“管理内核”按钮；
- 发布通道：正式版支持 Stable/Preview，公开版固定 Stable；
- 代理模式：不使用代理、固定代理、代理池；
- 无头模式、GeoIP、人类行为模拟。

### 高级选项

- 扩展目录；
- Chromium 启动参数；
- 每行一个路径或参数；
- 展开后显示填写示例和说明。

### 表单行为

- 未选择内核时阻止保存，并将焦点移动到内核选择框；
- 保存中按钮显示“正在保存…”并禁用重复提交；
- 关闭有修改的表单时显示未保存确认；
- 创建成功 Toast：“配置已创建”；
- 编辑成功 Toast：“配置已保存”。

## 3. CloakBrowser 内核管理弹窗

点击“管理内核”后打开大尺寸 Modal/Drawer，不能跳转到独立内核页面。

### License 区域

- License Key 密码输入；
- “验证并登录”；
- 登录成功显示账号、套餐、到期时间和会话数；
- “退出登录”；
- 正式版未登录时，下载按钮显示“需要 License”。

### 版本筛选与信息

- 全部版本、公开版、正式版、已安装；
- Wrapper 版本；
- 已安装数量；
- “刷新版本列表”；
- 发布列表刷新失败时保留已安装版本管理，并显示错误提示。

### 版本卡片

显示 CloakBrowser 版本、Chromium 版本、Stable/Preview、公开版/正式版、发布日期、安装包、大小和已安装/默认状态。

2026-09-12 补充（confirmed，用户后续要求）：正常桌面宽度采用双列卡片，窄窗口采用单列。版本摘要显示后端识别的当前平台，不由前端选择或拼接下载包。不同版本可并行下载；请求等待、失败重试和取消分别属于各自卡片。同 edition/version 共用安装目录，不能因通道不同重复并发安装。某个版本下载中不禁用其他版本的下载按钮；筛选或目录失效时仍保留活动任务的取消入口。

操作包括：

- 下载安装；
- 重试下载；
- 设为默认；
- 取消默认；
- 打开目录；
- 删除。

## 4. 配置操作弹窗

### 复制浏览器配置

- 标题：“复制浏览器配置”；
- 显示复制来源；
- 输入新配置名称；
- 名称为空、超过 120 字符或冲突时在字段下方显示错误；
- 按钮：“取消 / 创建副本”；
- 提交中显示“正在复制…”；
- 成功 Toast：“配置已复制”。

### 删除浏览器配置

- 标题：“删除浏览器配置”；
- 显示目标名称；
- 说明此配置将永久删除且不可撤销；
- 默认焦点为“取消”；
- 按钮：“取消 / 确认删除”；
- 成功 Toast：“配置已删除”。

### 删除浏览器内核

- 标题：“删除浏览器内核”；
- 显示 CloakBrowser 版本；
- 说明会删除本地文件，操作不可恢复，并提示检查引用；
- 默认焦点为“取消”；
- 按钮：“取消 / 确认删除”。

## 5. 状态画板

- 加载：Skeleton 或“正在同步本地数据，请稍候…”；
- 空态：还没有浏览器配置，显示“创建第一份浏览器配置，再打开临时窗口验证效果”；
- 列表错误：显示错误原因和重试；
- 内核下载：显示准备下载、下载中、安装中和百分比；
- 内核失败：显示失败原因和“重试下载”；
- License 未登录：正式版卡片显示锁定说明；
- 指纹重新生成：图标 300ms 旋转，完成后显示成功 Toast；
- 保存/复制/删除：成功 Toast 150ms 淡入，2.6 秒后淡出；
- sidecar 断线：页面顶部显示本地服务离线提示，恢复后由用户手动重试保存。

## 6. 动效与可访问性

- Modal/Drawer 150ms 淡入并轻微上移，不超过 8px；
- 下载进度 300ms linear；
- 弹窗支持 Escape 和遮罩关闭；
- 提交、删除、下载进行中禁止关闭；只防止同一安装目标重复提交，不阻止其他版本并行下载；
- 危险确认框默认聚焦取消；
- 错误使用 `role=alert`，进度使用 `role=status`；
- 表单字段错误与控件关联，键盘可以完成完整流程。
