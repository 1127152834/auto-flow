## 1. 已确定的原型方向

本轮不再提供布局 1/2/3 供选择。此前的顶部供应商 Tabs、全宽供应商分组和统一模型目录三个候选全部废弃，因为它们都改变了旧项目的主从关系。

当前原型固定复用以下结构：

1. 页面顶部为 AutoFlow 应用级导航和“模型管理”页头；页头右侧提供“添加供应商”。
2. 页头下方是一个完整工作台卡片，桌面宽度下采用 `278px + 自适应内容区` 的双栏布局。
3. 左栏是供应商资源栏；右栏只显示当前选中供应商的详情及其模型目录。
4. 供应商通过左栏纵向列表切换，不使用横向 Tabs。
5. 模型编辑使用大尺寸 split Modal：左侧摘要与测试，右侧设置表单。
6. 供应商新增和编辑使用大尺寸居中 Modal；新增显示横向三步指示，编辑直接进入连接信息，仍保留旧三步指示并高亮当前步；步骤指示不作为导航。

## 2. 主页面布局

### 2.1 供应商左栏

左栏固定为 278px，包含：

1. 标题“供应商”、供应商总数和右侧加号按钮。
2. “搜索供应商”输入框。
3. 纵向供应商列表。每项显示供应商 Logo、名称、本地模型数量和连接状态点。
4. 当前项使用左侧黏土色竖线和浅色背景标识。
5. 点击供应商项切换右侧详情，并清除上一供应商遗留的本次模型测试反馈。

没有供应商时显示“尚未配置模型供应商”，说明“添加供应商并验证连接，再从远端目录选择或手动添加模型”，并提供“添加供应商”。供应商搜索无结果时只显示“没有匹配的供应商”。

### 2.2 当前供应商详情

右栏从上到下依次为：

1. 供应商身份区：Logo、名称、连接状态 Badge、说明、最后检查时间。
2. 右上操作：“测试连接”“编辑”和更多菜单。
3. 更多菜单：启用/停用供应商、删除供应商。
4. 三列连接事实：接口协议、服务地址、访问凭据是否已配置。
5. 最近一次连接测试或操作反馈 `FeedbackCard`。
6. 模型目录标题和操作：“同步并添加”“添加模型”。
7. 模型搜索、状态筛选和“当前结果数 / 供应商模型总数”。
8. 模型表格：模型、标签、上下文、状态、操作。

“同步并添加”与“添加模型”都打开添加模型 Modal；前者额外使供应商发现目录缓存失效，从而重新读取远端候选。它不会自动覆盖、停用或删除本地模型。

每个模型行直接提供“测试”按钮；更多菜单提供“编辑模型”、启用/停用模型和“删除模型”。菜单按 Escape 后关闭并把焦点还给菜单触发按钮；选择菜单项后菜单关闭。

## 3. 供应商新增流程

新增供应商使用居中大尺寸 Modal。顶部横向显示“选择供应商 / 连接信息 / 选择模型”三步状态；它们是不可点击的步骤指示，不是页面 Tabs。

### 3.1 第一步：选择供应商

- 内容：供应商搜索、常用供应商卡片、自定义 OpenAI 兼容接口卡片、当前预设摘要。
- 默认选择 DeepSeek。
- 选择另一预设会替换供应商名称、预设 ID、协议、默认 Base URL、API Key、启用状态和说明。
- 底部按钮：“取消”“下一步”。
- “取消”关闭 Modal；“下一步”进入连接信息，不发请求。
- 打开此步后，供应商目录搜索框获得焦点。

### 3.2 第二步：连接信息

- 字段：供应商名称、接口协议、服务地址、API Key、说明、“启用供应商”。
- 名称和 Base URL 必须非空。
- API Key 是否必填由预设决定；Ollama 和自定义 OpenAI 兼容接口允许留空。
- 底部按钮：“上一步”“取消”“测试连接”。
- “上一步”返回供应商选择并保留当前会话里的表单。
- “取消”关闭 Modal 并丢弃未保存内容，不增加未保存确认。
- “测试连接”读取供应商模型目录，不发起模型推理。
- 测试进行中禁用重复提交并锁定 Modal。
- 测试失败留在本步，显示内联错误，并保留全部输入，不创建供应商。
- 测试成功进入第三步，显示连接成功、消息、单次耗时和发现模型。

### 3.3 第三步：选择模型

- 内容：连接成功反馈、模型搜索、“选择全部/取消全选”和可多选的远端模型列表。
- 每项显示显示名称、模型 ID 和远端明确返回的上下文长度；缺失时显示“上下文长度未知”。
- 底部按钮：“修改连接”“取消”“保存供应商”或“保存供应商和 N 个模型”。
- “修改连接”返回第二步并清除当前发现结果；重新测试成功后重新生成候选并清空选择。
- “取消”关闭 Modal 并丢弃当前接入草稿，不增加未保存确认。
- 不提供单独的“跳过”按钮；零模型选择时，“保存供应商”就是旧实现的跳过模型行为。
- 保存期间锁定 Modal；保存成功后关闭并刷新供应商列表。

最终保存会再次读取远端模型目录，再原子保存供应商和所选模型。若某个所选模型已不在最新目录中，整体失败，不显示部分成功。

## 4. 供应商编辑

从右侧供应商头部的“编辑”按钮进入。编辑复用同一个大尺寸 Modal，但直接显示连接信息，不显示预设选择，也不进入模型选择步骤。

内部连接签名比较预设 ID、接口协议、Base URL、API Key；编辑界面不提供更换预设入口，因此用户可触发连接变化的字段是接口协议、Base URL 和 API Key。

- 只修改名称、说明或启用状态：主按钮为“保存修改”，直接保存，不重新测试连接。
- 修改接口协议、Base URL 或 API Key：主按钮立即变为“测试并保存”，保存前通过连接更新接口验证新配置。
- 连接保存失败：保留当前表单和错误，不覆盖旧持久配置。
- “取消”、右上关闭、Escape 或点击遮罩：关闭并丢弃未保存编辑，不增加未保存确认。
- 保存进行中：锁定 Modal，禁止关闭和重复提交。

## 5. 模型添加与编辑

### 5.1 split Modal 布局

模型 Modal 为大尺寸双栏：

- 左侧约 285px：供应商 Logo 和名称、模型标识、启停状态、本次测试状态、“测试模型”按钮及说明。
- 右侧：标题“模型设置”、错误、显示名称、模型标识、上下文窗口、自定义标签、“运行默认值（可选）”、本次测试结果和编辑态“从目录移除”。
- 底部：“取消”和“保存模型/保存修改”。

新增时模型标识可从供应商发现目录搜索选择，也可手动输入；目录读取失败仍允许手动输入。选择远端候选会填入模型 ID、显示名称和远端明确返回的上下文长度。编辑现有模型时模型 ID 只读并可复制。

### 5.2 标签和默认值

- 标签在按 Enter 时提交；中文输入法组合态 Enter 不提交。
- 标签输入框失焦时也提交；直接保存时尚未提交的草稿同样计入。
- 英文逗号和中文逗号都用于拆分标签；提交时去除首尾空白、空项和精确重复项。
- 每个已提交标签可单独删除。
- “运行默认值（可选）”默认折叠，摘要右侧显示“使用供应商默认参数”。
- 展开后说明：“本页不覆盖采样参数。使用模型时由调用方传入；未传入的参数沿用供应商默认设置。”
- 折叠区内只有“使用说明”文本域，不添加温度、top-p 或其他采样参数。

### 5.3 模型测试状态

左栏本次测试状态严格为：尚未测试、正在测试、测试通过及当前时间、测试失败。右侧测试结果只在本次 Modal 会话显示：

- 成功：模型 ID、单次延迟和输出预览。
- 供应商实际返回推理内容时，额外显示“查看本次返回的思考内容”折叠区。
- 失败：显示“模型调用失败”和错误信息。

切换新增模型 ID 会清空旧测试结果和保存错误。测试按钮在模型 ID 为空、模型测试进行中或保存进行中禁用。旧实现允许模型测试期间关闭 Modal，也未因模型测试进行中禁用保存；只有保存进行中锁定 Modal。原型必须保留该行为，不额外增加测试完成后才能保存的门槛。

### 5.4 从编辑打开删除确认

编辑现有模型时，右侧底部显示“从目录移除”。点击后，删除模型确认 Modal 叠加在仍然打开的编辑 Modal 上：

- 标题：“删除模型”。
- 说明：“确认从目录移除‘模型显示名称’？”
- 正文：“只移除 AutoFlow 中的模型配置，不会删除供应商的远端模型。”
- 按钮：“取消”“确认移除”。
- 取消、右上关闭、Escape 或点击遮罩只关闭确认层，返回原编辑 Modal，保留编辑表单。
- 确认移除期间锁定确认层；失败时保留确认层并显示错误；成功后关闭确认层和原编辑 Modal，再刷新模型目录。

## 6. 启停与删除

### 6.1 启停

- 停用供应商保留供应商及其模型，但它的所有模型不再出现在业务模型选择器中。
- 停用单个模型只排除该模型，不删除配置。
- 启停请求进行中防止重复触发；失败时保留服务端现状并显示页面内 `FeedbackCard`。
- 停用状态使用中性色，不等同于连接失败。

### 6.2 删除模型

- 模型行更多菜单中的“删除模型”和编辑 Modal 中的“从目录移除”进入相同确认。
- 删除只移除 AutoFlow 本地模型配置，不影响供应商远端模型。
- 按钮使用“确认移除”，请求中显示“正在移除…”。

### 6.3 删除供应商

- 从供应商右上更多菜单进入。
- 标题：“删除供应商”；说明明确供应商及其本地模型一并删除。
- 正文说明工作流中引用的模型将不再可选、当前接口未返回确切引用数、历史记录不会被改写。
- 不显示未经查询的工作流引用数量。
- 按钮：“取消”“确认删除”，请求中显示“正在删除…”。
- 删除失败保留确认 Modal 和对象级错误；成功后刷新供应商列表。

## 7. Modal、焦点与反馈规则

### 7.1 关闭与锁定

未锁定时，Modal 支持右上关闭按钮、Escape 和点击遮罩关闭。关闭后把焦点还给实际打开该 Modal 的按钮；嵌套删除确认关闭后逐层返回父 Modal 中的触发按钮。若触发按钮已不存在，则回退到原页面容器。

锁定时：

- 右上关闭按钮禁用，辅助名称变为“正在处理，请稍候”。
- Escape 和点击遮罩不关闭。
- ProviderWizard 在连接测试或保存期间锁定。
- ModelEditor 只在保存期间锁定，不在模型测试期间锁定。
- 删除确认在删除请求期间锁定。

旧交互没有未保存内容确认。取消、Escape、遮罩或右上关闭都会直接丢弃未保存内容；原型不增加离开确认。

### 7.2 反馈方式

模型管理旧页面没有触发 Toast。供应商连接测试、模型行测试、启停失败等反馈使用页面内 `FeedbackCard`；模型编辑测试和表单错误使用 Modal 内联结果。保存成功通常关闭 Modal 并刷新列表，不额外弹 Toast。

2026-09-24（confirmed，来源：用户要求及 `ModelManagementPage.test.tsx` 回归）：首页 `FeedbackCard` 在本次操作结果出现 2 秒后自动移除，成功和失败均适用；同一供应商或模型再次产生结果时重新计时。页面不从持久化的 `lastCheckMessage` 回显历史通知，连接状态徽标与最后检查时间保留。此前首页反馈常驻的行为 superseded；Modal 内联结果与表单校验不变。

全局 Toast 组件虽然存在，默认时长为 3000ms，悬停或焦点进入时暂停计时，但它不是模型管理旧交互的一部分。本原型不规定 2.6 秒 Toast，也不为模型管理新增 Toast。

## 8. 数据与能力边界

### 供应商

- 配置字段：名称、预设、协议类型、Base URL、API Key、启用状态、描述。
- 连接状态：未测试、最近连接成功、最近连接失败；只描述最近一次模型目录请求。
- 可显示最近检查时间、单次延迟、发现数量和结果消息，不推导实时在线、可用率或模型生成能力。
- API Key 必填性由预设决定；Ollama 和自定义兼容接口允许留空。

### 模型

- 配置字段：模型 ID、显示名称、自定义标签、可空上下文长度、启用状态、描述。
- 同一供应商内模型 ID 唯一。
- 模型测试结果仅属于本次会话，不持久化为健康状态。
- 标签是用户维护信息，不作为能力证明。

不增加能力/模态徽章、价格、余额、额度、吞吐、成功率、平均或 P95 延迟、长期健康分、默认模型、训练或微调入口。旧契约没有 capabilities 字段或能力筛选。

## 9. 现场核对与源码证据边界

以下交互已经在旧页面现场核对：

- 模型管理主页面的供应商左栏、右侧详情和模型目录。
- 模型行“更多操作”进入“编辑模型”。
- 模型编辑的 split 布局及“运行默认值”展开内容。
- “从目录移除”叠加删除确认，取消后返回并保留原编辑 Modal。
- Escape 关闭未锁定 Modal。
- 供应商编辑修改 Base URL 后，按钮从“保存修改”变为“测试并保存”；取消后页面仍显示旧值。
- 新增供应商从预设选择进入连接信息步骤。
- 本地样例连接失败后停留连接信息并保留表单。

以下行为本轮只有源码和既有测试证据，不声称已通过现场真实请求验证：

- 连接成功后进入第三步并选择或零选择模型。
- 对真实远端模型发起简短推理测试。
- 供应商与模型的持久保存。
- 供应商和模型启停。
- 模型删除与供应商级联删除的持久结果。

取证截图位于 `reference/01-legacy-model-management.jpg` 至 `reference/08-legacy-connection-error.jpg`，详见[取证清单](./reference/README.md)。这些截图用于证明模型管理内容区和交互，不作为新 AutoFlow 全局导航的视觉基准。

## 10. 交互验收矩阵

| 场景 | 入口/前置 | 操作 | 必须出现 | 不得出现 |
| --- | --- | --- | --- | --- |
| 切换供应商 | 左栏存在多个供应商 | 点击另一供应商 | 右侧切换为该供应商详情与模型；左栏选中态更新 | 横向供应商 Tabs、多个供应商详情同时展开 |
| 新增供应商第一步 | 点击页头或左栏加号 | 搜索并选择预设，点“下一步” | 进入连接信息；预设填充协议和默认地址 | 点击步骤标题跳步、此时发请求 |
| 返回预设 | 新增流程第二步 | 点“上一步” | 返回选择供应商；当前会话表单仍在 | 自动关闭 Modal |
| 连接表单校验 | 新增流程第二步 | 清空名称/Base URL，或清空必填 Key | “测试连接”禁用 | 未满足必填仍发请求 |
| 连接失败 | 连接表单有效 | 点“测试连接”，返回失败 | 停留第二步；内联错误；输入保持 | 创建供应商、进入第三步、Toast |
| 连接成功 | 连接表单有效 | 点“测试连接”，返回成功 | 进入第三步；显示单次耗时和发现列表 | 宣称模型推理成功或实时在线 |
| 零模型接入 | 第三步未勾选模型 | 点“保存供应商” | 允许提交；按钮无模型数量后缀 | 强制选择模型、虚构“跳过”按钮 |
| 多模型接入 | 第三步勾选 N 个模型 | 点“保存供应商和 N 个模型” | 再次校验目录并原子保存 | 部分成功状态 |
| 编辑非连接字段 | 供应商编辑 | 改名称、说明或启用状态 | 按钮仍为“保存修改”；直接保存 | 强制连接测试 |
| 编辑连接字段 | 供应商编辑 | 改协议、Base URL 或 API Key | 按钮变“测试并保存”；通过验证更新 | 沿用旧成功结果直接保存 |
| 取消供应商编辑 | 已改 Base URL | 点“取消”后重开 | 恢复服务端旧值 | 未保存确认、保留未保存 Base URL |
| 新增模型发现失败 | 点击“添加模型” | 目录请求失败 | 显示错误并允许手输模型 ID | 阻断手工添加 |
| 标签提交 | 模型编辑 | 输入 `本地, 推理，生产` 后 Enter 或失焦 | 拆分、trim、去空、去重后显示标签 | 仅支持一种逗号、输入逗号立即提交 |
| 上下文校验 | 模型编辑 | 输入空值、正整数或负数 | 空值与正整数可保存；负数内联报错且不请求 | 自动猜测上下文长度 |
| 模型测试 | 模型 ID 非空 | 点“测试模型” | 左栏显示测试中；右侧显示本次结果或错误 | 持久健康状态、要求测试后才能保存 |
| 思考内容 | 测试响应含 reasoningPreview | 展开“查看本次返回的思考内容” | 仅显示本次实际返回内容 | 无返回时仍展示折叠项 |
| 默认值展开 | 模型编辑 | 展开“运行默认值（可选）” | 显示供应商默认参数说明和使用说明 | 温度、top-p、采样参数控件 |
| 编辑中删除取消 | 编辑模型 | 点“从目录移除”，再点“取消” | 确认层关闭；返回原编辑 Modal；表单保留 | 同时关闭编辑 Modal |
| 编辑中确认移除 | 删除确认已打开 | 点“确认移除”并成功 | 删除本地配置；关闭两层 Modal；刷新列表 | 声称删除远端模型 |
| Escape 关闭 | 任一未锁定 Modal | 按 Escape | 关闭当前最上层 Modal 并归还焦点 | 未保存确认 |
| 请求期间关闭 | 连接测试、保存或删除请求进行中 | 点 X、遮罩或按 Escape | 当前 Modal 保持打开；X 禁用 | 提前关闭或重复提交 |
| 操作反馈 | 测试、启停、保存或删除 | 操作完成或失败 | 页面 `FeedbackCard` 显示 2 秒后移除；Modal 内联反馈；成功保存后刷新 | 模型管理 Toast、历史检查结果回显为通知 |
