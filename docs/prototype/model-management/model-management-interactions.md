## 2. 数据与状态语义

### 供应商

- 配置字段：名称、预设、协议类型、Base URL、API Key、启用状态、描述。
- 连接状态：未测试、最近连接成功、最近连接失败；只描述模型目录请求的结果。
- 可展示最近连接检查时间、单次耗时和结果信息，不推导当前在线状态或可用率。
- API Key 的必填性由预设决定；Ollama 和自定义兼容接口允许不填。
- 禁用供应商保留数据和模型；其模型从业务可调用选项中排除，但继续出现在管理界面。

### 模型

- 配置字段：模型 ID、显示名称、自定义标签、上下文长度、启用状态、描述。
- 上下文长度允许未设置；标签属于用户维护的数据，不视为经验证的视觉、工具调用或推理能力。
- 模型列表显示供应商归属；同一供应商内模型 ID 唯一。
- 模型测试结果为本次会话的临时结果，不展示为长期健康状态。
- 禁用模型仅排除该模型的调用选项，不删除配置。

## 3. 供应商接入与编辑

接入使用大尺寸 Modal，顶部横向三步提示，不引入左侧步骤栏。

1. 选择预设：搜索或选择旧项目供应商预设；预设提供协议、默认地址和密钥填写规则。
2. 配置连接：填写名称、Base URL、API Key、描述和启用状态；点击“测试连接”。测试期间显示轻量旋转并禁止重复提交；错误保留已输入内容。
3. 选择模型：展示接口实际发现的模型，可搜索、多选，也允许暂不添加模型；提交“完成接入”。

旧后端在最终接入时会再次发现模型，并事务性保存供应商与所选模型。若所选模型已不可用，不宣告部分成功；提示重新获取列表并调整选择。

供应商编辑使用同一组表单组件，不重复走预设选择流程。修改连接字段后，界面不得继续将旧地址的测试结果呈现为新连接的成功结果；具体失效策略在正式契约阶段明确。

密钥输入使用密码控件，列表不展示密钥正文。新架构拟采用“已配置”标记与替换输入，不向前端回传已保存的完整密钥；这是待规格确认的工程改进，不是旧接口现状。

## 4. 添加与编辑模型

- “添加模型”打开 Modal，可从发现列表中选择，或手动填写模型 ID。
- 发现模型只更新候选列表，不自动同步删除、禁用或覆盖本地模型。
- 表单使用单一内容区，包含显示名称、模型 ID、上下文长度、标签、描述和启用开关。
- 编辑已有模型时模型 ID 只读并可复制；上下文长度留空或输入正整数。
- 保存期间显示“正在保存…”；保存失败保持表单，成功后刷新目录并显示 Toast。
- 不增加温度、采样参数、默认模型、对话输入框、训练或微调入口。

## 5. 两种测试必须分开

| 操作 | 实际请求 | 可展示结果 | 不能推导 |
| --- | --- | --- | --- |
| 测试连接 | 获取供应商模型目录 | 成功/失败、单次耗时、发现数量、错误信息 | 模型一定可以生成、额度充足、当前在线 |
| 测试模型 | 对指定模型发送固定简短生成请求 | 本次调用耗时、返回片段、供应商实际返回的推理片段（如有）、错误 | 长期健康、成功率、平均速度、能力认证 |

旧模型测试使用“只回复 OK”，最大输出 16 tokens。展示实际响应，不要求每个供应商必须恰好返回 `OK`；输出预览最多 240 字符，推理预览最多 2000 字符。失败时区分可获得的鉴权、网络、接口和模型错误，不捏造供应商没有返回的原因。

测试结果可在当前模型行下展开，或在独立结果弹窗显示；具体容器随最终布局确定，不使用永久右侧面板。同一目标测试期间禁止重复触发，并明确“测试中”。

## 6. 删除与启停

- 删除模型：展示名称、ID 和供应商，说明仅删除 AutoFlow 本地配置，不删除远端模型；操作按钮“确认删除”。
- 删除供应商：展示供应商名称及本地模型数量（从本地数据计算），说明其本地模型一并删除且不再可选；不展示未经查询的工作流引用数量。
- 删除确认框默认焦点在“取消”。执行期间禁止重复提交和关闭；失败时保留弹窗，完成后更新列表。
- 启用开关需等待接口确认；失败回退开关并显示错误。禁用不等于连接失败，使用中性状态色。

## 7. 正常、加载、空、错误与反馈

| 情形 | 展示与交互 |
| --- | --- |
| 首次加载 | 表头与稳定骨架，不显示虚构数量 |
| 尚无供应商 | “还没有模型供应商”，操作“接入供应商” |
| 供应商尚无本地模型 | “还没有添加模型”，提供发现和手动添加入口 |
| 发现目录为空 | 明确“接口未返回模型”，允许按旧能力手动添加 |
| 搜索无匹配项 | 提供清空筛选，不误导用户重新接入供应商 |
| 本地列表请求失败 | 错误原因与重试；已有数据可保留并标记刷新失败 |
| 供应商目录失败 | 保留本地模型管理；添加流程显示重试及手动输入入口 |
| 保存/删除失败 | 保留操作上下文，内联错误；不提前显示成功 Toast |
| 操作成功 | 供应商已接入/已保存、模型已添加/已保存/已删除、供应商已删除 |
| 表单有未保存内容 | 拟增加离开确认；这是交互改进，待最终规格确认 |

动效沿用已选规范：弹窗 150ms 淡入并上移不超过 8px；Toast 150ms 淡入，2.6 秒后淡出；轻量旋转表示请求进行中。支持减少动态效果设置。弹窗支持 Escape 和遮罩关闭，提交进行中禁止关闭；有未保存输入时先确认。焦点限制在当前弹窗内，关闭后回到触发按钮。

## 8. 图片审核与已知待修正项

- 三张图片的供应商、模型名称、数量、连接状态、耗时和响应片段均为示例，不代表真实接口验证结果。
- 布局 1 的停用状态应在定稿中统一为中性灰，不将停用渲染为错误。
- 布局 2 中 Ollama 的密钥示例不代表密钥必填，空密钥也可接入。
- 布局 3 自动生成的模型行选择框不在旧功能范围内；若选中此布局，定稿时移除。不得据此增加模型批量删除、批量测试或批量同步。
- 所有供应商连接结果都应明确为“最近一次检查”，不能因为图中简写为“已连接”就承诺实时在线检测。
- 当前只有主页面候选图。未完成接入三步、编辑、测试失败、删除确认等详细画板，不能将本目录视为可直接开发的完整视觉基准。
