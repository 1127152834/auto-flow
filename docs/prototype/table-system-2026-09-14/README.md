## 选定方向

- 细浅色横纵网格、明确列对齐、轻量表头；避免粗重边框、卡片套卡片。
- 正文目标14px、控件目标32px、单行表格目标32px；这些是待工程验证的设计目标，不是对生成图片逐像素测量结论。多行资源名称/次要描述与200%缩放需保证可读和可达。
- 紧凑工具栏：字段选择与搜索视觉组合，筛选/排序/显示列等同高；主操作与次操作有层级。
- 轻量勾选、选中行与焦点单元格区分，状态用小标记配文字，表格内部处理必要横向滚动。
- 暖灰背景、黏土棕强调色、现有顶部导航继续沿用。
- 统一的是可复用视觉与控件规范；按页面真实能力组合工具栏，不给每张表凭空增加筛选、批量选择、分页或编辑功能。原型示例数据、代理名称、规则和分页仅用于比较样式。

## 适用与边界

覆盖整个AutoFlow的真实表格：项目记录/字段/状态、代理/代理池、模型目录、弹窗和详情内嵌表格，以及主线当前已有其他表格。浏览器配置/内核等目前以卡片展示的内容先盘点，不能因统一表格就强制改成表格。截图上方项目头及页面层级不因本次表格风格确认而再次重排。

本次确认不改变数据语义、查询条件、版本/幂等/恢复、接口和业务能力边界。不将截图当作可以即时单元格编辑的授权。
