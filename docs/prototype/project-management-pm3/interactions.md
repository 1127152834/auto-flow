# PM3 自动化详情与批次启动交互基准

- 日期：2026-09-14
- 状态：B0 候选视觉基准
- 画板：1440 × 1024，桌面端，100% 缩放
- 全局导航：沿用 AutoFlow 当前顶部导航；不出现左侧应用导航、模块侧栏或第二套导航

## 1. 视觉系统

五张画板必须使用同一页面骨架，只切换自动化详情的活动页签或叠加启动弹窗。

| 项目 | 基准 |
|---|---|
| 页面背景 | 暖灰 `#f1eee7` |
| 主表面 | 米白 `#fbfaf7`，次级表面 `#f6f3ee` |
| 文本 | 主文本 `#34322e`，次文本 `#625e57` |
| 强调色 | 黏土棕 `#8d4e2f`，浅强调 `#f2e3d7` |
| 边框 | `#d8d3c9`，1px 细线 |
| 圆角 | 控件 4px，卡片/浮层 6px；禁止胶囊化和大圆角卡片 |
| 密度 | 全局头部 74px；主区最大宽度 1280px；控件 32/40px；表格普通行 32px、含操作行 40px |
| 字体 | macOS/Windows 系统无衬线字体；标题 24–28px，正文 14px |
| 阴影 | 只用于 Modal/Popover，轻量、低对比 |

顶部导航固定为：AutoFlow 标识、总览、项目（活动）、浏览器配置、代理管理、模型管理；右侧为设置和“本地服务正常”。正文统一收进 1280px 居中容器，1440px 画板的外边界约为 x=80–1360。正文固定包含返回箭头、面包屑、项目紧凑页头、六个项目页签，其中“自动化”处于活动状态。

## 2. 自动化详情共用骨架

- 面包屑：最左侧为明确的返回箭头按钮，后接 `项目 / 内容采集项目 / 自动化 / 资料整理`；返回目标为自动化列表。
- 项目上下文：项目名“内容采集项目”、说明“收集资料，整理内容，维护项目数据”。
- 自动化页头：图标、名称“资料整理”、说明“将采集内容整理为可维护的资料记录”、管理状态“配置已保存”和独立运行准入“可以运行”。工作流保存与校验事实在关联工作流区单独显示，不能与管理配置状态混成一个状态。
- 右侧主操作：次按钮“打开 Studio”，主按钮“启动运行”。
- 配置页签：`基本信息`、`输入与参数`、`资源与环境`、`运行设置`。
- 四页签共用一份草稿。底部固定操作栏显示保存状态，提供“取消修改”和“保存配置”。
- 正常状态不展示内部 ID、修订号或开发编号。

## 3. 画板 A：基本信息

文件：`automation-detail-overview.png`

字段和动作：

1. 自动化名称：`资料整理`，必填，trim 后 1–80 个 Unicode 码点。
2. 用途说明：`将采集内容整理为可维护的资料记录`，0–1000 个 Unicode 码点。
3. 关联工作流：显示 `资料整理流程`、校验状态“可以运行”、最近保存时间；提供“打开 Studio”。
4. 关联说明：建立后不能通过普通编辑替换工作流。
5. 配置摘要：4 个参数、临时浏览器环境、最多 10 个任务、并发 1。

状态覆盖：读取中使用轻量 Skeleton；工作流不可运行时在关联卡片中显示结构化原因，仍允许保存配置草稿。

## 4. 画板 B：输入与参数

文件：`automation-detail-inputs.png`

页面分为“项目数据输入”和“启动参数”两段：

- 项目数据输入：示例使用空态，文案“当前自动化不读取项目数据，可以直接使用参数启动”；“添加数据输入”允许进入真实配置、保存和预览流程。只要存在项目数据输入，运行校验必须给出“需要后续数据执行能力”的结构化 blocker，不能静默忽略输入。
- 启动参数采用细网格表，列为参数名称、类型、必填、默认值、说明、操作。
- 示例参数：`关键词`（文本、必填）、`采集页数`（整数、默认 3）、`仅保留正文`（布尔、默认开启）、`备注`（文本、可选）。
- 操作：新增参数、编辑、上移/下移、移除。参数稳定身份不显示给普通用户。

校验：重复名称和默认值类型错误在本页签显示错误数量；必填参数可以没有默认值，在启动弹窗未填写时才报错。保存时聚焦首个配置错误。

## 5. 画板 C：资源与环境

文件：`automation-detail-resources.png`

字段和规则：

1. 浏览器配置：选择来源为 `继承项目默认` 或 `指定浏览器配置`；示例选择指定的 `商品资料采集`，展示 CloakBrowser 内核、最终采用值及来源。
2. 代理设置：单选 `继承项目默认` / `跟随浏览器配置` / `不使用代理` / `固定代理` / `代理池`；示例选中“跟随浏览器配置”。
3. 模型提供方：可选，下拉显示 `OpenAI · 内容处理模型`。
4. 环境策略：仅开放“每个任务创建临时环境”；“固定持久环境”和“使用记录关联环境”明确标记暂未开放。
5. 资源检查区：浏览器配置、CloakBrowser 内核、代理、模型逐项显示最终采用值、来源及可用/未配置状态。

资源缺失允许保存草稿；页面顶端“启动运行”仍可进入服务端校验，随后显示结构化阻断。错误必须说明缺少哪项资源和修复入口，不能只靠禁用按钮表达。

## 6. 画板 D：运行设置

文件：`automation-detail-run-policy.png`

字段和规则：

1. 最大任务数：1–100，默认 1；画板展示用户已改为 10 的状态。
2. 并发任务数：固定为 1，控件只读并解释“当前版本按顺序执行”。
3. 失败处理：开关“某个任务失败后停止创建后续任务”。
4. 单任务超时：数值 + 分钟，示例 15 分钟。
5. 任务结束时环境处理：单选“关闭并清理临时环境”；保留环境选项标记需要后续能力。
6. 运行摘要：最多 10 个任务、串行、单任务最长 15 分钟；摘要由字段实时计算，不推算包含排队、收尾和恢复的批次总时长。

无限运行不得出现。错误值保留输入并在字段下方显示原因。

## 7. 画板 E：启动运行弹窗

文件：`batch-start-dialog.png`

启动弹窗叠加在自动化详情基本信息页上，宽约 680px，内容区可滚动，背景遮罩使用系统令牌 `rgb(52 50 46 / 32%)`。

弹窗内容：

1. 标题“启动自动化”，副标题“资料整理”。
2. 运行检查：工作流、浏览器配置、CloakBrowser 内核均显示绿色“可用”。
3. 参数表单：关键词 `温室补光`、采集页数 `3`、仅保留正文开启、备注可选。
4. 本次任务数：数值 10（用户已修改；默认 1），限制 1–100。
5. 资源摘要：浏览器配置“商品资料采集”、代理“跟随浏览器配置”、临时环境、并发 1。
6. 本次环境覆盖：`使用自动化配置`（选中）或 `每个任务创建临时环境`；说明“本次覆盖只用于这个批次，不会修改自动化默认设置”。
7. 底部：取消、主按钮“启动 10 个任务”。

状态规则：

- 校验失败：错误保留在对应字段和顶部摘要，弹窗不关闭。
- 资源缺失：启动按钮禁用，提供“返回配置”或具体资源修复入口。
- 提交中：按钮显示“正在创建批次…”，禁止重复提交、Escape 和遮罩关闭。
- 结果不明：保留弹窗和操作身份，显示“正在核对启动结果…”，不换键重发。
- 成功：关闭弹窗，进入对应批次详情；Toast 只提示“批次已创建”。
- 关闭弹窗：保留当前表单会话中的启动草稿；切换工作区时清除。
- 409 冲突：保留全部输入，刷新自动化与资源事实后明确要求用户重新提交。

## 8. 共用交互与可访问性

- 页面离开、切换页签、打开 Studio、浏览器前进/后退遇到脏草稿时统一确认。
- `Tab` 按视觉顺序移动；页签支持方向键；Dialog 打开后焦点进入标题后的第一个可编辑字段，关闭后返回“启动运行”。
- `Escape` 先关闭 Select/Popover，再关闭 Dialog；保存或启动提交中不关闭。
- 所有字段有可见标签、帮助文本和关联错误；状态不能只靠颜色表达。
- JSON 标量严格区分 `false`、`0`、空字符串、明确 `null` 和未提供；界面不得用 truthy/falsy 合并这些值。
- 200% 缩放时页面保持单一主内容滚动，表格或弹窗内容在自身区域滚动，应用宽度不被下拉框或长文本撑开。

## 9. 状态画板与实现验收

五张 B0 图展示正常已保存状态；以下状态必须使用同一骨架在组件测试、E2E 和截图验收中实现，不为每个状态另造独立页面：

| 状态 | 权威表现与恢复 |
|---|---|
| `ready` | 管理状态“配置已保存”和准入“可以运行”分开显示。 |
| `draft` | 底部显示未保存数量；页签切换不提交，离开进入统一保护。 |
| `blocked` | 持久区列出工作流、参数、项目数据输入或资源 blocker，并提供对应修复入口；仍允许保存草稿。 |
| `unavailable` | 核心服务不可用，配置仍可查看；启动由服务端结构化拒绝。 |
| 保存中 | “正在保存配置…”，冻结候选并禁止重复提交与离开。 |
| 保存 CAS 冲突 | 保留“我的修改”，同时展示服务端最新摘要；不自动覆盖或部分保存。 |
| 启动校验失败 | 精确定位参数或资源错误；必填参数未提供只在启动时失败。 |
| 启动 409 | 保留弹窗输入并刷新最新事实，由用户再次提交。 |
| 启动结果不明 | 使用原 Idempotency-Key 查询 Operation/Batch，显示“正在核对启动结果…”。 |

参数表操作可直接显示编辑，并在行级更多菜单或参数编辑器中提供上移、下移和移除；不得只实现图中可见的单一动作。
