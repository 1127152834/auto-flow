## 通用视觉、键盘与缩放检查

对下述实际可进入的 14 处表面执行：

- [ ] 100%：表头与主要值为 14px，轻表头、浅色 1px 横纵网格；普通单行目标 32px，含按钮行允许 40px，多行内容可增高，操作不得被裁掉。
- [ ] 表格查询控件及创建工具为 32px；筛选、排序、显示列按现有业务提供，不要求给缺少这些功能的页面新增按钮。
- [ ] 200%：通过应用实际缩放设置切换并记录值；表格可内部滚动、查询工具可换行，页面整体不得因长表格横向撑开。组件脚本已自动设置两种缩放，但真实页面仍须单独检查。
- [ ] 仅用 Tab/Shift+Tab 进入搜索、选择器、表格滚动区、行操作与分页；焦点清晰。滚动区域聚焦后可用键盘横滚，最后一列操作可达；普通只读单元格不逐格增加 Tab 停靠。
- [ ] Select/Popover/菜单能用键盘打开、选择、Escape 关闭并恢复焦点；弹层内部可滚动，关闭时页面宽度不跳动。
- [ ] 在隔离数据中使用长名称、长 URL/标识、空值和多行内容，检查内部横滚、换行、title 或已有详情入口；完整值仍有读取途径。
- [ ] 空态、加载、错误、只读及禁用状态仍有文字解释；选中背景与真实 Checkbox 同步，状态不能只靠颜色判断。
