# 全局小圆角规范

2026-09-14，confirmed。来源：用户在精细网格验收后要求整个系统趋近直角、但仍看得出圆角。本次为已授权的有界视觉调整，不改变尺寸密度、导航和业务逻辑。

| 用途 | 半径 |
|---|---|
| 小标记、Checkbox外框 | 2px |
| 按钮、输入/搜索/选择、菜单项、文字标签 | 4px |
| 卡片、表格边框、弹窗、大浮层 | 6px |

唯一落点 `renderer/styles/radii.css`，同时由主应用 tokens.css 与 Studio webrpa.css 导入；Tailwind xs/sm=2、md/lg=4、xl及以上=6，control=4、card/modal/panel=6。旧Studio默认radius映射4。保留相邻控件拼接处0、圆形头像/图标/单选/开关/状态点/滚动条/画布连接点的圆形语义，外部网页代码示例不随应用样式重写。

固定像素圆角迁到语义令牌，覆盖按钮、输入、弹窗、节点、Markdown回复、提示和内嵌预览；两处内联样式采用var而非复制常数。文字胶囊改为control，避免模块残留另一种轮廓。系统原生窗口框架由macOS/Windows绘制，本次不改成自绘窗口。

验证：真实创建项目弹窗的computed半径；100/200%无页面横向溢出；Escape及焦点恢复；浏览器、代理、模型、设置入口；独立Studio运行时token一致。表格既有样式与虚拟滚动由原组件QA回归。完整业务历史验收不因样式调整自动改写。
