## 接口与所有权

- `GET /api/v1/dashboard` → OpenAPI `DashboardRead`。
- `GET /api/v1/settings/runtime` → `RuntimeRead`，包括路径、版本和占用代码。
- `POST /internal/settings/quiesce` / `resume`：只接受 host token，拒绝 Origin，不进入公开 OpenAPI。检查在途写入及带副作用的内核/模型查询；暂停期间拒绝新的变更。
- 桌面 IPC 统一契约：`apps/desktop/src/shared/settings.ts`；main 校验窗口和主 frame 来源。renderer 不能任意指定路径或导出内容。
- 本机偏好与工作区根选择由 main 管理；Python 管理资源计数、执行器占用与暂停门控。两者通过窄契约协调，未建立第二套配置数据库。
