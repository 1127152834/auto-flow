# 项目拾取／录制归属和统计（2026-09-23）

已批准的 AutoFlow 项目集成适配，沿用 WebRPA 录制算法、既有 worker/资源锁和生命周期；没有第二套执行器或租约框架。

- browser/element-picker/recorder 请求携带宿主 projectId。外项目或省略项目不能读取或控制已归属会话；录制审查、事件、命令回执分别按持久归属验证。
- 同一 SQLite 写预约内检查项目生命周期并发布内存占用，再开始异步启动。归档能看到 starting/ready/closing；取消启动、清理失败及重试由现有 worker 承担，清理确认前不释放归属。
- 0020 增量增加录制会话 projectId/documentId、审查/命令 projectId；旧记录 null 不自动推断。新录制统计按项目、文档、创建时间计算。运行状态筛选不适用于录制时返回 null+原因；页面说明历史无归属未计入。
- 永久删除复用既有 project_id 表清理和事件外键级联，保留其他项目及无归属历史。测试覆盖归档、删除、恢复、命令和审查隔离。
- 正式开发构建真实项目 UI → 可见 CloakBrowser → 操作录制/暂停/恢复 → 审查/生成/保存 → 原生窗口关闭重开 → 独立重放 → 项目录制统计通过。源浏览器和运行浏览器均清理，原生关闭未调用 BrowserWindow.close/destroy。
