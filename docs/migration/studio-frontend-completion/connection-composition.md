# F1 Studio 连接装配

日期：2026-09-13；状态：本切片已实现并验证；依据已授权 F1 服务消费边界。

请求层不默认导入 Mock。入口明确装配服务 origin 与 transport；当前正式 Studio 入口仍显式选择浏览器本地协议夹具。测试入口显式选择同一夹具。HTTP/SSE 网络测试选择实际本地 HTTP transport，消费组件保持不变。

API 地址在调用时读取，不在模块导入时缓存。未装配时给出明确错误；无效 origin 不改变既有配置；禁止 URL 中的凭据、路径、查询和片段。已有请求取消和网络错误通知继续保留。服务重连、工作区切换必须先停止旧事件客户端，再装配连接，不把此函数当作热切换协调器。

验证：服务 API 与直接工具请求走同一配置；SSE 使用同一 origin；真实 HTTP 请求和分块事件通过；取消与错误回归；完整前端测试、类型、lint 和构建。此切片不宣称鉴权接入、工作区离开协调或全量服务合同完成。
