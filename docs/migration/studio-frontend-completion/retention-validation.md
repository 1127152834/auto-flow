# F1/F5 留存策略与清理交互

2026-09-14。实现的是前端和服务消费协议，真实文件清理与定时任务尚未实现。

## 行为与接口

沿用冻结 WebRPA 的 `/retention/config`（GET/POST）、`/retention/usage`（GET）、`/retention/cleanup`（POST）。POST 配置保留部分更新、null 忽略语义；Studio 表单提交完整配置。OpenAPI 登记严格配置、更新、用量、保存与清理回执 DTO。所有回执必须明确 success=true，结构不完整、非法统计或旧连接响应不能确认成功。

保留当前 AutoFlow 默认值：自动清理关闭、录像/数据各 30 天、总大小 0 MB、间隔 24 小时。未搬入旧项目的自动开启/14 天/1024 MB/6 小时默认值。天数与大小为非负安全整数，0 表示不限制；间隔为至少 1 的安全整数。旧项目 0 间隔静默替换默认值的行为不迁入。

Mock 使用独立 settings 留存策略；模拟清理返回 recordings/data 的 removed=0、freedMB=0，不读写真实产物文件。失败写入返回 507，非法更新 422，不支持的方法 405。真实后端应只清理登记产物，不复制旧目录全扫描和吞掉写入/删除异常的实现。

## 组件与保护

提取 RetentionSettings，复用设置草稿离开协调。读取失败展示错误/重试；保存失败保留输入；空数值不被转为 0。保存和手动清理互斥，未保存策略先保存后清理，所有操作完成前禁止离开。切标签、关闭、AI 关闭沿用父级 guard，保存、放弃、取消有明确结果。

连接变更保留输入并禁用旧表单；重新打开后明确读取目标连接。迟到读取、写入、清理与用量回复不覆盖新连接。清理回执确认后若用量刷新失败，分别展示已确认结果与刷新错误。卸载不应用响应。

## 证据与边界

新增 3 个前端测试文件共 74 项；与现有设置/AI 关闭测试合计 117 项通过。18 项 Python DTO 用例通过。内存与真实本地 HTTP 夹具运行相同配置协议用例；不是实际文件删除测试。

浏览器从更多操作进入全局配置，验证无效间隔、取消保留、保存后关闭、重开恢复、还原测试值和模拟清理回执。只操作 localhost:5175 独立 Mock 数据。见 evidence/f5-retention/browser-validation.md。

类型、ESLint、Ruff、mypy、OpenAPI、49 项脚本检查及 renderer/main/preload 构建通过。构建 39.17 秒。此前 277 文件/3271 项全量回归覆盖安全归属批次，不含本批；本批使用上述针对性回归。
