# F3 日志原始时间与重放

2026-09-14。实际页面热更新回放中发现历史日志显示当前时间。execution:log和execution:log_batch的消费缓冲没有带上服务端timestamp，Store因而补入接收时间。现在两种事件均保留timestamp，沿用已有addLogBatch的时间字段能力。

新增内存和真实HTTP两项用例，分别包含实时单条、实时批量、重新连接从序号0重放：固定2020年的两个时间在所有阶段保持不变。修复前两项失败；修复后与输入/调试HTTP回归共3文件11项通过，类型/lint通过。

此变更不负责服务端日志ID去重、分页持久化、独立运行身份或本地合成完成日志的服务器时间；F3日志历史完整验收尚未完成。不用接收时间冒充已知服务端事件时间。
