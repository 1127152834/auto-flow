# F2/F6 工具栏与 500 节点编辑验收

2026-09-14。本机 macOS arm64，开发入口 http://localhost:5175/studio.html，独立 Mock 数据。F6 整体仍未完成。

## 修复

工具栏采用自然换行和最小高度，宽窗口保持单行。为运行、文件、计划任务、浏览器、录制图标增加明确的可访问名称。模块条在本身较窄时将操作按钮另起一行，宽时保持原排列；底部留出浮动视图按钮空间，并设置滚动定位间距。出错处理弹窗补充关闭按钮名称。

实际发现并修复：357px 工具栏按钮越界；768px “更多操作”右界约 811.6px；窄模块条文本与操作按钮相互挤占，点击末尾节点可能误开出错处理。没有把节点存在于 DOM 当作可点击通过。

修复后 357/768px 工具栏均无越界，1440px 高度仍为 48px；357px/768px 分别为 77px/81px。窄模块条依次点击实际 data-block-id 0499、0500，选中样式对应相应行，未再误开弹窗。宽模块条保持 nowrap，窄时为 wrap。

## 500 节点验证

夹具 fixtures/capacity-500.bundle.json：500 个打印日志节点、499 条顺序连线、无资源依赖，245,262 字节。通过真实文件选择器导入，不修改 Store 绕过界面。

- 导入成功，画布计数 500。当前窄画布一次观察到 16 个可见节点 DOM；这是一次观测，不是固定渲染上限。
- 模块条显示 500 步，最后一行可选择，属性显示“容量标记 0500”。
- 界面修改为“容量标记 0500：界面编辑已确认”并保存。
- 刷新应用，重新打开同名文件，列表显示约 159.9 KB；仍有 500 行，末尾编辑值恢复。
- 4 项规则测试验证全部节点/连线、全部数据和位置保存往返、最后节点修改撤销重做、两视图转换后的真实连线执行顺序。

测试开发中两项修正：Vite 将静态 new URL(JSON, import.meta.url) 转为资源 URL，改用 Node 文件路径读取夹具；最初误将连线数组排列当成执行顺序，改为从首节点逐条沿有向连线遍历，严格断言每个非末尾节点只有一条后继、末尾零后继及全部 500 节点顺序。没有改变执行器去迎合错误断言。
