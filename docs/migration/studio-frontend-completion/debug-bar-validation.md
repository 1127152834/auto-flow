# F3 调试控制条确认与异常处理

2026-09-14。沿用原调试操作与UI布局，未引入另一套执行器。

继续/单步发送期间禁止重复控制；HTTP成功后保持等待状态，由SSE恢复或下一次暂停确认转换。明确HTTP拒绝显示错误并保留暂停；网络结果未知时不允许再次单步，停止仍可用。停止优先于尚未返回的控制请求，停止失败保留现场与重试入口，不声称已结束。

每次前端setPaused增加本地pauseRevision，用于隔离异步UI回执，不作为后端pauseId。新暂停、恢复、工作流变化或卸载使旧响应失效。不同workflowId的paused/resumed事件被过滤。此处不解决同文档不同运行的迟到事件，仍需要独立runId和服务端暂停上下文。

实际UI验收发现停止日志误写“失败”，现改为info级别“执行已停止”；单步暂停底部文案与暂停原因一致。

新增8个组件用例和2个真实本地HTTP用例；首轮组件5项中4失败、1通过，HTTP其他工作流事件过滤2项修复前失败。相关4文件50项通过，类型与lint通过。HTTP测试包括丢失单步响应后依靠SSE进入下一暂停、总共仅发一次单步，并核对停止日志。
