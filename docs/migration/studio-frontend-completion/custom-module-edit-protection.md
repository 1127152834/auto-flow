# 自定义模块编辑会话保护

日期：2026-09-14。F2.3/F5 已授权范围中的有界修复。

进入模块前读取最新内容；读取失败或期间文档变化时不使用列表缓存覆盖草稿。主文档备份包括标识、节点、连线、名称、变量、历史及未保存状态。备份失败不能进入。切换正在编辑的模块需先处理当前模块草稿。

保存按钮、快捷键和保存保护在模块模式统一更新模块工作流，包含变量及特殊节点序列化；允许空模块。失败保留草稿，旧保存响应不确认新编辑。退出先保存/放弃/取消，再恢复主文档及历史；备份异常不清空画布。

对应测试覆盖变量往返、模块元数据保留、晚响应、读写失败、保存/放弃/取消和退出恢复。真实模块运行后端不属于本批证据。

模块编辑期间新建/打开整文档要求先退出并恢复主工作流，以保护被隐藏的主草稿；模块间切换复用保存决定并继续保留最初主草稿备份。
