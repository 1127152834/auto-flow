# F5：配置编辑离开保护

2026-09-14。限定凭据与 WebDAV 编辑表单，不将本批等同于整个宿主退出保护。

## 实现

- 在全局配置切标签、右上角关闭、遮罩关闭及「完成保存」之前调用当前表单的离开检查。
- 修改后提供保存后继续／放弃修改／取消。取消保留输入；保存失败保留表单；只有保存确认后继续原目的操作。
- 确认期间锁定表单，重复操作不能改写第一次目的地或追加保存。正在写入时不关闭。
- 无修改或已确认保存不重复询问。WebDAV 连接测试不标记为已保存。
- 卸载取消待决请求；凭据与 WebDAV 连接更换时旧表单不能向新服务提交。
- 复用现有 ConfirmDialog 和对话框注册，三种选择可由既有对话框工具感知；未增加 i18n。

## 后续明确缺口

1. MCP 编辑弹层内部关闭、配置标签离开、连接替换与迟到响应仍待同样处理。MCP 当前仅校验回执形状，没有连接修订保护。
2. 原有全局 Store 中其它配置即时写入的字段不是本批所指服务表单；其请求确认、失败回滚和导入/重置合同需分别核对。
3. Toolbar 的 beforeunload 仍是浏览器原生提示，不支持异步保存完成后再退出。正式 Electron 退出、工作区切换的异步草稿/配置/会话协调没有因此补齐。
4. 外部父组件强制隐藏或服务/应用崩溃不属于该表单按钮保护；不声称能恢复未提交凭据或密码。
5. 不把 Mock 保存或浏览器预览测试当作真实 WebDAV 连接、加密存储、正式 Electron 或其它平台实测。
