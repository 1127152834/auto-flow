# 页面注入脚本测试服务合同

2026-09-14；状态：本批前端与协议验收通过，正式浏览器执行待后端接入。属于已批准F1/F2配套工具补齐，不新增自动化节点或执行引擎。

## 源差异及目标

冻结WebRPA InjectJsEditorDialog.handleTest在renderer用new Function同步执行代码，document/window来自JSON字符串。querySelector等方法会在序列化时丢失，无限循环能阻塞工作台，而且结果不是目标网页结果。AutoFlow保留代码编辑布局、变量、复制、AI入口和结果区，将“测试运行”转为服务请求，取消该页面内执行路径。

当前阶段HTTP/内存Mock只验证服务协议；Mock结果强制标明“未执行代码或查询网页”。真实后端后续在自动化浏览器所选页面中执行相同请求。测试可能改变页面状态，界面明确显示目标及该语义，不将测试当只读定位。

## 接口与字段

统一/api/browser/script-tests：

- GET /context：读取当前可测试页面的browserSessionId、pageId、revision、url及activeRequestId（无活跃请求时为null）。没有浏览器或被运行/拾取/录制占用时明确409。
- POST 根路径：requestId、context、code、variables。上下文必须与当前浏览器、页面和导航修订一致；同ID同内容返回原状态，不再执行；不同内容409。
- GET /{requestId}：非消费式读取状态；未知404。状态为running/completed/failed/cancelled/expired。
- POST /{requestId}/cancel：幂等取消，完成取消清理后返回cancelled；已经完成保留原终态，不伪造取消。

状态包含requestId、context、status、hasResult、result、error及executionKind(browser/mock)。null返回值与无返回值通过hasResult区分；failed/expired必须有错误。上下文全部必填，revision为安全非负整数。code非空，code与变量的UTF-8 JSON请求合计最多1MiB；超限明确拒绝，不截断。只接受JSON变量，不接受非有限数字或静默丢弃不支持的值。

真实服务：每次测试最多30秒，页面导航/关闭使在途操作过期，取消需中止页面求值；不能取消时保留占用并报清理错误。结果与取消确认前不释放资源。同一浏览器只允许一个在途测试，与运行、录制和拾取互斥。结果保留到该服务生命周期结束，用原ID补查响应丢失，不重放代码。

前端：点击时捕获当前代码和声明初值副本；先获取上下文再发送。请求中禁用重复测试；响应不明只查询原ID。关闭、改代码或变量后使旧结果不可展示并请求取消；旧请求未确认清理前不启动新请求。停止测试保留编辑内容；界面提供错误、待确认、取消和重试查询状态。测试不写流程变量、节点结果或编辑历史。继续沿用中文界面，语言字段属于业务配置。

## 本批验收

1. 三种结果：有值、null、无返回值；结构化大值与错误显示。
2. 未打开浏览器、正在被占用、非法上下文、导航后旧修订、超限和非JSON输入均明确拒绝。
3. 同ID重试、响应丢失原ID查询、取消幂等、取消与完成竞争、旧响应和连续点击不重复执行。
4. 改代码/变量、关弹窗、换节点/文档后的迟到结果不得进入新上下文；清理失败可继续查询/重试取消。
5. 实际页面里输入无限循环测试代码不会在Studio主线程执行；Mock必须明确标识未执行。
6. 内存/本地HTTP共用协议测试，前端组件和真实浏览器按钮链路分别记录；真实浏览器页面求值交付待正式后端验收，不能用Mock替代。

## 实现边界与恢复

状态每秒补查；单次HTTP请求10秒上限。重新打开编辑器时通过activeRequestId恢复上次测试，未结束前不提交当前代码。取消与完成竞争时保留服务终态；已经完成不能显示“已取消”，过期编辑结果不应用。

测试仅针对服务当前所选页面，不能代替节点“所有页面／URL匹配／索引”各运行模式的验证。服务地址变化时停止旧响应消费，明确提示原测试清理未确认；不会把旧页面代码提交给新服务。完整工作区离开协调、同地址服务epoch和真正浏览器求值仍是待交接项，不能据此关闭F5/F6。
