# F5：AI 配置关闭确认及弹窗生命周期

2026-09-14。

AI close_global_config 现在调用已挂载配置窗口的关闭处理器，等待保存/放弃/取消与保存结果后报告成功。旧 UI 事件入口也调用同一处理器，Toolbar 不再直接隐藏配置。未挂载处理器时报告不可用，已挂载但已关闭则幂等返回成功。重复关闭在首个请求等待时拒绝。

useConfirm 卸载时取消未决请求，晚到调用直接返回取消，替换弹窗取消前一个等待。该修复避免 AI 等待保存失败提示确认时，窗口卸载导致命令永久不结束。
