# AI 快照回退与操作记录修复

日期：2026-09-14；范围：F2 已授权实施中的有界修复。

快照恢复必须一次恢复节点、连线、名称和变量，并可撤销、重做，不清空此前编辑历史。退出自定义模块仍明确建立主画布历史基线，防止撤销跨入已经退出的模块。旧 AI 记录缺少变量时保留当前变量。

AI 先捕获完整操作前快照，仅成功返回的变更记入时间线；取消、拒绝和异常不记录为成功操作。回退按钮调用同一 Store 恢复入口。

验证：快照往返、历史保留、模块历史隔离、快照引用隔离、取消不记账和成功记录变量；运行相关组件/Store 测试、类型检查、lint 和构建。完整模块编辑会话恢复及异步动画竞态另行推进，不据此标记 F2 完成。
