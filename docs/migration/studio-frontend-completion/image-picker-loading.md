# 图像路径选择器加载与请求保护

2026-09-14，F2/F5 有界批次通过。本批只处理节点里的 ImagePathInput，不把整个资源管理服务标为完成。

- 资源列表和文件夹列表一起成功且结构合法后才能展示可选项。加载、服务失败、空列表分别展示；失败提供重试，不把失败解释为空库。
- 显式“选择图像资源”入口使已有路径仍可重开资源库；选择资源仍只向原字段回填路径。
- 关闭、卸载或服务更换使在途列表失效；旧列表不能覆盖下一次打开的结果。
- 系统文件选择只允许一个在途请求；用户修改字段、组件卸载或连接更换后，旧回调不能覆盖新值。取消不修改；错误显示，不只写 console。
- 用户输入路径保持原文，不校验本机文件是否真实存在。本批使用组件服务夹具，不声称真实宿主文件对话框验收通过。
- 全局资源缓存初始化、资源面板并发刷新/增删冲突及完整换区隔离另行处理。

## 验证结果

新增17个组件场景（5种列表失败、3种文件迟到、3种文件无效等分别登记）；与图片预览、上传、资源命令回归合计4文件57项通过。TypeScript、ESLint、renderer/main/preload构建通过。IAB另验证资源选择及撤销/重做，见 evidence/f2-image-picker/browser-ui.md；18条逐项台账。

本批没有重跑整套前端；上一批全量2922发生于图像选择器改动之前。本批完整HTTP/SSE资源故障与真实宿主文件选择尚未验收；现有资源协议测试的通过不替代这些UI场景。
