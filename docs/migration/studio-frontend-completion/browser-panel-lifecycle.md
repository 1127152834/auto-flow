# F4 浏览器面板生命周期验证

- 日期：2026-09-14；状态：本批已实现，F4 整体未完成。
- 来源：冻结 WebRPA 迁入的 AutoBrowserDialog；前端 Mock 服务消费范围。

关闭浏览器、停止拾取返回错误时保留最后确认状态；刷新失败不能证明浏览器已关闭。成功命令使旧状态查询失效。面板隐藏/卸载后忽略迟到结果；每次只有一个轮询请求在途，连续错误只提示一次，恢复后继续轮询。日志回调变化不重置结果去重。

组件测试先复现 6 个失败，修复后扩展为 9 项；加定位测试与录制恢复共 24 项通过。类型检查、lint、renderer/main/preload 构建通过。证据在 evidence/f4-browser-lifecycle。

浏览器界面实测：在独立 localhost:5175 测试页，通过工具栏依次打开面板、打开 Mock 浏览器、启动选择器、停止选择、关闭浏览器。界面依次出现“已打开”“停止选择”“启动选择器”“打开浏览器”，日志确认四个操作。未调用 Store 或内部页面函数。见 browser-ui.md。

边界：该界面链消费内存 Mock，不是 CloakBrowser 实测或正式 Electron 验收。已经发出的剪贴板写请求不能由面板关闭撤回。跨消费者拾取所有权、页面身份、会话命令幂等、宿主离开协调仍待完成；不以本批测试关闭 F4。
