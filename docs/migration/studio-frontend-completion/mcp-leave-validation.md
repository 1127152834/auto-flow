# F5：MCP 连接与编辑离开保护

2026-09-14。

## 已完成

- config/status/save/reload 回执绑定连接修订；旧连接回执不进入当前配置。
- 成功读取后才启用写入；读取失败保留旧列表供识别但禁用写入。显式重新读取后切换到新配置。
- 连接改变保留编辑内容，停止接收旧确认，不将原配置提交给新服务；删除确认也核对所属连接。
- MCP 编辑层关闭、取消、遮罩，以及全局标签/关闭/完成保存/遮罩接入保存、放弃、取消。无修改不要求保存。
- 保存后离开只在成功后执行原目的；保存失败保留输入。实际保存函数验证名称、重复名、stdio 命令、URL 及映射文本，不能借离开路径绕过按钮禁用。
- 复用同一配置检查 hook；编辑层新增语义化 dialog/关闭名称；正常保存仍在确认后关闭。

TypeScript、ESLint、49 项脚本检查、renderer/main/preload 构建通过（32.92 秒）。浏览器确认取消保留、保存后关闭、重新编辑回显，并恢复空白测试目录。见 evidence/f5-mcp-leave。
