# Studio 数据库、DP 与浏览器设置范围调整

日期：2026-09-15

## 产品决定

- 从 Automation Studio 的节点目录、搜索、收藏、常用、自定义模块分类和教学入口中排除全部数据库节点。
- 从 Automation Studio 排除全部 `DP 反检测自动化` 节点。
- Studio 不管理浏览器内核、可执行文件、扩展目录、启动参数或浏览器类型。
- AutoFlow 只使用 CloakBrowser。内核及 Profile 由主应用管理端维护，Studio 的网页节点和临时会话只消费管理端提供的 Profile。

## 代码处理

- 数据库与 DP 源定义暂时保留在兼容层，用于识别旧工作流并给出“不受支持”问题；它们不会进入可添加节点目录。
- 从 Studio 全局设置移除数据库和浏览器两个标签及其同步逻辑。
- 删除数据库专题文档、速查内容、示例和清单入口。
- 保留节点基线由 284 调整为 227：数据库 48 个、DP 9 个，共排除 57 个。

## 验收标准

- 节点目录共 227 个唯一入口。
- 数据库和 DP 分类不显示，相关节点不能通过搜索、收藏、常用或自定义模块分类重新出现。
- Studio 全局设置不显示数据库或浏览器管理入口，也不显示 Edge、Chrome、Chromium、Firefox 等内核选项。
- 旧文档中的数据库或 DP 节点不静默转换为其他节点，仍能被兼容层识别并明确提示不支持。
- 浏览器 Profile 的 CRUD 和 CloakBrowser 内核管理仍属于 AutoFlow 主应用管理端，不属于 Studio。
