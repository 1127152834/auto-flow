# F2 配置字段上下文与重命名保护

2026-09-14，confirmed。ConfigPanel 的字段子树以文档与节点身份作为 key。切换时重建字段局部 UI 状态，保留文档 Store/历史；普通参数修改不改变 key。解决相同类型节点之间复用 VariableNameInput 导致旧名称、延迟重命名提示残留。

VariableNameInput 对 blur 检测定时器去重，值变化或卸载取消旧任务。确认批量改引用时再次检查输出字段仍等于待确认新名，过期则关闭提示，不写旧引用替换。

8 个新用例：切换节点但未编辑不触发改名；待执行 blur、已打开提示、同 ID 节点切换文档均失效；提示打开后再修改字段不套用旧替换；blur 等待期间再次修改不显示旧提示；有效“全部更新”和“仅改此处”保持原行为。
