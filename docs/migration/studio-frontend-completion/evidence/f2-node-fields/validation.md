# F2.2 节点字段、默认值与独有分支核销

日期：2026-09-15

## 结论

- 871 个适用字段逐项与冻结源码字段绑定、当前配置组件清单和工作流 Store 导出/导入合同核对通过。
- 8 个核心网页节点的默认回显与基础约束通过实际 `ConfigPanel` 验证；文本、数值和运行预检继续引用既有共享规则专项。
- 40 个存在独有分支的节点逐项登记。34 个节点由本批实际 `ConfigPanel` 分支测试覆盖；图像触发、手势触发、元素变化触发和分组引用既有实际组件专项。条件、断言、用户输入、子流程、全局配置水合、服务列表、AI 提供商和格式复选等链路均通过界面操作写入 Store。
- 本批发现并修复时间戳转换节点的默认分支不一致：下拉框默认显示“日期时间 → 时间戳”时，输入提示现在采用相同的有效默认值。

## 证据边界

字段专项证明字段仍有冻结源码依据、真实配置组件归属且能通过文档序列化往返。共享输入控件、路径/图像/选择器/模型/代码编辑器等行为由 `f2-tool-entries` 与 `f2-selector-entries` 专项集中证明，避免对相同控件机械重复 871 次交互。独有分支必须由实际组件交互证明，不能用 AST 条件存在代替。

Mock 仅用于工作流列表、全局配置水合、剪贴板和手势等前端服务消费边界；这些结果不代表真实自动化后端已执行。
