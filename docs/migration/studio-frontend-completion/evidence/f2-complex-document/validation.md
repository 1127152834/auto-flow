# F2.3 复杂文档与自定义模块闭环验收

日期：2026-09-15

范围：复杂模块条、分组、便签、子流程、自定义模块列表，以及工作流整包中的模块依赖。真实自动化执行和原生文件落盘不在本证据内。

## 已验证的用户能力

- 条件分支可从实际 `BlockFlowView` 入口插入步骤，顶层块可重排并通过全局历史撤销。
- 嵌套条件、循环和分支在流程图与模块条结构之间往返时保留节点和分支关系。
- 模块条复制完整控制块时生成新标识，并重映射块内 `errorPolicy.targetId`；不在复制集合内的子流程定义引用保持原值。
- 模块条删除步骤时保留分组和便签，并清除指向已删除步骤的悬空连线。
- 子流程分组和子流程头改名会同时更新稳定 `subflowGroupId` 引用及旧名称引用，整批修改可一次撤销、重做，并通过文档导出/导入恢复。
- 分组尺寸、吸附状态和带动组内多个节点移动进入文档历史；组外节点不移动。
- 便签内容、字体格式和尺寸进入文档历史，保存重开后恢复。
- 自定义模块删除确认支持取消；删除或收藏服务失败时保留列表状态并在原入口显示错误。
- 整包导出递归收集嵌套自定义模块；缺失依赖返回明确错误并阻止生成不完整整包。
