# 浏览器 UI 实测

环境：`http://localhost:5175/studio.html`，正式 Studio 页面结构，持久 Mock 服务。该服务明确显示“未执行真实网页操作”。

1. 通过“文件操作 → 导入整包”选择本目录的 `ui-debug-variable.bundle.json`，页面显示 1 个“打开网页”节点和 1 个全局变量。
2. 聚焦节点断点按钮并按 Enter，按钮从“设置断点”变成“移除断点”；随后“运行 → 运行 (F5)”在该节点前显示“断点暂停”。
3. 展开“变量 1 → 编辑”，把 `count` 从 `1` 改为 `7` 并应用。新的暂停事件返回后，面板显示值 `7` 和来源 `[Mock] 人工调试修改`。
4. 点击“单步”，暂停条消失，流程完成。运行历史状态刷新为 `completed`。

首次实测暴露两个问题：透明断点按钮在 React Flow 中缺少 `nodrag/nopan` 和 pointer 隔离；终态事件后运行历史摘要没有刷新。前者已为断点及局部起跑按钮补齐画布手势隔离，后者增加 `studio:run-history-changed` 生命周期通知与组件回归。首次失败不计通过；以上记录是修复后的可观察结果。

边界：这不是正式 Electron，也没有真实浏览器执行；只证明用户可见的导入、断点、暂停变量修改、单步和历史终态链路已消费 Mock/事件合同。
