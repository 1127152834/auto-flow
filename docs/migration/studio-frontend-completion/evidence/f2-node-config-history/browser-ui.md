# 真实浏览器界面操作：节点参数历史

2026-09-14，独立 localhost:5175/studio.html，IAB tab 7，Mock 接口。全链使用 CUA 点击、快捷键和文件选择器，未调用内部函数或直接修改 Store。

1. 文件菜单→导入整包→选择 browser-fixture.json，出现 1 个打开网页节点，名称“F2 网页参数验收”。
2. 选中节点并展开配置；Cmd+S 保存。02:58:56 日志“工作流已保存”，工具栏“空闲”。
3. 打开方式从“新标签页”改“当前标签页”，说明变为“在当前标签页打开，会关闭当前页面”，工具栏“有未保存的更改”。
4. 点击画布节点取得焦点，Ctrl+Z，再选中节点：节点数量仍为 1，配置恢复“新标签页”。Ctrl+Y 后恢复“当前标签页”。
5. Cmd+S，确认覆盖本次测试文件；03:00:08 保存成功，工具栏“空闲”。
6. 刷新，画布为空；文件菜单→打开→F2 网页参数验收；03:00:39 已打开日志。展开配置后 URL=https://example.test、打开方式=当前标签页、等待条件=页面加载完成，节点数 1。

下拉触发器仍有焦点时，尝试 Cmd+Z/Ctrl+Z 未观察到变化；上述通过证据明确限定画布焦点。输入框与下拉焦点的完整快捷键矩阵仍需验收。此链不是正式 Electron 测试，也不是网页执行。
