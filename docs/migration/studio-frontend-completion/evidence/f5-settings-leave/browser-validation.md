## 凭据：取消与放弃

打开全局配置/凭据库，编辑本任务的「F5 凭据确认验收」，仅将说明改为「待确认的离开保护测试」。点击系统，出现保存凭据编辑三选框，原表单禁用。选择取消，说明输入重新可编辑。再次点击存储，重新出现三选框，原待确认说明仍在。选择放弃后进入存储。

## WebDAV：保存后切换与回显

WebDAV 原为空白禁用。只将子目录填写 leave-ui-fixture（未输入地址或密码），点击凭据库，出现保存 WebDAV 配置三选框，表单禁用。选择保存后继续，进入凭据库；原凭据说明仍是 Mock 协议更新回显验收，证实此前放弃没有保存修改。再次进入存储，子目录显示 leave-ui-fixture。

## 清理及直接关闭

将子目录恢复空白，点击保存配置，界面明确显示「已保存模拟配置，未连接远程存储」。点击右上角关闭全局配置，无多余未保存提示，标题不再出现。保留原空闲/空画布及其它本任务测试资源。
