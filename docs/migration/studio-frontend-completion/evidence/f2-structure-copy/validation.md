# F2.3 结构复制与内部引用

来源：停止检查点明确记录的 3 个红例，以及冻结 WebRPA 已有 `parentId`、`subflowGroupId`、`errorPolicy.targetId` 结构语义。本次只修复既有复制/跨文档粘贴/合并入口，不增加结构类型。

- 三种入口生成完整旧 ID → 新 ID 映射，再统一改写复制集合内部的容器、子流程、错误回流和边引用。
- 子节点随父容器复制时保留父坐标系中的相对位置；顶层节点整体平移。
- `selected` 是 React Flow 会话状态，既有历史会移除它。测试只在历史/保存比较时排除该字段，仍严格比较节点 ID、类型、位置、数据、全部内部引用和连线。
- 未复制的外部定义不在 ID 映射中，因此引用保持原值。本项不宣称解决外部依赖打包。

修复前 3 项失败，见 `before.log` 和 `interrupted-failing.log`。修复后专项 3 项通过；关联导入/导出和结构测试见 `related.log`。层级为 Store/文档规则，不是正式 Electron 复制粘贴 E2E。
