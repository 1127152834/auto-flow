# 浏览器 UI 验收：会话离开保护

2026-09-15；本地开发入口 http://127.0.0.1:5175/studio.html；Mock 服务。

通过 CUA 可访问性操作和键盘完成，未注入 Store 或调用页面内部函数：

1. 名称改为「F5 会话离开验收」，显示「有未保存的更改」。打开自动化浏览器面板，点击打开，再进入网页智能录制。
2. 开始录制后按 Alt+N，出现「结束活跃会话后离开？」以及取消／放弃修改并结束会话／保存并结束会话。
3. 取消后仍显示「录制中」「停止录制」，流程名称保持。
4. 再次 Alt+N，保存并结束会话后才显示「未命名工作流」「空闲」。录制面板变为「开始录制」，显示来源归属，禁止加入当前画布。
5. 关闭录制面板，文件→打开，列表包含「F5 会话离开验收.json」，打开后名称恢复。

这是浏览器界面与模拟服务验收。尚未据此验证正式 Electron 退出、真实浏览器进程清理或工作区切换；这些需要独立证据。
