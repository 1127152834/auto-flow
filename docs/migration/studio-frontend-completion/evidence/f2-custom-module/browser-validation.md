# 实际浏览器模块往返验收

2026-09-14；本地 localhost:5175/studio.html，独立 Mock 数据域。通过 CUA 的真实点击、拖拽、输入和快捷键完成，不注入 Store。

1. 主流程命名“F2 模块主草稿验收”，从动作库拖入打印日志节点。
2. 自定义 → 创建模块，标识 f2_module_roundtrip，显示名“F2 模块往返验收”。列表显示创建结果。
3. 编辑 → 编辑工作流 → 确定编辑。顶部显示“编辑模块: F2 模块往返验收”，一个日志节点。
4. 在全局变量面板新增 module_saved，字符串“模块保存往返”。
5. 退出 → 取消：仍显示模块名称和该变量，状态为未保存。
6. 退出 → 保存后继续：恢复主流程名称、一个日志节点、零变量、未保存状态。
7. 再次编辑模块：一个节点和 module_saved=模块保存往返，状态空闲。
8. 退出后 Cmd+Z 将主流程节点撤销到零，Cmd+Shift+Z 恢复一个，表明原历史仍可使用。
9. 再次进入已保存模块并刷新页面；异步恢复后显示模块名称、一个节点、module_saved 原值。退出仍恢复主流程名称和未保存状态。
10. Cmd+S 保存独立验收主流程，界面变为空闲。模块数据仍在此 Mock 数据域。

这属于浏览器前端端到端证据，不是正式 Electron 窗口/包、真实模块执行、Windows 或 Intel 实机证据。
