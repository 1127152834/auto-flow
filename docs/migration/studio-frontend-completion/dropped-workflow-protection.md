# F2 文件拖入与异步文档保护

2026-09-14；有界修复，沿用原文件合并格式和逐文件合并交互。

- 文件读取、密码输入和解密都绑定拖入时的文档身份。切换到其他文档后，即使又打开原文档，也取消尚未完成的导入。
- 同一文档继续编辑允许合并，保留已有变量和编辑。多文件按拖入顺序读取，依次显示密码弹窗；正在导入时再次拖入给出提示。
- 合并成功进入撤销历史并标记未保存；无效 JSON、读取失败、解密失败及取消不添加节点。
- 密码弹窗被另一请求替换或组件卸载时，原请求按取消完成，不能永久等待。

用例见 dropped-workflows.test.ts（9 项）、password-prompt-lifecycle.test.tsx（2 项），加编辑/变量历史回归共 23 项。全量回归 103 文件、1,242 项通过（运行开始后增加的密码生命周期测试由上述定向测试覆盖）。最终 TypeScript、ESLint、renderer/main/preload 构建通过，服务调用盘点仍为 142 个服务、83 个事件、105 个 AI 动作、46 处直接请求。证据在 evidence/f2-dropped-workflows。

证据层级：实际 Store 与文件读取/解密边界集成；尚未登记操作系统文件拖拽的正式 Electron E2E。保留的旧文档分组引用重映射、完整格式损坏矩阵仍需后续专项覆盖；本批不宣称 F2 完成。
