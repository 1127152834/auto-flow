# MCP 配置保存与错误保护

2026-09-14；保存一致性与错误保护已验收，F5 有界任务。依据冻结 MCPConfigPanel.tsx 与后端 ai_assistant.py 的 config/status/reload。

当前问题：列表和服务器映射浅拷贝后先改本地，保存失败仍显示成功状态；删除失败后仍重连；加载不检查 HTTP 或 success:false，错误包可能被当成空配置；重复保存没有互斥；模板预填名称被误判为编辑已有项。

目标：成功确认后更新列表，失败保留已确认配置与编辑输入；删除失败不发 reload；一次面板最多一个保存或重连，待确认时不能重复提交/关闭编辑弹窗；加载/业务错误显示明确提示与重试。使用现有 apiRequest 处理统一错误，不增加第二网络层。模板创建显式传递新增状态，重名不能覆盖已有配置。

用例先覆盖加载HTTP错误与业务错误、新增失败及重试、禁用失败、删除失败且不重连、重复提交、重连失败、模板名称编辑与重名。真实 MCP server 连接和工具执行不在本批，Mock 状态必须明确未连接，不能伪造已注入工具。

## 实际验收

新增 18 项测试，连同传输与凭据回归共 39 项通过。TypeScript、ESLint、48 项脚本、OpenAPI 一致性、renderer/main/preload 构建通过。证据见 evidence/f5-mcp-save。最近一次全量 2,835 项属于日志批次的文件集，不包含本批新增 MCP 用例；本批没有另报全量通过。

独立 IAB localhost:5175/studio.html 中，通过“更多操作 → 全局配置 → MCP → 推荐模板 → 通用 HTTP 抓取”，确认模板作为新增表单，名称可编辑。填写 mcp-ui-check、node、--version，清空自动批准工具后保存；列表显示一个未连接服务器。点击禁用后显示已保存/已禁用，切到系统再返回 MCP，禁用状态恢复，连接数及工具注入数仍为 0。没有运行命令或连接外部服务器，保留一条禁用的 Mock 测试配置。正式 Electron/其他平台仍未实测。

首轮 7 项失败用于定位原实现；删除用例最先暴露无可访问按钮名称，增加名称后再验证失败不重连。新网络用例最初缺独立 localStorage 且未兼容 Request 入参，补齐夹具后通过。测试类型曾使用不支持的 exact 选项，已改为默认精确名称匹配，未放宽断言。

本批仅修复请求错误、确认后提交、面板并发及模板新增身份。环境变量/请求头的文本语法验证、连接更换与请求迟到隔离、全套 MCP OpenAPI 生成类型和真实工具状态合同仍待后续，不宣称 MCP 全功能或 F5 完成。
