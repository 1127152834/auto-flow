# F4 录制来源与命令恢复

日期：2026-09-15。状态：本切片已实现，完整录制审查、分页及宿主协调仍按 F4/F5 推进。

## 实现

- 录制绑定来源文档标识、名称、连接代次。浏览器状态返回前切换文档，不启动录制；启动已接受后切文档，保留原会话的停止入口，禁止把步骤加入新画布。
- 服务切换立即停止旧轮询，不将旧会话停止请求发送到新工作区。关闭旧连接预览需要明确确认，取消保留步骤。
- 启动和停止响应丢失后查询原 `sessionId`。启动不重发；停止确认终态后，从原确认游标补读尾部。查询也不可用时保留未知状态及停止责任；服务明确返回会话不存在时按拒绝处理，可以重新开始。
- `StudioRecorderStatus` 进入生成 OpenAPI 类型。内存与 HTTP 夹具均要求启动/停止/读取的明确会话标识，移除无标识的旧兼容调用。
- 组件串行处理启动和停止；来源不匹配的生成按钮禁用，并在处理函数中再次验证。组件卸载后的响应不能启动后台轮询。
