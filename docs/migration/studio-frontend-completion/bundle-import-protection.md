# F5 整包导入保护

日期：2026-09-14；状态：本切片已实现并验证。

整包导入会恢复资源并替换文档，必须先通过保存/放弃/取消。文件读取期间草稿变化、资源导入期间继续编辑时不得用迟到结果覆盖。确认取消不调用导入服务；服务失败保留草稿；非法响应不得报告导入成功。导入后的文档尚未保存为工作流，应标为未保存。

本切片仍保留原资源导入 API。已确认导入资源后用户继续编辑，文档保持原样并明确提示资源已导入，需要重新操作；不伪装成服务端资源事务回滚。完整资源事务/恢复协议后续继续验收。

用例：取消无请求、保存后导入、放弃后导入、保存失败、服务失败、保存中编辑、资源请求中编辑、文件读取中编辑、无效工作流与成功导入脏状态。真实文件选择由界面触发，组件测试用标准 input change 注入独立测试文件。

- 8 项新增整包场景通过，工具栏相关共 28 项通过；TypeScript、ESLint 与 renderer/main/preload 构建通过。
