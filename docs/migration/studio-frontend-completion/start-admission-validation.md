# 启动确认与文档服务身份

2026-09-14；状态：有界实现、专项与完整复核通过。

原工具栏在HTTP接受后立刻释放启动锁，SSE迟到时同一次用户操作可再次提交。现在分开记录请求准备与待确认状态，三种运行入口共用同一保护。HTTP接受不冒充running，网络丢失或5xx不自动重试动作，显示等待确认与停止入口；明确4xx拒绝允许显式重试。只有匹配服务工作流标识的started/completed/stopped解除等待，外来事件无效，早于HTTP的终态不会被旧响应恢复成等待。全局停止和停止按钮支持待确认请求。

缓存的服务流程标识绑定编辑文档ID；异步准备时切换文档，旧响应只归属原文档，当前文档后续运行必须独立创建。现有正在准备的快照仍按原行为启动，不声称补齐跨窗口/文档离开协调。
