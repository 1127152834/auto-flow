## 修复和合同

变量声明进入文档历史；增删改和重命名标脏。节点创建产生的默认变量随节点一起撤销。loadWorkflow 未带变量时清空旧变量，导入变量纳入历史基线。带引用的重命名一次更新声明和嵌套配置中的可识别文本引用；保留界面“不更新引用”的现有选择。重复名字拒绝，不能覆盖另一变量。
