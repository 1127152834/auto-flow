# 日志身份与有界补读去重

2026-09-14；本批规则与网络协议测试通过，F3 有界切片。

冻结 WebRPA LogManager.log 为每条日志生成 uuid4。execution:log 和 execution:log_batch 均携带 id，但原前端缓冲丢弃 id，Store 重新生成随机标识。当前目标保留服务端全局唯一且不可变的日志 id、时间与 details，实时和补读共用去重入口。

同 ID 重送不增加行或覆盖首条已确认内容；不同 ID 即使节点、时间和文本相同仍保留。无 ID 的旧生产者和前端本地日志继续生成独立标识，不按内容猜测重复。去重只覆盖当前保留行及本批输入，不维持无限已读集合；超过 maxLogCount 被裁掉的旧行允许再次补入。清空日志后允许完整补读。服务必须为不同执行生成不同日志 ID；前端当前仍缺独立 runId 和服务生命周期标识，本批不解决同流程迟到事件归属，也不构成完整历史分页恢复。

测试：内存与实际 HTTP/SSE 的单条/批量交叉重复、重连保留行、清空补读、相同内容不同 ID；Store 同批重复、重复内容冲突首条保留、无 ID 日志、容量裁剪及清空。已有时间戳和跨文档缓冲保护回归。
